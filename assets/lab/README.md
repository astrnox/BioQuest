# Virtual laboratory visual assets

These project-bound WebP assets were prepared for the BioQuest virtual biology laboratory. They are intentionally rendered with the same bright neutral laboratory lighting, realistic glass/plastic materials, and restrained sage/cream palette so canvas overlays remain readable.

## Generated assets and prompt direction

- `chromatography-apparatus.webp` — a sealed chromatography chamber with one hanging filter-paper strip, baseline above a shallow solvent layer, front-on laboratory product-photography composition.
- `dna-extraction-bench.webp` — a four-station plant DNA workflow: mortar and pestle, gauze filtration, cold-ethanol interface beaker, and heated diphenylamine test tube.
- `microbe-streak-bench.webp` — an aseptic streak-plate workbench with alcohol lamp, inoculating loop, open Petri dish, and clean neutral background.
- `catalase-test-tubes.webp` — four transparent test tubes in a wooden rack, equal pale reaction mixture, front-facing comparison setup.
- `plasmolysis-normal.webp` — circular red-onion epidermis micrograph with turgid cells in one fixed field.
- `plasmolysis-separated.webp` — edited version of the same field, with the protoplast retracted from the cell wall while cell-wall geometry remains aligned.

`microscope-3d-preview.webp` is a compressed preview derived from the user-approved 3D microscope prototype.
