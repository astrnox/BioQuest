## 1. 规则速查表（一页判生死）

| 判定 | 条件（满足其一即可） | 动作 |
|---|---|---|
| **S（金标）** | 总分 ≥ 90，且命中[金标要件](#7-顶刊出题专项金标投稿通道)（顶刊原文改编 + 双重复核通过） | 上架并标记 `premium`，优先用于联赛/竞赛轮刷题 |
| **A（留）** | 总分 80–89，无红牌，解析与引用完整 | 上架 |
| **B（留待修）** | 总分 70–79，无红牌，仅存在轻微瑕疵 | 上架，登记必改项，1 个月内补齐后升 A |
| **C（重修）** | 总分 60–69，或存在重大但不触红牌的缺陷 | 下架，全题重写后重新走 [一审-复核](#10-审题流程与复检机制) |
| **D（删）** | 总分 < 60，或命中任意[红牌](#4-一票否决项红牌直接判删) | 删除单题文件、[id大全](#9-题库文件存储规范per-id-单题文件--id大全)条目，并由脚本再生 bank/index/manifest |

记分公式：`总分 = D1×25% + D2×15% + D3×15% + D4×15% + D5×10% + D6×10% + D7×5% + D8×5%`（各维度满分 100，见[第 5 节](#5-七大质量维度评分细则)）。

> 一句话版本：**科学错、抄袭、占位解析、假引用、超纲灌水、格式损坏 → 删；顶刊改编 + 双重复核 → 金标；其余按 8 维打分排座次。**
>
> 附加要求与目标：**A 级建议带图；S 级金标凡主题可得配图必须带真实图片**；全库带图占比 ≥ 30%（核算见[第 13 节](#13-图片规则30-真实论文配图)）；题库采用 per-id 单题文件存储（[第 9 节](#9-题库文件存储规范per-id-单题文件--id大全)）。

## 2. 目的与适用范围

### 2.1 目的

1. 把题库从"占位演示数据"（README 已声明，见 [README.md](file:///workspace/README.md)）升级为"可直接用于联赛命题"的高质量题库；
2. 为每一位审题人提供**可操作的打分锚点**，消除"凭感觉留/删"的主观差异；
3. 建立**可追溯、可复核**的裁决记录（评分卡留档），防止同一道题被反复改判；
4. 明确**前沿题来源通道**（顶刊原文改编），使题库始终保持与 2024–2026 生物学进展同步。

### 2.2 适用范围

- **规范真源（v1.1 起）**：`/workspace/data/questions/<tag>/<difficulty>/<id>.json`（每道题一个 JSON，按考点与难度分目录）；筛选索引为 `data/questions/id-all.json`（id大全，见[第 9 节](#9-题库文件存储规范per-id-单题文件--id大全)）。
- 兼容产物：`/workspace/data/bank/<tag>.json`（整主题合并题集，旧前端加载器使用）、`/workspace/data/index/<tag>.json`（轻量索引），均由脚本再生，禁止手改。
- 题目配图：`/workspace/assets/questions/<id>/`（真实配图，见[第 13 节](#13-图片规则30-真实论文配图)）。
- 迁移产物：`/workspace/scripts/converted-questions.json`、`/workspace/scripts/convert-to-mtf.js` 生成的题目，同样适用本规则；
- 归档区 `archive/data-legacy/` 的旧格式数据**不直接适用**，如需复活必须按本规则重写后走全新流程。

### 2.3 目标题型与对标考试

| 项 | 说明 |
|---|---|
| 本库题型 | 多重判断（`type: "mtf"`，A/B/C/D 四个陈述，每项 `answer: true/false`） |
| 对标考试 | 全国中学生生物学联赛（理论卷：单选 + 多选/多重判断，覆盖细胞/生化/植物/动物/遗传/进化/生态/微生物免疫/生物技术）；第一届 GGBO 生物学竞赛（真题见 [第一届GGBO生物学竞赛考试试题.pdf](file:///workspace/第一届GGBO生物学竞赛考试试题.pdf)） |
| 风格基准 | 联赛真题（[全国中学生生物学联赛真题与答案 .pdf](file:///workspace/全国中学生生物学联赛真题与答案%20.pdf)）：题干自足、选项同构、多选通常 1–2 个正确项、解析以机制解释为主 |

### 2.4 与现有自动校验的关系

本规则是**质量分级规则**；现有代码链（[review-questions.py](file:///workspace/tools/python/review-questions.py) 调用的 `scientific_sanity_check / proposition_rule_check / distractor_quality_check / dedup_check / self_check`，定义见 [server.py](file:///workspace/tools/python/server.py)）是**格式与硬伤拦截器**。

- 自动校验负责：字长下限、选项包含关系、答案结构、与库内相似度 > 0.88 的去重、双模型自检一致性；
- 本规则负责：科学真伪、命题境界、干扰项设计质量、解析完备性、难度标定、前沿性、引用真实性的**分级判定**；
- 流程衔接：自动校验不过 → 先修/删（见第 10 节）；自动校验通过 → 进入本规则打分。

**红线提醒 ①**：自动校验通过 ≠ 质量合格。占位解析（如"正确答案：A。详细解析请参见相关教材。"）能通过字长校验，但按本规则直接判 C/D。

**红线提醒 ②（答案审计，v1.1 强制）**：自动校验只查"答案结构"，**不查"答案对错"**。实测 [genomics_comp.json](file:///workspace/data/bank/genomics_comp.json) 五题标答全部存在科学错误（见 R1 判例）。因此**任何解析改写或新题提交前，必须先做答案审计**：逐选项与公认科学结论比对，确认 `answer` 无误后才写解析；解析只能基于**审计后的正确标答**，禁止为明显错误的标答"圆场"——那是在制造错误知识传播。

## 3. 题目分级与去留判定

### 3.1 五级定义

| 等级 | 名称 | 含义 |
|---|---|---|
| S | 金标 | 联赛命题级，可作竞赛压轴/前沿题；含顶刊出处与完整推导解析 |
| A | 优质 | 联赛命题级，科学清晰、解析完备、无明显短板 |
| B | 合格可修 | 联赛可用，存在轻微瑕疵（如引用缺失、某选项可更精炼） |
| C | 待重修 | 有硬伤但不触红牌（如解析过短、难度标定失当、干扰项弱） |
| D | 淘汰 | 触犯红牌或总分不达标，必须删除 |

### 3.2 判定动作矩阵

```
总分 ≥ 90 且命中金标要件 ──────────────→ S  上架 + premium 标记
总分 ≥ 90 未命中金标要件 / 80–89 ─────→ A  上架
70–79 ────────────────────────────────→ B  上架，登记必改项
60–69 ────────────────────────────────→ C  下架重修
< 60 或命中红牌 R1–R12 ──────────────→ D  删除
```

### 3.3 裁决记录

每道题的裁决必须写进评分卡（模板见[第 12 节](#12-评分卡模板)）并归档，至少包含：

- 题目 id、主题、审题日期、一审人、复核人；
- 八维得分与总分、等级、动作；
- 红牌/扣分点引用（哪一段命中第几条规则）；
- 修改记录（改了什么、改后是否复评）；
- **答案审计记录**：若 `answer` 有改动，必须记录改动前后值与依据（引用教材/文献），并双人确认（见 R1 判定要点）。

## 4. 一票否决项（红牌，直接判删）

命中下列任意一条，**不用打分，直接判 D**。红牌裁决必须双人确认（一审负责人 + 复核人）。

### R1 科学事实错误

- 题干、选项或解析中存在与公认科学结论相悖的事实；**包括"标答本身就是错的"**（格式校验发现不了，必须人工答案审计）。
- 典型例子（2026-08 审计实测，全部已按正确标答修复，见[§15 修订记录](#15-修订记录)）：[genomics_comp.json](file:///workspace/data/bank/genomics_comp.json) 五题标答全部出错——
  - `M4-15-d6e03be35bca`（ATAC-seq）：选项 A"利用 Tn5 转座酶检测基因组开放区域"与 B"反映染色质可及性"均为正确叙述却标 `false`，标答仅 D；
  - `M4-15-a46a014b6807`（ChIP-seq）：A"流程含交联、免疫沉淀、测序、分析"与 B"绘制全基因组组蛋白修饰图谱"均为正确却标 `false`；
  - `M4-15-287eb21899d1`（比较基因组学）：C"帮助识别功能重要的保守元件"为正确却标 `false`；
  - `M4-15-d9fd6be3d7a7`（系统发生基因组学）：A/B 正确却标 `false`，D"不能解决快速辐射演化"为错误却标 `true`；
  - `M4-15-e04dabe4401c`（结构域预测）：D"InterPro 整合多个特征数据库"为正确却标 `false`。
- 处置：命中 R1 一律判 D；但可通过"'先下线 → 修正标答与解析 → 走 C 流程复活'"保留考点（修复后按新分定级）。

> 判定要点：① 查教材权威定义；② 查领域综述；③ 涉及数据/数值必须复核（如人类染色体数、光合作用量子产额、遗传计算比例）；④ 对存疑项做"最小权威源"检索后再下结论。

### R2 抄袭与版权违规

- 整题或选项直接从真题、教辅、论文原文翻译/抄录，未经许可且未改造。
- 联赛真题 PDF 仅作为**风格对照**，不得直接收录原文（版权）；同考点必须重新命题（换情境、换数据、换设问）。
- 论文图表直接搬用需版权许可；规则鼓励"改画示意图/简化数据表"（示意图仅供题解，不作为带图题的 evidence）；
- **配图版权**：题目配图仅可从开放获取（OA/CC-BY 等）论文或已授权素材获取，必须写入 `license` 与 `credit`（见[第 13 节](#13-图片规则30-真实论文配图)）；伪造出处、盗链外站、无许可搬用论文图均按 R2 判 D。

### R3 占位/空壳解析

- `explanation` 为占位符模式，如："正确答案：A。详细解析请参见相关教材。" / "正确答案：A, B。详细解析请参见相关教材。"（本库大量存在，见 [mendel.json](file:///workspace/data/bank/mendel.json#L48-L92) 的 `M4-01-6f6db374bc12`）、解析为空、或解析只列答案不解释任何选项。
- 联赛题解析最低要求（v1.1）：**逐项覆盖 A/B/C/D，且每项都要说明"为什么对/错"**——正确项给出依据，错误项给出错因；只复述答案、不给理由的空壳句（如"该选项错误是因为概念不清"）按 40 分档扣分（见 [D4](#d4-解析质量权重-15)）。整题 < 120 字或未逐项覆盖判 D（若其余均佳，可执行"先判 D 下线、重写解析后走 C 流程复活"）。

### R4 参考文献造假或无法核验

- `references` 中的 DOI 无法解析、或作者/标题/年份/期刊与 DOI 元数据不符，或明显为 AI 幻觉引用（如把综述作者写成科普作家、年份错配）。
- 判定：抽样 100% 核验 S/A 级题的引用；B 级以下无引用不构成红牌，但**有引用就必须真实**。
- 示例（需核验）：[mendel.json](file:///workspace/data/bank/mendel.json#L38-L46) 中 `M4-01-1cdf6e6e0193` 的引用 `Henig RM, "Mendel's laws of inheritance", Nature Reviews Genetics, 2020` —— 与已知综述对应关系存疑，**核验不通过则按 R4 处理该引用字段并降级**。

### R5 选项设置违规

- 出现"以上都对 / 以上都不对 / 无法确定 / 都有可能"等无信息量选项；
- 通过把科学上正确的叙述故意标 false 来"凑四个选项"（见 R1 的 ATAC-seq 例）；
- 正确项数量不当：mtf 四选项题**正确项应为 1–3 个**；全对（0 false）或全错（0 true）判违规（联赛多选语境下无此惯例）；
- 选项互为包含/同义重复（同一事实换说法出现两次）。

### R6 歧义双解

- 题干或某选项存在两种科学上都讲得通的解读，且解析无法澄清的；
- 判定：双人独立读题，若两人对任一选项的判读不一致且无法通过修改措辞消除，即命中 R6。

### R7 语义重复

- 与库内已有题目题干/选项语义相似度过高。沿用自动校验阈值：**相似度 > 0.88 判重**；题干 8-gram 重叠率 > 70% 亦判重（不同题型间不算，如 mcq 与 mtf 同考点不判重）。

### R8 数据格式损坏

- 缺字段（`question` / `subQuestions` / `explanation` / `difficulty` / `target` / `tags` 任一缺失）；
- `subQuestions` 不足 4 项、`label` 不连续（A/B/C/D）、`answer` 非布尔；
- JSON 解析失败、id 重复、id 与 index 文件不一致。

### R9 内容违禁

- 政治敏感、诱导作弊（教人作弊手段）、人身攻击、歧视性内容、成人或暴力内容；
- 医学题目涉及传播危害健康的不实信息（如夸大某疗法）。

### R10 超纲灌水

- 考点超出联赛考纲，且**非**前沿题（无顶刊出处支撑），属于"炫技式冷门"（如堆叠本科才学的生僻酶学名词而不给情境）；
- 判据：对照联赛大纲八模块；与真题覆盖面比对；一个考点若无任何教材/真题支撑，除非有文献出处，否则判 R10。

### R11 难度与目标严重错配

- `difficulty: league` 但实为纯识记题（考察"名词是什么"而无推理）；或 `target: high_school` 但涉及竞赛级计算；或 `difficulty` 与 `target` 字段互相矛盾（如 league + high_school 并存）。
- 判据见[第 5 节 D5](#d5-难度与区分度联赛适配-权重-10)。

### R12 引导式/暗示式选项

- 选项含明显语气标记帮助猜答案（如唯一加长选项、唯一带具体数字的选项、其余选项均为明显错误句式）；或题干暗示答案（如"以下哪个**不是**"只被一个选项满足且其余选项显然正确）。

## 5. 七大质量维度评分细则

> 每维度满分 100，最终按权重折算。评分锚点给出 **0 / 40 / 70 / 90 / 100** 五档描述，取最近档，允许 5 分步进微调（如 75 = "未到 90 档但显著优于 70 档"）。
> 说明：D1 科学正确性是大前提，虽不是"一票否决"性质，但任何维度打到 0 分都会把总分拖到 D 区间；第 4 节红牌与本节是**递进关系**——先查红牌，再打分。

### D1 科学正确性与严谨性（权重 25%）

核心问题：**这道题所依据的科学事实是否成立、表述是否严谨？**

| 分数 | 锚点描述 |
|---|---|
| 100 | 全部事实精确，数值/比例/机制无瑕疵，用词严谨（"通常/多数情况"得当），无时代局限错误 |
| 90 | 事实完全正确，仅个别表述可更严谨 |
| 70 | 核心事实正确，但存在边缘性表述问题（如把"细菌无核膜"说成"细菌无染色体"） |
| 40 | 存在实质性事实偏差（如机制因果关系颠倒、数值错一位、比例错误） |
| 0 | 明确科学错误（→ 同时命中 R1，判 D） |

扣分点清单：

- 概念张冠李戴（如"翻译发生在细胞核"）；
- 数值/单位错误（如"人类 22 对常染色体"写成"23 对常染色体"）；
- 机制因果颠倒（如把"Ca²⁺ 内流导致突触囊泡释放"说反）；
- 以偏概全（把特例当通则且未限定）；
- 用中学旧表述否认已更新结论且无出处（如仍称"基因是 DNA 片段"而忽略 RNA 病毒/非经典遗传）。

核验动作：① 教材（人教版为主）对照；② 若为前沿题，对照原文摘要与结论；③ 数值算一遍。

### D2 命题规范性与题干质量（权重 15%）

核心问题：**题干是否自足、指向明确、联赛语境规范？**

| 分数 | 锚点描述 |
|---|---|
| 100 | 题干给出完整情境/限定（如"在减数分裂 I 后期"），不依赖选项可独立作答，无复习提示，无冗余词 |
| 90 | 情境清晰，个别用词可优化 |
| 70 | 题干基本自足，但偏口号式（如"关于 X，以下说法正确的有哪些？"未给任何限定/情境） |
| 40 | 题干依赖选项才能理解；或含明显复习暗示（"记得老师常说…"）；或设问含糊（"以下正确的是"指向多解） |
| 0 | 题干残缺（无有效设问）或与选项无关（→ 接近 R8） |

好题干公式：`[限定情境/体系] + [考察操作或机制] + [设问动词]`
例（好）："某二倍体植物花色由两对独立遗传的基因控制，F₂ 出现 9:7。下列分析正确的有："
例（差，本库常见）："关于比较基因组学方法，以下说法正确的有哪些？"——无情境、无体系，属于可判 70 分或以下的"口号题干"。

联赛级额外要求：

- 题干一般 15–80 字（与真题相当），信息量集中在情境而非语气；
- 涉及实验题必须给全实验条件（材料、处理、检测），缺条件判扣分；
- 不用反问句、感叹句；不用"瞧瞧/想想"等口语。

### D3 选项与干扰项质量（权重 15%）

核心问题：**四个陈述是否同构、独立、均具信息量？干扰项是否基于真实误区？**

| 分数 | 锚点描述 |
|---|---|
| 100 | 四陈述同构（同为机制/同为数值/同为实例）、互斥、长度均衡（最长/最短 ≤ 2.5 倍）、干扰项全部基于常见误区且具迷惑性 |
| 90 | 同上，个别干扰项略弱 |
| 70 | 结构合格，但 1 个干扰项偏弱（正确性一目了然或明显无关） |
| 40 | 结构不合格：正确项扎堆（3–4 个 true）、或干扰项通过"否定正确事实"拼凑、或选项长度差异悬殊 |
| 0 | 命中 R5/R12（设置违规/引导暗示）→ 判 D |

干扰项设计的"三真一假"思维：联赛多选/判断题的干扰项应来自**学生的典型误解**，例如：

- 把适用条件漏掉（"F₂ 比例一定是 9:3:3:1"）；
- 把层次错配（"转录不需要酶"）；
- 把因果倒置（"ATP 合成酶驱动 H⁺ 泵"）；
- 把特例普遍化（"所有细胞都有细胞壁"）。

正确项数量纪律：**mtf 四选项题正确项 = 1–3 个**。分布建议在整卷层面均匀（约 1/3 单正确、1/3 双正确、1/3 三正确），避免同一套题连续出现"都是 2 个正确"的节奏暗示。

选项长度纪律：**单项 8–60 字**，四选项长度均衡（最长/最短 ≤ 2.5 倍）；避免"一句话 vs 三句话"的悬殊布局（那会诱导猜题，命中 R12 风险）。

### D4 解析质量（权重 15%）

核心问题：**解析是否逐项说明"为什么对/错"、长度适中、有依据、能教学？**

**格式要求（v1.1 强制执行）**：每项以 `A【对】…` 或 `B【错】…` 开头，紧跟 1–2 句理由（依据/错因）；**单项 20–60 字**（过长视为冗余、过短视为只给结论），全题 120–320 字。

| 分数 | 锚点描述 |
|---|---|
| 100 | 逐项以"【对】…/【错】…"格式覆盖 A–D；每项均给出机制/推导/错因；单项 20–60 字、整题 120–320 字；含推导过程（计算/遗传题）；有出处（教材页码或文献 DOI） |
| 90 | 逐项覆盖且均给理由，但某单项略短（< 20 字）或出处可补充 |
| 70 | 覆盖 3/4 项，或覆盖全部但有 1–2 项只给结论不给理由 |
| 40 | 只覆盖正确项、错误项未解释；或全篇空话（"该选项错误是因为概念不清"）；或整篇明显超长/超短 |
| 0 | 占位符 / 空（→ R3，判 D） |

解析写作模板（每项必须落到"为什么"）：

```
A【对】依据：……（机制原理 1–2 句，20–60 字）。
B【错】错因：……（指出它与正确机制出入在哪，20–60 字）。
C【错】错因：……（常见误区说明）。
D【对】依据：……。
【考点延伸】本题考察 xxx，属于联赛 xx 模块；关联真题/文献：……
```

自我检查清单：① 四个字母都出现且顺序一致；② 每项都有理由动词（"依据/因为/而/因此"）；③ 每项字数在 20–60 区间；④ 与审计后的标答严格一致（见 R1 答案审计）；⑤ 学术上站得住（重要机制不凭记忆，对照教材/文献）。

### D5 难度与区分度（联赛适配）（权重 10%）

核心问题：**这道题放在联赛卷子里，难度位置对不对、能不能拉开分？**

| 分数 | 锚点描述 |
|---|---|
| 100 | 难度与 `difficulty` 字段一致；纯识记 0%、理解/应用/分析为主；预判正确率 0.35–0.75；区分度好（会者不错基础分） |
| 90 | 同上，个别选项区分度略低 |
| 70 | 难度基本匹配但有一项偏离（如 20% 纯识记成分） |
| 40 | 明显错配：识记题标 league，或联赛题只考记忆；或 90% 考生必对/必错 |
| 0 | 严重错配 → R11，判 D |

难度判定工具：

- 对照联赛真题同考点题的设问深度；
- 用 BKT/IRT 引擎历史数据（`js/integrations/irt-enhanced.js` 已接入）校验实测正确率：样本 ≥ 30 后，正确率 > 0.9 视为过易、< 0.2 视为过难，需复核 difficulty；
- 能力层次自评：识记（是什么）< 理解（为什么）< 应用（换情境）< 分析（多步/多条件）< 综合（跨模块）。联赛题应 ≥ 理解档，前沿题为应用/分析档。

### D6 新颖性与前沿性（权重 10%）

核心问题：**这题是不是"老题换皮"？有没有带出新东西？**

| 分数 | 锚点描述 |
|---|---|
| 100 | 基于近三年顶刊原文核心发现改编（命中金标要件）；或对本库既有考点给出全新情境与设问 |
| 90 | 新情境 + 新数据，机制为经典但组合新颖 |
| 70 | 考点经典，情境至少做了场景更新（不直接与库内题同构） |
| 40 | 与库内已有题仅换数字/换名词，属换皮 |
| 0 | 与库内题整题同构（→ R7，判 D） |

鼓励方向：空间组学、单细胞、表观遗传、RNA 修饰、基因编辑临床转化、microRNA、合成生物学、微生物组-宿主互作、生态-气候互作、古 DNA 与人类演化（详见[第 7 节](#7-顶刊出题专项金标投稿通道)）。

### D7 可溯源性 / 参考文献（权重 5%）

核心问题：**考点与解析有没有出处可查？**

| 分数 | 锚点描述 |
|---|---|
| 100 | `references` 非空，DOI 经核验有效，作者/年份/期刊与元数据一致；解析内标注出处 |
| 70 | 无 `references`，但解析引用教材章节（注明版本/页码），或经典考点可溯源教材 |
| 40 | 出处含糊（"据说…""某某研究"），无法定位 |
| 0 | 有引用但造假/错配（→ R4，按红牌处理） |

要求：S/A 级题 `references` 必填；B 级以下可用教材页码替代，但**绝不能出现假引用**。参考文献格式见[第 7.5 节](#75-引用格式与版权红线)。

### D8 唯一性 / 去重（权重 5%）

核心问题：**库内是否已有语义等价的题？**

| 分数 | 锚点描述 |

| 100 | 与库内全题语义相似度 < 0.85，题干 8-gram 重叠 < 60% |
| 70 | 相似度 0.85–0.88（临界），需说明与既有题的差异 |
| 40 | 相似度 > 0.88（命中自动校验阈值） |

### 7.4 从论文到题目的六步改造法

1. **选点**：从摘要/主图结论中挑出 1 个可迁移到高中知识体系的核心机制结论（如"某 lncRNA 通过充当 miRNA 海绵上调靶基因翻译"）。
2. **定档**：确认对应考纲模块、`subject`、`concept`；预估联赛可考难度（应用/分析档）。
3. **情境重构**：把论文的实验体系转译为高中生能读懂的实验情境（保留关键变量：材料、处理、对照、检测），**不出现论文特异性术语堆叠**。
4. **设项**：按 [D3](#d3-选项与干扰项质量权重-15) 设计 4 个陈述，干扰项取材典型误解，正确项 1–3 个。
5. **作解析**：按 [D4](#d4-解析质量权重-15) 模板写 150–400 字，含机制推导与**文献出处**。
6. **回环校验**：三级查证——① 机制与原文一致；② 考点在联赛考纲内或具前沿出处；③ 无 R1–R12 命中；④ 双人复核通过方可标 S。

加分项（S 级推荐做法）：将论文数据的**简化结果表/柱状图**转换为题干情境（如"野生型 vs 敲除组目标 mRNA 相对量 1.0 vs 0.4"），考察读图表 + 机制推理，这是联赛真题近年偏好。

### 7.5 引用格式与版权红线

- 引用格式（沿用题库现有 `references` 结构）：

```json
"references": [
  {
    "doi": "10.1016/j.cell.2018.03.006",
    "title": "Metazoan MicroRNAs",
    "authors": "Bartel DP",
    "year": 2018,
    "journal": "Cell"
  }
```

## 9. 题库文件存储规范（per-id 单题文件 + id大全）

> v1.1 起，题库从"一主题一个 JSON"迁移为"**一题一文件 + id大全索引**"，满足按考点/难度按需加载、单题追溯与 diff 审计。落地工具：`tools/python/rebuild-bank-perid.py`（build / clear / verify / new）。

### 9.1 目录规范（唯一真源：`data/questions/`）

```
data/
  questions/                      # 规范单题文件（真源，仅此处手改；new 命令可脚手架建题）
    <tag>/                        # 考点目录（80 个，与 data/bank/<tag>.json 同名）
      <difficulty>/               # high_school | league
        <id>.json                 # 一题一文件，内容 = 该题完整对象（不含 id 字段）
    id-all.json                   # ① id大全：全库筛选索引（见 9.3）

  index/<tag>.json                # 兼容产物：轻量索引（id -> {src,tags,diff,module,...}）
  manifest.json                   # rev+1 + files 的 SHA-256 全量重算 + total/topics.count
assets/
  questions/<id>/                 # 该题配图（fig1.webp + image.json 溯源，见第 13 节）
```

- 新增/删除/修改题目的唯一正规路径：**直接编辑 `data/questions/`**（可用 `new` 命令生成骨架），然后运行 `python3 tools/python/rebuild-bank-perid.py build --per-id-only` 一次再生 `id-all.json`、`data/bank/`、`data/index/` 并更新 `manifest.json`；不得手改三个产物。
- 批量导入旧格式：先恢复 `data/bank/<tag>.json` 形态的整卷文件，再 `build --from-bank` 自动迁移成 `data/questions/`。

### 9.2 常用命令

```bash

python3 tools/python/rebuild-bank-perid.py build --per-id-only     # 真源 → 再生四件套
```


用途：前端按 `tag` + `difficulty` 过滤出 id 列表后，仅加载 `file` 指向的单题文件；CI/脚本用 `total`、`has_image` 做去重与带图占比核算。

### 9.4 提交与修改纪律

1. **备份先行**：批量编辑前备份真源：`cp -r data/questions /tmp/questions-backup-<date>`（2026-08-29 重构时曾对 `data/bank/` 做 `/tmp/bank-backup`）；
2. **答案审计同步**：改动 `answer` 必须留"前后值 + 依据"记录（见 R1 与评分卡）；
3. **原子化**：编辑 questions 目录 → 跑 `build --per-id-only` → 跑 `verify`（errors=0 才提交）→ 复核 answer diff 清单；
4. **id 命名**：沿用内容寻址 id（如 `M4-15-d6e03be35bca`）；新题按 `M{模块}-{主题序号}-{8位hex}`，hex 取规范内容 sha256 前 8 位；
5. **manifest**：`rev` +1、`updated_at` 更新、四类文件 SHA-256 全量重算（脚本自动完成）。

## 10. 审题流程与复检机制

### 10.1 单人初审（一审）

1. 运行自动校验链（[review-questions.py](file:///workspace/tools/python/review-questions.py) + [server.py](file:///workspace/tools/python/server.py) 五重校验）；不过 → 修复或删除，**不过不进入打分**；
2. 按[第 4 节](#4-一票否决项红牌直接判删)过 12 条红牌；命中 → 判 D，直接删除并记录；
3. 按[第 5 节](#5-七大质量维度评分细则)八维打分，填[评分卡](#12-评分卡模板)，得等级与动作（S/A/B/C/D）；
4. 出具理由：引用扣分条款 + 可执行修改建议（"B 级：D7 缺引用，补 Bartel 2018 或当页教材"）。

### 10.2 双人复核（终审）

- 审题人 ≥ 2 人；**S 级与 D 级必须双人确认**（D 级删除要留 `id` 清单，便于误删恢复）；
- 复核人独立打分，两卡差异 ≥ 10 分或等级跨档（如 A↔C）时进入仲裁：第三人对争议维度给出最终分；
- 复核重点是 R1（科学）、R2（版权）、R4（引用）、R6（歧义）四类易漏项。

### 10.3 学生反馈闭环（数据驱动复检）

- 平台已有 `fb_good` / `fb_bad` 埋点（见 [review-questions.py](file:///workspace/tools/python/review-questions.py) 数据模型）：
  - 样本 ≥ 30 且 `fb_bad/(fb_good+fb_bad) > 40%` → 强制复检（优先查 R1/R6）；
  - 正确率 > 0.9 → 复核 difficulty 是否虚高（D5）；
  - 正确率 < 0.2 → 复核是否超纲/设问歧义（R6/R10）；
- 错误反馈走 GitHub issue 模板（[question_error.yml](file:///workspace/.github/ISSUE_TEMPLATE/question_error.yml)）的，合并到月度复审批次。

### 10.4 定期全量复审

| 周期 | 范围 | 动作 |
|---|---|---|
| 每季度 | 随机 20% 题目 | 抽检等级有效性，抽取差异 > 0.5 档时回溯校准 |
| 每半年 | 全部 S 级与 references 非空题 | 引用时效（> 5 年的综述降级提示）、前沿性复核 |
| 每年 | 全量 | 按最新考纲与顶刊进展重判；失效前沿题转普通档或下架 |

## 13. 图片规则（带图占比 ≥30%，图片必须真实有效）

### 13.1 目标与占比核算

- 全库带图题 / 总题数 **≥ 30%**（按 `data/questions/id-all.json` 的 `has_image` 统计；核算命令：`python3 tools/python/fetch-figures.py coverage`）。
- 带图定义：题目配有 1 张及以上与考点直接相关、能辅助理解机制/作答的图片。
- 每季度发布前核算一次；未达标时，新入库题优先带图补足。

### 13.2 "真实有效"铁律（来源白名单）

图片必须是**真实存在、可溯源**的素材：

- 开放获取（OA）论文原文配图，且许可为 **CC BY / CC BY-NC / CC BY-SA / CC0 / 公有领域**（如 PMC / PLoS / eLife / BMC / Frontiers / MDPI）；
- 已授权教材/机构图库、或仓库内已授权真实照片（`assets/lab/`、`microscope-3d/`，见 `ASSET-LICENSES.md`）；
- 禁止：AI 生成图冒充论文图、占位图/纯色块、无许可盗搬、盗链外站（必须本地文件）、分辨率过低（宽 < 640px）。

### 13.3 从论文取图的操作与工具

"从论文里截"的标准动作（已封装到 `tools/python/fetch-figures.py`）：

```bash
# 1) 登记素材（自动解析许可/图源/下载原图 → assets/questions/<id>/fig1.<png|jpg|webp|gif|svg> + image.json，保留原格式）
python3 tools/python/fetch-figures.py stage --qid <题id> --pmcid PMCxxxxx --figure 2 [--panel A] [--caption "图题"]
#    许可不合规（无法识别 OA/CC）时脚本直接拒绝，必须显式 --license 兜底；
# 2) 挂接到单题文件（须先有 data/questions/**/<id>.json）
python3 tools/python/fetch-figures.py attach --qid <题id>
# 3) 一步到位 = fetch；占比核算 = coverage；许可查证 = license --pmcid PMCxxxxx
```

- 裁剪：`--crop 宽,高,x,y`（可选，需 Pillow）裁出单一 panel（如 Fig.2A）；
- 支持格式：**png / jpg / webp / gif / svg**（保留原格式，不强制转 webp；svg 适合图标/示意图）。

### 13.4 image 字段 schema（挂在单题 JSON 上）

```json
"image": {
  "file": "assets/questions/M4-01-1cdf6e6e0193/fig1.png",
  "caption": "孟德尔豌豆杂交 F₂ 性状分离示意（改绘自 OA 论文）",
  "source": "paper",
  "doi": "10.7554/eLife.109979",
  "pmcId": "PMC13313686",
  "figure": "Fig. 1",
  "license": "CC BY 4.0",
  "credit": "Figure 1, © 作者（期刊名）；有修改，CC BY 4.0"
}
```

- `source ∈ paper | book | repo | original`；自绘示意图 `source: original`，**不得谎称论文图**；
- `verify`（rebuild-bank-perid.py）会检查 `image.file` 是否真实存在于 `assets/questions/<id>/`（缺失 → R8）；
- **前端渲染**：`loader.js` 的 `_normalizeQuestion` 会把 `image.file` 映射到 `chart` 字段；`utils.js` 新增 `isChartImageSrc`（挂 `window.BioQuest`），`renderChart` 据此支持本地相对路径与 png/jpg/jpeg/webp/gif/svg 渲染（不再只认 data URI / http(s)）。

### 13.5 挂接与违规处置

- 流程：图入 `assets/questions/<id>/` → 单题 JSON 写 `image` → `build --per-id-only` 刷新 id大全 → 双人核对图片与考点匹配；
- 违规：伪造出处/无许可 → R2 判 D；文件缺失/字段不全 → R8；图片与考点不匹配 → 扣 D1/D2 并限期更换；
- 过渡期（v1.1）：主库真实图覆盖尚不足 30% 属已知缺口；补齐节奏 = 新题 ≥ 50% 带图 + 存量题按考点重要性补图，达标判定 = `coverage` 输出 ≥ 30%。
