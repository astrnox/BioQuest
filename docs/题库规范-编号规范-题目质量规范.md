## 一、题库规范

### 1.1 存储模式（v1.1：per-id 单题文件 + id大全）

题库自 v1.1 起从"一主题一个 JSON"迁移为"**一题一文件 + id大全索引**"，满足按考点/难度按需加载、单题追溯与 diff 审计。

| 层级 | 说明 | 性质 |
|---|---|---|
| `data/questions/<tag>/<difficulty>/<id>.json` | 规范单题文件，**唯一真源** | 仅此处手改 |
| `data/questions/id-all.json` | id大全：全库筛选索引 | 脚本再生，禁止手改 |
| `data/bank/<tag>.json` | 兼容产物：整主题合并题集（旧前端 loader 读取） | 脚本再生，禁止手改 |
| `data/index/<tag>.json` | 轻量索引：id → {src, tags, diff, module, ...}，loader 交叉核对用 | 脚本再生，禁止手改 |
| `data/manifest.json` | rev+1 + files 的 SHA-256 全量重算 + total/topics.count | 脚本再生 |
| `assets/questions/<id>/` | 题目配图（fig1.* + image.json 溯源） | 手写，见图片规则 |

### 1.2 目录结构标准

```
data/
  questions/                      # 规范单题文件（真源，仅此处手改）
    <tag>/                        # 考点目录（80 个，与 data/bank/<tag>.json 同名）
      <difficulty>/               # high_school | league
        <id>.json                 # 一题一文件，内容 = 该题完整对象（不含 id 字段）
    id-all.json                   # ① id大全：全库筛选索引
  bank/<tag>.json                 # 兼容产物：整主题合并题集
  index/<tag>.json                # 兼容产物：轻量索引
  manifest.json                   # rev+1 + SHA-256 全量重算
assets/
  questions/<id>/                 # 该题配图（fig1.* + image.json 溯源）
```

### 1.3 四件套一致（索引同步，R8 强制执行）

`data/questions/<tag>/<difficulty>/<id>.json`（真源）↔ `data/questions/id-all.json`（id大全）↔ `data/bank/<tag>.json`（兼容合并）↔ `data/index/<tag>.json`（轻量索引）四者题目集合必须一致。批量增删后运行 `rebuild-bank-perid.py build` 再生四件套并跑 `verify`，**禁止手工单改**。

### 1.4 提交与修改纪律

1. **备份先行**：批量编辑前备份真源：`cp -r data/questions /tmp/questions-backup-<date>`；
2. **答案审计同步**：改动 `answer` 必须留"前后值 + 依据"记录（见质量规范 R1 与评分卡），双人确认；
3. **原子化流程**：编辑 questions 目录 → 跑 `build --per-id-only` → 跑 `verify`（errors=0 才提交）→ 复核 answer diff 清单；
4. **id 命名**：沿用内容寻址 id（如 `M4-15-d6e03be35bca`），见"编号规范"；
5. **manifest**：`rev` +1、`updated_at` 更新、四类文件 SHA-256 全量重算（脚本自动完成）；
6. **批量导入旧格式**：先恢复 `data/bank/<tag>.json` 形态的整卷文件，再 `build --from-bank` 自动迁移成 `data/questions/`。

### 1.5 图片存储规范

- 图片以**独立文件**存放于 `assets/questions/<id>/`（本地、根相对路径、保留原格式 png/jpg/webp/gif/svg），浏览器静态缓存友好、可按 id 懒加载；
- 单题 JSON 只存 `image` 元数据（`file/caption/source/doi/pmcId/figure/license/credit`），由 `loader._normalizeQuestion` 映射到 `chart` 字段渲染；
- `manifest.json` 仅对 `data/` 数据分片做 SHA 完整性与去重核算；`assets/` 属静态资源，不入清单；
- **图文排版顺序**：题干 → 图（renderChart）→ 选项列表；图水平居中、`max-width:100%` + `max-height:min(60vh,560px)` + `object-fit:contain`；移动端 60vh 上限，加载失败由 `data-chart-fallback` 兜底。

### 1.6 题库目标

- 将题库从"占位演示数据"（README 声明）升级为"**可直接用于全国中学生生物学联赛命题**"的水平；
- 全库带图题占比 **≥ 30%**，且图片必须真实有效（取自论文原文/授权素材）；
- 保持与 2024–2026 生物学进展同步（顶刊出题通道）。

## 二、编号规范

### 2.1 题目 ID 编号规则（核心）

```
M{模块}-{主题序号}-{8位hex}
```

- 模块：`M1`~`M4`（见 2.2）；
- 主题序号：该主题在库内的顺序编号（如 `01`、`02`、`15`）；
- hex：**取规范内容 sha256 的前 8 位**，保证内容寻址、全局唯一；
- 示例：`M4-15-d6e03be35bca`、`M1-02-30bbc833`、`M4-01-1cdf6e6e0193`；
- 要求：**全局唯一**；重复/缺失 → 判 R8（数据格式损坏 → 删）。

> 新题骨架命令：`python3 tools/python/rebuild-bank-perid.py new --tag <考点> --difficulty <档> --id M{模块}-{主题序号}-{8位hex}`

### 2.2 模块划分（`module_1` ~ `module_4`）

| 模块 | 范围（示意） |
|---|---|
| module_1 | 细胞生物学 / 分子生物学 / 生物化学 |
| module_2 | 植物生理 / 植物学 / 微生物与生物技术 |
| module_3 | 动物生理 / 动物学 / 生态学 |
| module_4 | 遗传学 / 进化 / 生物信息学（现代生物技术） |

- `tags` 字段中必须含模块标记，格式 `module_{1..4}`；脚本 `module_of(tags)` 按正则 `^module[_]?(\d+)$` 解析；
- 联赛考纲八模块归类口径：细胞/生化/植物/动物/遗传/进化/生态（含微生物生态）/微生物-免疫-生物技术。

### 2.3 主题 tag 命名

- 考点目录 `data/questions/<tag>/` 与 `data/bank/<tag>.json` **同名**（共 80 个主题，如 `mendel`、`rna_biology`、`genomics_comp`、`plant_stress`）；
- tags 字段 ≥ 2 项：主题标识 + `module_{1..4}` + subject + 概念词；与 index 保持一致。

### 2.4 题型 type 编号

| 值 | 含义 | 状态 |
|---|---|---|
| `mtf` | Multi-true-false 多重判断（A/B/C/D 每项独立判 T/F） | **当前唯一合法值** |
| `mcq`/`fft` 等 | 单选/填空等 | 未来扩展需先更新规则 |

### 2.5 难度与目标档位（字段级强制）

| 字段 | 允许值 | 一致性要求 |
|---|---|---|
| `difficulty` | `high_school`（高考档）｜`league`（联赛档） | 错配 → R11 |
| `target` | `high_school` ｜ `competition` | 与 difficulty 语义一致（league→competition），矛盾 → R11 |

### 2.6 选项编号 label

- `subQuestions` 恰 4 项，label **连续 A→D**（A/B/C/D）；项数 ≠ 4 或 label 不连续 → R8；
- 解析必须逐项以 `A【对】…/B【错】…` 开头覆盖 A–D（质量规范 D4/R3）；
- mtf 四选项题**正确项 = 1–3 个**；全对（0 false）或全错（0 true）判违规 → R5。

### 2.7 id大全（`data/questions/id-all.json`）schema

```json
{
  "_meta": { "generated_at": "2026-08-29", "total": 400, "schema_version": 1 },
  "questions": {
    "M4-01-1cdf6e6e0193": {
      "tag": "mendel", "difficulty": "league", "target": "competition",
      "subject": "遗传学", "concept": "分离定律", "type": "mtf",
      "len": 151, "has_image": false, "file": "mendel/league/M4-01-1cdf6e6e0193.json"
    }
  }
}
```

- 前端按 `tag` + `difficulty` 过滤出 id 列表后，仅加载 `file` 指向的单题文件；
- CI/脚本用 `total`、`has_image` 做去重与带图占比核算。

### 2.8 其他编号/标识要求

- 数据库（Supabase）题 id：`row.get("id", f"bio_{int(time.time()*1000)}")`（review-questions.py 兜底默认值）；
- 图片文件：`assets/questions/<id>/fig1.<png|jpg|webp|gif|svg>`；
- 反馈定位："专项练习 · 遗传 → 第 8 题"（[question_error.yml](file:///workspace/.github/ISSUE_TEMPLATE/question_error.yml) 出错位置需带题号或链接）；
- id 与 index 文件不一致 → R8 判 D。

## 三、题目质量规范

### 3.1 字段级验收清单（单题对象逐字段）

| 字段 | 验收标准 | 违反处置 |
|---|---|---|
| `id`（对象 key） | 全局唯一，格式 `M{模块}-{主题序号}-{8位hex}` | 重复/缺失 → R8 判 D |
| `type` | `"mtf"`（当前唯一合法值） | 非法值 → R8 |
| `question` | 题干 15–80 字，情境自足 | < 15 字 → R8；空 → R8 |
| `subQuestions` | 恰 4 项，label 连续 A–D，每项含 `text`（≥ 8 字）与 `answer`(bool)；正确项 1–3 个 | 项数≠4 → R8；正确答案数违规 → R5 |
| `explanation` | 逐项"A【对】…/B【错】…"覆盖 A–D，单项 20–60 字、整题 120–320 字，无占位符 | 占位符/空 → R3 |
| `subject` | 学科门类（细胞生物学/遗传学/生态学/植物学/动物学/微生物学/免疫学/生物化学/生物信息学等） | 缺失 → R8 |
| `concept` | 具体到考点（如"分离定律""基因互作"），不与题干重复堆词 | 空/与题干重复 → 扣 D2 |
| `difficulty` | `high_school`（高考档）或 `league`（联赛档） | 错配 → R11 |
| `target` | `high_school` 或 `competition`；与 difficulty 语义一致（league→competition） | 矛盾 → R11 |
| `tags` | ≥ 2 项：主题标识 + `module_{1..4}` + subject + 概念词；与 index 一致 | 缺主题/模块 → R8；index 不一致 → 扣 D8 |
| `references` | 见 D7 与引用格式（3.8）；S/A 级必填 | 造假 → R4 |
| `image`（可选） | `{file,caption,source,doi,pmcId,figure,license,credit}` 字段齐全；文件真实存在；许可明确 | 字段缺失 → R8；伪造/盗链/无许可 → R2 |

### 3.2 自动校验链（格式与硬伤拦截器，先于人工打分）

`review-questions.py` + `server.py` 五重校验，**不过不进入打分**：

1. **scientific_sanity_check**（科学事实校验）
2. **proposition_rule_check**（命题规则校验）
3. **distractor_quality_check**（干扰项质量校验）
4. **dedup_check**（与已有题相似度 > 0.88 去重）
5. **self_check**（双模型自检，DeepSeek 671B 温度 0.3：单选一致才过；mtf 逐选项输出判定，≥ 3/4 一致才过）

> 红线提醒①：自动校验通过 ≠ 质量合格。占位解析（"正确答案：A。详细解析请参见相关教材。"）能过字长校验，但按规则直接判 C/D。
> 红线提醒②（v1.1 强制）**答案审计**：自动校验只查"答案结构"，**不查"答案对错"**；写/改解析前必须先逐选项核对标答符合公认科学结论，解析只能基于审计后的正确标答。

### 3.3 自动校验的具体阈值（server.py 实现）

| 校验项 | 规则 | 阈值/判定 |
|---|---|---|
| 题干长度 | `len(stem) < 15` | 判失败（过短） |
| 解析覆盖 | 解析文本须包含 A/B/C/D（竞赛题强制） | 缺任一字母 → 失败 |
| 解析长度 | 高考题 ≥ 100 字；竞赛题 ≥ 120 字 | 低于 → 失败 |
| 题干模板化 | 高考题禁"某种/某生物"等模糊开头，禁"科学家们经常…" | 命中 → 失败 |
| 选项包含关系 | 两个选项 > 10 字且互为子串（一处含另一处） | 命中 → 失败 |
| 无效选项 | 禁"以上都对/以上都错/以上均对/以上均错/无法确定/以上皆是/以上皆非" | 命中 → 失败 |
| 干扰项长度 | 正确项与错误项平均长度差异相对 > 3.5 倍 | 疑似一眼可辨 → 失败 |
| 干扰项相似度（非高考题） | 正确/错误项平均相似度 < 0.03 | 风马牛不相及 → 失败 |
| 干扰项术语 | 错误项无有效学科术语（去停用词后为空）且无图 | 失败 |
| 去重 | 与已有题干 `SequenceMatcher` 相似度 > 0.88 | 判重丢弃 |
| 自检 | 单选：模型作答 == 标答；mtf：≥3/4 选项一致 | 不一致 → 失败 |

### 3.4 红牌一票否决项（R1–R12，命中即判 D，双人确认）

| 编号 | 名称 | 要点 |
|---|---|---|
| R1 | 科学事实错误 | 与公认结论相悖；**含"标答本身就是错的"**（须人工答案审计）；数据/数值必须复核 |
| R2 | 抄袭与版权违规 | 直接抄录真题/教辅/论文原文；真题 PDF 仅作风格对照；论文图需 OA/CC/已授权 |
| R3 | 占位/空壳解析 | "正确答案：A。详细解析请参见相关教材。"、解析为空、只列答案不解释 |
| R4 | 参考文献造假/无法核验 | DOI 无法解析、元数据不符、AI 幻觉引用（有引用就必须真实） |
| R5 | 选项设置违规 | "以上都对/都不对/无法确定"；正确叙述故意标 false 凑项；正确项非 1–3 个；选项互为包含/同义重复 |
| R6 | 歧义双解 | 双人独立读题，判读不一致且无法改措辞消除 |
| R7 | 语义重复 | 相似度 > 0.88 或题干 8-gram 重叠率 > 70%（不同题型间不算） |
| R8 | 数据格式损坏 | 缺字段、subQuestions 不足 4 项、label 不连续、answer 非布尔、JSON 解析失败、id 重复/inconsistent |
| R9 | 内容违禁 | 政治敏感、诱导作弊、人身攻击、歧视、成人/暴力、危害健康的不实医学信息 |
| R10 | 超纲灌水 | 超出联赛考纲且非前沿题（无顶刊出处支撑）的冷门堆叠 |
| R11 | 难度与目标严重错配 | league 档纯识记；target 与 difficulty 矛盾 |
| R12 | 引导式/暗示式选项 | 语气标记帮猜答案；题干暗示答案（唯一明显正确/长选项带数字等） |

> 处置补充：命中 R1/R3 等可通过"先 D 下线 → 修正标答与解析 → 走 C 流程复活"保留考点，修复后按新分定级。

### 3.5 八维质量评分（D1–D8）

记分公式：`总分 = D1×25% + D2×15% + D3×15% + D4×15% + D5×10% + D6×10% + D7×5% + D8×5%`（各维度满分 100）。

| 维度 | 权重 | 核心问题 | 关键锚点（100 分档） |
|---|---|---|---|
| D1 科学正确性 | 25% | 科学事实是否成立、表述是否严谨 | 事实精确无瑕疵；机制因果正确；数值准确；以偏概全扣分；明确错误 → 0 分命中 R1 |
| D2 命题规范/题干 | 15% | 题干自足、指向明确、联赛语境规范 | 好题干 = [限定情境] + [考察操作/机制] + [设问动词]；题干 15–80 字；实验题给全条件 |
| D3 选项与干扰项 | 15% | 四陈述同构、独立、均具信息量；干扰项基于真实误区 | "三真一假"设计：漏条件/层次错配/因果倒置/特例普遍化；选项单项 8–60 字，最长/最短 ≤ 2.5 倍 |
| D4 解析质量 | 15% | 逐项说明"为什么对/错"、长度适中、有依据、能教学 | 每项 `A【对】…/B【错】…` + 理由，单项 20–60 字、整题 120–320 字；有推导；有出处 |
| D5 难度与区分度 | 10% | 联赛卷中难度位置对不对、能否拉开分 | 预判正确率 0.35–0.75；≥ 理解档（识记 < 应用 < 分析 < 综合）；样本 ≥30 后实测 >0.9 过易、<0.2 过难 |
| D6 新颖性与前沿性 | 10% | 是否"老题换皮"、有没有带出新东西 | 基于近三年顶刊核心发现改编（金标要件）；新情境+新数据；仅换数字/换名词 = 换皮（40） |
| D7 可溯源性/引用 | 5% | 考点与解析有无出处可查 | references 非空 + DOI 核验有效；无引用可用教材页码替代；出处含糊 → 40；造假 → R4 |
| D8 唯一性/去重 | 5% | 库内是否已有语义等价题 | 相似度 < 0.85、8-gram 重叠 < 60%；0.85–0.88 临界需说明差异；> 0.88 → R7 |

### 3.6 题目分级与去留判定

| 等级 | 含义 | 条件 | 动作 |
|---|---|---|---|
| S 金标 | 顶刊原文改编 + 双重复核 + 总分 ≥ 90 | 命中金标要件 | 上架 + `premium` 标记，优先联赛/竞赛轮 |
| A 优质 | 无红牌，解析与引用完整 | 总分 80–89 | 上架 |
| B 合格可修 | 仅轻微瑕疵 | 总分 70–79，无红牌 | 上架，登记必改项，1 个月内补齐升 A |
| C 待重修 | 有硬伤但不触红牌 | 总分 60–69 | 下架全题重写，重走一审-复核 |
| D 淘汰 | 触犯红牌或总分不达标 | 总分 < 60 或命中 R1–R12 | 删除单题文件、id大全条目，脚本再生 |

### 3.7 联赛适配性核验清单（league/competition 上架前逐项过）

- [ ] 知识范围：可归入联赛八模块之一；前沿题须有顶刊白名单出处；
- [ ] 设问层级 ≥ 理解档；纯识记题下沉 `high_school`；
- [ ] 信息自足：关掉课本也能作答，关键限定（时期/物种/条件）齐全；
- [ ] 选项纪律：正确项 1–3 个，无"以上全对"，选项同构同质；
- [ ] 答案确定性：双人独立判读一致，无 R6 双解；
- [ ] 解析教学性：讲清"为什么错"（错因）而非只给结论；
- [ ] 区分度预判：会做者 35%–75%；10 秒内可排除的选项 ≤ 25%；
- [ ] 卷面分布：连续 10 道新题正确答案分布不一（避免 2/2 规律、避免正确项偏 C）；
- [ ] 无版权/抄袭：与真题、教辅、论文原文无 8 连词重叠（R2 通过）；
- [ ] 引用真实：DOI 全部核验通过（R4 通过）；
- [ ] 索引一致：四源一致（R8 通过）；
- [ ] 图片适配：带图题图片真实、许可合规、与考点匹配（全库 ≥30%）。

### 3.8 参考文献格式与版权红线

```json
"references": [
  { "doi": "10.1016/j.cell.2018.03.006", "title": "Metazoan MicroRNAs",
    "authors": "Bartel DP", "year": 2018, "journal": "Cell" }
]
```

- **真实性核验**：DOI 前缀与期刊匹配（`10.1038/*` Nature 系、`10.1126/*` Science 系、`10.1016/*` Cell/Elsevier 系）；去 doi.org 解析 301 成功且元数据标题一致 → 通过；
- **版权红线**：论文图表须改画示意或取得许可；题干/选项/解析全部转述改写，禁止大段直译；任何一段与原文 8 连词重叠即视为抄袭风险（R2）；
- **引用时效**：主刊/子刊近 3 年（2023-01 之后）可走金标通道；综述近 5 年可入但须落到具体机制；超过时效降级为普通 A/B。

### 3.9 图片规则（≥30% 真实有效）

- 全库带图占比 ≥ 30%（按 id大全 `has_image` 统计，命令 `python3 tools/python/fetch-figures.py coverage`）；
- 图源白名单：OA 论文配图（CC BY / CC BY-NC / CC BY-SA / CC0 / 公有领域，如 PMC/PLoS/eLife/BMC/Frontiers/MDPI）、已授权教材/机构图库、仓库已授权真实照片；
- 禁止：AI 生成图冒充论文图、占位图/纯色块、无许可盗搬、盗链外站（必须本地文件）、分辨率过低（宽 < 640px）；
- `image` 字段：`source ∈ paper|book|repo|original`；自绘示意图 `source: original`，不得谎称论文图；
- 违规处置：伪造出处/无许可 → R2 判 D；文件缺失/字段不全 → R8；图片与考点不匹配 → 扣 D1/D2 并限期更换；
- 过渡期节奏：新题 ≥ 50% 带图 + 存量按考点重要性补图，`coverage` ≥ 30% 判定达标。

### 3.10 审题流程与复检机制

**单人初审（一审）**：① 自动校验链五重校验不过 → 修/删；② 过 12 条红牌；③ 八维打分填评分卡；④ 出具可执行修改建议。

**双人复核（终审）**：审题人 ≥ 2；**S 级与 D 级必须双人确认**（D 级删除留 id 清单便于恢复）；两卡差异 ≥ 10 分或跨档 → 第三人仲裁；复核重点 R1/R2/R4/R6。

**学生反馈闭环（数据驱动）**：
- 样本 ≥ 30 且 `fb_bad/(fb_good+fb_bad) > 40%` → 强制复检（优先查 R1/R6）；
- 正确率 > 0.9 → 复核 difficulty 是否虚高（D5）；正确率 < 0.2 → 复核超纲/歧义（R6/R10）；
- 错误反馈走 GitHub issue 模板（[question_error.yml](file:///workspace/.github/ISSUE_TEMPLATE/question_error.yml): 出错位置 + 当前错误 + 正确答案 + 参考资料），月度合并复审。

**定期全量复审**：季度随机 20%（等级有效性）、半年 S 级与 references 非空题（引用时效/前沿性）、每年全量（按最新考纲+顶刊进展重判）。
