§1 蓝藻门 Cyanobacteria

原核光合生物——藻类中最原始、唯一能固氮的门类

蓝藻又称蓝细菌(Cyanobacteria),是藻类植物中最原始的类群。核心特征:

  1. 原核生物:无真正的细胞核(只有拟核/核区),无核膜核仁;无膜包被的细胞器(无线粒体、叶绿体、内质网等)
  2. 光合色素:叶绿素 a + 藻蓝素(含藻蓝素和少量藻红素),因藻蓝素含量高而显蓝绿色
  3. 仅有叶绿素 a,无叶绿素 b——这是蓝藻与绿藻的关键区别之一
  4. 细胞壁:含肽聚糖(与革兰氏阴性菌相似,真核藻类才含纤维素+果胶质),部分种类外有胶质鞘
  5. 光合作用场所:无叶绿体,光合片层(类囊体)散布于细胞质中
  6. 贮藏物:蓝藻颗粒体(蓝藻淀粉),分布在光合片层表面

蓝藻约 2000 余种,广泛分布于淡水、海水、湿地、土壤,部分种类耐高温(温泉)。

💡 奥赛高频辨析:蓝藻是原核而非真核!虽然能进行光合作用,但无叶绿体、无真正细胞核。光合色素只有叶绿素a(无叶绿素b),与绿藻区别开。蓝藻是地球上最古老的光合生物之一(化石可追溯到35亿年前)。

1.1 异形胞——蓝藻的标志性结构

异形胞(heterocyst)是部分丝状蓝藻(如念珠藻、项圈藻)营养细胞特化而成的特殊细胞,是蓝藻分类和生态的重要标志。

异形胞的功能:

  • 固氮:异形胞内含固氮酶(nitrogenase),能将空气中 N₂ 还原为 NH₃ → 这是蓝藻特有的固氮能力
  • 繁殖:丝状体常在异形胞处断裂形成藻殖段,进行营养繁殖

异形胞的结构特点(适应固氮酶的厌氧需求):

  • 细胞壁加厚(含糖脂层),阻挡氧气进入 → 营造厌氧微环境
  • 无光合系统Ⅱ(PSⅡ)→ 不释放氧气(固氮酶遇氧失活)
  • 仍保留光合系统Ⅰ(PSⅠ)→ 可进行循环光合磷酸化提供 ATP
  • 细胞内透明,颜色较浅(藻蓝素含量低)
💡 异形胞是奥赛必考结构!记三个关键词:①固氮酶 ②厌氧环境(壁加厚+无PSⅡ) ③藻殖段断裂处。注意:固氮酶对氧气极度敏感,所以异形胞必须营造厌氧环境——这是结构与功能统一的经典案例。

1.3 繁殖方式

蓝藻无有性生殖,繁殖方式简单:

  • 营养繁殖:藻殖段(hormogonium)——丝状体在异形胞处或死细胞处断裂,每段可长成新个体。单细胞种类靠二分裂
  • 无性生殖:形成厚垣孢子(akinete)——由营养细胞增大、壁加厚、贮藏物增多形成,抗逆性强,条件适宜时萌发为新个体
念珠藻繁殖流程
丝状体(n)→ 异形胞处断裂→ 藻殖段(n)→ 长成新丝状体(n)
营养细胞增大壁加厚→ 厚垣孢子(n)→ 萌发新个体(n)
💡 蓝藻全生活史均为单倍体(n),无世代交替、无核相交替(无有性生殖则无减数分裂)。藻殖段在异形胞处断裂是关键记忆点。

📌 蓝藻门竞赛要点速记:

  1. 原核:无真正细胞核,无叶绿体等膜性细胞器
  2. 光合色素:仅叶绿素a + 藻蓝素(无叶绿素b、c、d)
  3. 固氮:异形胞含固氮酶,是唯一能固氮的藻类门类
  4. 繁殖:藻殖段(营养)+ 厚垣孢子(无性),无有性生殖
  5. 代表:念珠藻、发菜、微囊藻(水华)、项圈藻(与满江红共生)
§2 绿藻门 Chlorophyta

高等植物的祖先——色素与贮藏物与陆生植物完全相同

绿藻门是藻类中种类最多、与高等植物亲缘关系最近的类群,被认为是高等植物的祖先。核心特征:

  1. 真核生物:有完整的细胞核和膜性细胞器
  2. 光合色素:叶绿素 a + b + β-胡萝卜素 + 叶黄素——与高等植物完全相同
  3. 贮藏物:淀粉——与高等植物完全相同(在色素体中形成淀粉核)
  4. 载色体(叶绿体)形态多样:杯状、带状、片状、星状、网状等
  5. 细胞壁:纤维素 + 果胶质(与高等植物相同)
  6. 鞭毛:多数为2条等长尾鞭型鞭毛(顶生),部分无鞭毛

绿藻约 7000 余种,淡水为主,也有海生和陆生。从单细胞到多细胞均有,展示了从简单到复杂的演化趋势。

💡 绿藻是高等植物的祖先——这是奥赛必考结论!两条铁证:①光合色素完全相同(叶绿素a+b);②贮藏物完全相同(淀粉)。苔藓起源的"绿藻起源说"正是基于此。记住:绿藻→苔藓→高等植物的演化线索。

2.1 衣藻 Chlamydomonas——单细胞绿藻代表

衣藻:绿藻门、衣藻属,典型的单细胞游动绿藻,是研究最透彻的模式绿藻。

细胞结构:

  • 形态:卵形或球形,前端有2条等长鞭毛
  • 色素体:大型杯状色素体(chloroplast),占细胞大部分
  • 淀粉核(造粉核):1个,埋在色素体基部,为蛋白质鞘包围
  • 鞭毛:2条等长鞭毛(顶生,尾鞭型),运动器官
  • 眼点:位于前端,含类胡萝卜素,感光(趋光性)
  • 伸缩泡:2个,位于前端鞭毛基部,调节渗透压
  • 细胞核:1个,位于杯状色素体凹陷处

繁殖方式:

  • 无性生殖:原生质体分裂 → 2/4/8/16 个游动孢子(zoospore,具鞭毛)→ 脱离母壁 → 新衣藻
  • 有性生殖:原生质体分裂 → 配子(与游动孢子形态相似,但数量多、体积小)→ 同配生殖(isogamy,两配子大小形态相同)→ 合子 → 厚壁 → 减数分裂 → 4个游动孢子 → 新衣藻
💡 衣藻结构口诀:"杯状色素体+淀粉核+2鞭毛+眼点+伸缩泡"。有性生殖为同配生殖(两配子大小形态相同),这是最原始的有性生殖方式。注意:配子和游动孢子形态相似,区别在数量和体积。
衣藻生活史(只有一种单倍体植物,合子减数分裂)
衣藻(n) 配子体→ 分裂产生配子(n)+ 分裂产生游动孢子(n)
配子(n) + 配子(n)→ 合子(2n) [唯一二倍体阶段]→ 减数分裂→ 4个游动孢子(n)→ 新衣藻(n)

2.2 水绵 Spirogyra——接合生殖代表

水绵:绿藻门、水绵属,典型的不分枝丝状体绿藻,常见于淡水池塘。

细胞结构:

  • 形态:不分枝的丝状体,由一列圆柱形细胞组成,外有胶质层滑腻
  • 载色体:螺旋形带状载色体(1至多条,螺旋盘绕于细胞内壁)——水绵的标志性特征
  • 造粉核:一列,沿载色体中央排列
  • 细胞核:1个,悬于细胞中央(由原生质丝牵引)
  • 无鞭毛(全生活史中均无游动细胞)

有性生殖——接合生殖(conjugation):

  • 梯形接合:两条平行丝状体相邻细胞产生接合管,互相连通;一条丝的细胞内含物(雄配子)通过接合管流入另一条丝的细胞(雌配子)→ 融合形成合子(接合子)。两条丝状体如梯子状
  • 侧面接合:同一条丝状体相邻细胞侧面产生接合管,雄配子流入雌配子 → 合子
  • 合子:厚壁,有花纹;休眠后减数分裂 → 4核(3退化1存活)→ 萌发为新水绵

水绵的接合生殖属于特殊的同配生殖(两配子形态不同,有能动与不动之分,实为异配过渡类型)。

💡 水绵的识别标志 = 螺旋形带状载色体!"水绵"的滑腻感来自胶质层。接合生殖是无鞭毛绿藻特有的有性生殖方式,配子不游动而是通过接合管流动。梯形接合形成"梯子状"外观是经典识别点。

2.3 轮藻 Chara——形态最复杂的绿藻

轮藻:绿藻门(或独立为轮藻门),轮藻属,是绿藻中形态最复杂的类群。

孢子体结构:

  • 有节和节间分化:节部着生轮生短枝(似轮状,故名"轮藻"),节间由中央大细胞和外围皮层细胞组成
  • 假根:基部有假根固着底泥
  • 形态似被子植物(有茎、叶分化雏形),但无维管组织

有性生殖——卵式生殖(oogamy):

  • 卵囊(藏卵器):椭圆形,由5条螺旋管细胞包被,顶端有冠细胞;内含1个卵细胞(♀)
  • 精子囊(藏精器):球形,由8个盾形细胞组成,内产生双鞭毛精子(♂)
  • 受精:精子游入卵囊与卵结合 → 合子 → 减数分裂 → 原丝体 → 新轮藻
💡 轮藻是绿藻中有性生殖最进化的——已达到卵式生殖(精卵明显分化)。有节和节间分化、有卵囊精子囊结构,与高等植物形态最接近。但无维管组织,仍属藻类。

2.4 绿藻门生活史类型与竞赛要点

衣藻、水绵、轮藻三者的生活史均属于只有一种单倍体植物的生活史(合子减数分裂型):

  • 植物体始终是单倍体(n)
  • 唯一二倍体阶段是合子(2n)
  • 减数分裂发生在合子萌发时(合子减数分裂/zygotic meiosis)
  • 无世代交替(只有一种植物体),仅有核相交替(n ⇌ 2n)

有性生殖演化趋势:衣藻(同配)→ 水绵(接合,过渡型)→ 轮藻(卵式)——体现了从同配到卵式的演化方向。

💡 "只有一种单倍体植物的生活史" = 合子减数分裂型。三个代表:衣藻、水绵、轮藻。要点:植物体n、合子2n、减数分裂在合子萌发。无世代交替!这与褐藻的"异形世代交替"形成对比。
§3 硅藻门 Bacillariophyta

硅质细胞壁的金褐色藻类——复大孢子恢复细胞大小

硅藻是单细胞藻类,种类极多(约16000种),广泛分布于淡水和海水,是海洋初级生产的主力。核心特征:

  1. 单细胞(少数连成群体),微小(几μm至几百μm)
  2. 细胞壁(硅质果胶质):上壳 + 下壳——像培养皿一样套合
  3. 壳面有花纹:辐射状对称(中心硅藻)或两侧对称(羽纹硅藻),精美对称,可用于分类鉴定
  4. 光合色素:叶绿素a + c + β-胡萝卜素 + 墨角藻黄素(fucoxanthin,量大,显褐色/金褐色)
  5. 贮藏物:金藻昆布糖(chrysolaminarin) + 油(不是淀粉!)
  6. 鞭毛:仅精子具鞭毛(1条),营养细胞无鞭毛
💡 硅藻的识别标志 = 硅质细胞壁(上壳+下壳) + 金褐色(墨角藻黄素)。贮藏物是金藻昆布糖+油,不是淀粉!这与绿藻(淀粉)区分。硅藻细胞壁的精细花纹被称为"海洋的宝石"。

3.1 硅藻的壳壁结构

硅藻细胞壁由两半个壳套合而成,如同培养皿:

  • 上壳(epitheca):较大,套在外面
  • 下壳(hypotheca):较小,套在里面
  • 两壳之间有壳环带(girdle band)连接

壳面观(valve view)看花纹:

  • 中心硅藻目:壳面辐射对称(圆心放射),多为浮游生活(如圆筛藻)
  • 羽纹硅藻目:壳面两侧对称(羽毛状),多为底栖生活(如舟形藻),有的有纵沟(壳缝)可运动
💡 硅藻壳壁成分 = 硅质(SiO₂)+ 果胶质(不是纤维素!)。这是硅藻区别于其他藻类的重要特征。上壳大套外面、下壳小套里面的"培养皿"结构是经典考点。

3.2 复大孢子——硅藻特有的生殖机制

细胞分裂导致子细胞变小的问题:

硅藻以细胞分裂为主要繁殖方式。分裂时,两壳分离,各壳成为新细胞的上壳,再新生一个较小的下壳。因此:

  • 接受原上壳的子细胞 → 大小不变
  • 接受原下壳的子细胞 → 变小(因为新生下壳套在里面)

如此反复分裂,子代群体中部分细胞逐渐变小。当小到一定程度(约为原大的1/3),必须通过复大孢子(auxospore)恢复大小。

复大孢子的形成(有性生殖):

  • 两个小型硅藻靠近 → 各自减数分裂产生配子
  • 配子结合 → 合子(2n) → 膨大形成复大孢子(auxospore)
  • 复大孢子分泌新的大细胞壁 → 恢复原大 → 再行分裂
硅藻细胞变小与复大孢子循环
正常大细胞(2n)→ 分裂(子细胞渐小)→ 小细胞(2n)→ 减数分裂产配子(n)
配子(n)+配子(n)→ 合子(2n)→ 复大孢子(膨胀,分泌新壁)→ 恢复大细胞(2n)
💡 复大孢子 = 有性生殖的合子!这是奥赛必考概念。硅藻生活史只有一种二倍体植物(2n),减数分裂在配子形成时(配子减数分裂/gametic meiosis)。复大孢子的功能是恢复细胞大小,本质是有性生殖的产物。

📌 硅藻门竞赛要点速记:

  1. 细胞壁:硅质(SiO₂)+ 果胶质,上壳+下壳套合,有花纹
  2. 色素:叶绿素a+c + 墨角藻黄素(褐色)
  3. 贮藏物:金藻昆布糖 + 油(非淀粉!)
  4. 复大孢子= 有性生殖的合子,功能是恢复细胞大小
  5. 生活史:只有一种二倍体植物(配子减数分裂),与松藻、鹿角菜相同
  6. 鞭毛:仅精子具鞭毛,营养细胞无鞭毛
§4 红藻门 Rhodophyta

藻胆素显红色、全生活史无鞭毛——紫菜为代表

红藻门约 4000 余种,绝大多数海生,多生于深水(红光穿透深处)。核心特征:

  1. 光合色素:叶绿素 a + d + 藻胆素(藻红素 + 藻蓝素)
  2. 藻红素含量高,掩盖叶绿素绿色 → 显红色或紫红色
  3. 贮藏物:红藻淀粉(floridean starch)——碘处理有特殊颜色反应
  4. 无鞭毛——全部生活史中均无鞭毛细胞(精子也不游动!)
  5. 细胞壁:纤维素 + 果胶质(外层果胶质含琼脂/卡拉胶,有经济价值)
💡 红藻两大必考特征:①红藻淀粉的碘反应特殊(黄褐色→葡萄红色→紫色);②全生活史无鞭毛(精子也不游动,靠水流)。藻红素使红藻能利用深水中的蓝绿光,可生于较深海区。

4.1 红藻淀粉的碘反应

红藻淀粉(floridean starch)是红藻特有的贮藏多糖,其碘反应与普通淀粉不同,是红藻的鉴别特征:

贮藏物碘液反应颜色存在类群
普通淀粉蓝色 → 蓝紫色绿藻、高等植物
红藻淀粉黄褐色 → 葡萄红色 → 紫色红藻门
褐藻淀粉(昆布糖)无颜色反应(或浅褐色)褐藻门
金藻昆布糖无颜色反应硅藻、金藻
💡 红藻淀粉碘反应:先黄褐色 → 再葡萄红色 → 最后紫色。与普通淀粉(蓝紫色)截然不同!这是区分红藻与其他藻类的化学鉴定法。

4.2 紫菜 Porphyra 的生活史

紫菜:红藻门、紫菜属,重要的食用海藻。生活史较为复杂:

无性生殖途径:

  • 紫菜叶状体(单相,n) → 产生孢子(n) → 萌发为新紫菜叶状体(n)

有性生殖途径:

  • 果胞(♀):雌性生殖器官,顶端有受精丝,内含1个卵
  • 精子(♂):由精子囊产生,无鞭毛(不游动,靠水流到达受精丝)
  • 精子 → 受精丝 → 果胞内与卵结合 → 合子(2n)
  • 合子 → 产生果孢子(2n) → 萌发为壳斑藻(丝状体,2n)(生于贝壳内)
  • 壳斑藻 → 产生孢子(n)(减数分裂)→ 萌发为紫菜叶状体(n)
紫菜生活史简图
紫菜叶状体(n)→ 孢子(n) [无性]→ 紫菜叶状体(n)
果胞♀(n)+ 精子♂(n,无鞭毛)→ 合子(2n)→ 果孢子(2n)→ 壳斑藻(2n)→ 减数分裂→孢子(n)→ 紫菜叶状体(n)
💡 紫菜生活史有两种植物体:叶状体(n,食用部分)和壳斑藻(2n,生于贝壳内)。有世代交替!注意红藻的精子无鞭毛,靠水流传播,这是红藻区别于褐藻、绿藻的重要特征。

📌 红藻门竞赛要点速记:

  1. 色素:叶绿素a+d + 藻胆素(藻红素+藻蓝素),显红色
  2. 红藻淀粉:碘反应黄褐色→葡萄红色→紫色(非蓝紫色)
  3. 无鞭毛:全生活史中均无鞭毛细胞(精子也不游动)
  4. 代表:紫菜(食用)、石花菜(琼脂原料)、江蓠
  5. 经济:琼脂(石花菜)、卡拉胶(麒麟菜)均来自红藻细胞壁
§5 褐藻门 Phaeophyta

异形世代交替的海洋巨藻——海带为代表

褐藻门约 1500 种,全部多细胞,绝大多数海生,是海洋中体型最大的藻类(如巨藻可达数十米)。核心特征:

  1. 全为多细胞(无单细胞),有组织分化
  2. 光合色素:叶绿素 a + c + 墨角藻黄素(含量大,显褐色)
  3. 贮藏物:褐藻淀粉(昆布糖,laminarin)+ 甘露醇(mannitol)
  4. 细胞壁:纤维素 + 藻胶(褐藻胶/海藻酸,有经济价值)
  5. 游动孢子/精子具侧生不等双鞭毛(一长一短,侧生)
  6. 异形世代交替:孢子体(2n)大型,配子体(n)微小
💡 褐藻与硅藻的色素相同(叶绿素a+c+墨角藻黄素),但褐藻含量更大显明显褐色。褐藻是藻类中分化程度最高的——有表皮/皮层/髓的分化,有异形世代交替。海带是最重要代表。

5.1 海带 Laminaria japonica 的孢子体结构

海带:褐藻门、海带属,大型海生褐藻,是重要的食用和经济藻类。

孢子体(2n)结构——分三部分:

  • 带片(blade):扁平叶状,光合作用主体;有表皮/皮层/髓的分化
    • 表皮:1-2层,含色素体,光合作用
    • 皮层:外围,贮藏(甘露醇、褐藻淀粉)
    • 髓:中央,有喇叭丝(筛管类似物,运输功能)
  • 带柄(stipe):圆柱形,连接带片和固着器
  • 固着器(holdfast):树根状分枝,固着于岩石基质
💡 海带孢子体三部分:带片+带柄+固着器。带片有表皮/皮层/髓分化——髓部的喇叭丝类似筛管,有输导功能,这是褐藻组织分化的高级表现。注意:固着器不是真根(无维管组织)。

5.2 海带的异形世代交替

海带生活史为典型的异形世代交替,孢子体(2n)占绝对优势:

孢子体世代(2n,无性世代):

  • 成熟的孢子体(带片)→ 表皮细胞形成孢子囊(单室)
  • 孢子囊内减数分裂 → 产生游动孢子(n)(侧生不等双鞭毛)
  • 游动孢子有雌雄之分,分别萌发为雌配子体和雄配子体

配子体世代(n,有性世代)——微小丝状体:

  • 雄配子体(n):分枝丝状体 → 产生精子囊 → 精子(n)(侧生不等双鞭毛,游动)
  • 雌配子体(n):1至几个细胞 → 产生卵囊 → 卵(n)(不游动,留在卵囊顶端)
  • 受精:精子游至卵囊 → 与卵结合 → 合子(2n)
  • 合子 → 萌发为新孢子体(2n)(大型海带)
海带异形世代交替(孢子体2n占优)
孢子体(2n)大型:带片+带柄+固着器→ 孢子囊减数分裂→ 游动孢子(n,侧生不等双鞭毛)
→雄配子体(n,微小丝状)→ 精子(n,侧生不等双鞭毛)
→雌配子体(n,微小丝状)→ 卵(n,不游动)
精子(n)+ 卵(n)→ 合子(2n)→ 新孢子体(2n,大型)
💡 海带世代交替异形:孢子体(2n)大如海带,配子体(n)仅数个细胞的丝状体——差异巨大!减数分裂在孢子囊内(孢子减数分裂/sporic meiosis)。游动孢子和精子都具侧生不等双鞭毛(一长一短),这是褐藻的标志性鞭毛类型。
比较项孢子体(2n)配子体(n)
体型大型(带片+带柄+固着器)微小丝状体(数个细胞)
独立性独立生活(光合自养)独立生活(光合自养)
繁殖孢子囊→减数分裂→游动孢子精子囊/卵囊→精子/卵
优势度占优势退化(微小)
世代无性世代有性世代

📌 褐藻门竞赛要点速记:

  1. 色素:叶绿素a+c + 墨角藻黄素(量大,显褐色)
  2. 贮藏物:褐藻淀粉(昆布糖)+ 甘露醇
  3. 鞭毛:游动孢子和精子均具侧生不等双鞭毛(一长一短)
  4. 世代交替:异形,孢子体(2n)占绝对优势
  5. 减数分裂:在孢子囊内进行(孢子减数分裂)
  6. 代表:海带、裙带菜、鹿角菜、马尾藻
§6 藻类植物总结与演化

分门依据 · 生活史三型 · 有性生殖演化 · 内共生起源

6.1 藻类的分门依据

藻类植物的分类(分门)主要依据以下特征:

  1. 光合色素的种类和比例(最关键)——叶绿素a/b/c/d、藻胆素、墨角藻黄素等
  2. 载色体(叶绿体)的形态——杯状、带状、螺旋形、星状、盘状等
  3. 贮藏物的种类——淀粉、红藻淀粉、昆布糖、金藻昆布糖、油等
  4. 细胞壁成分——纤维素、果胶质、硅质、藻胶等
  5. 鞭毛的有无、数目、着生方式(顶生/侧生)、类型(尾鞭/茸鞭)
  6. 细胞核类型——原核(蓝藻)vs 真核(其他)
  7. 生殖方式和生活史类型
门类细胞核光合色素贮藏物鞭毛代表
蓝藻门原核叶绿素a + 藻蓝素蓝藻颗粒体无念珠藻、微囊藻
绿藻门真核叶绿素a+b + β-胡萝卜素+叶黄素淀粉2等长顶生衣藻、水绵、轮藻
硅藻门真核叶绿素a+c + 墨角藻黄素金藻昆布糖+油仅精子有舟形藻、圆筛藻
红藻门真核叶绿素a+d + 藻胆素红藻淀粉全无紫菜、石花菜
褐藻门真核叶绿素a+c + 墨角藻黄素(多)褐藻淀粉+甘露醇侧生不等双鞭毛海带、鹿角菜

6.2 有性生殖的演化趋势

藻类有性生殖的演化体现了从简单到复杂、从低级到高级的方向:

有性生殖演化方向
同配生殖(isogamy)
配子大小形态相同→ 异配生殖(anisogamy)
配子大小形态不同→ 卵式生殖(oogamy)
精子小能动,卵大不动
  • 同配生殖:两配子大小、形态完全相同,难辨雌雄。代表:衣藻(部分)
  • 异配生殖:两配子形态相似但大小不同。代表:部分衣藻、团藻
  • 卵式生殖:精卵明显分化,精子小而能动,卵大而不动。代表:轮藻(绿藻最高级)、海带(褐藻)、所有高等植物

卵式生殖是最高级的有性生殖方式,高等植物和动物均采用此方式。

💡 有性生殖演化:同配→异配→卵式。这是藻类演化的主线之一。记住:衣藻=同配(原始),轮藻=卵式(高级)。海带也是卵式。高等植物全部为卵式生殖。

6.3 生活史的三种类型

藻类(及植物)的生活史根据植物体倍性和种类可分为三种类型:

类型一:只有一种单倍体植物(合子减数分裂)

  • 植物体为单倍体(n),唯一二倍体阶段是合子(2n)
  • 减数分裂发生在合子萌发时(合子减数分裂/zygotic meiosis)
  • 无世代交替(只有一种植物体),有核相交替(n ⇌ 2n)
  • 代表:衣藻、水绵、轮藻(均为绿藻)

类型二:只有一种二倍体植物(配子减数分裂)

  • 植物体为二倍体(2n),唯一单倍体阶段是配子(n)
  • 减数分裂发生在配子形成时(配子减数分裂/gametic meiosis)
  • 无世代交替(只有一种植物体),有核相交替(2n ⇌ n)
  • 代表:松藻(绿藻)、硅藻、鹿角菜(褐藻)

类型三:有两种或三种植物体(世代交替)

  • 有孢子体(2n)和配子体(n)两种植物体,均能独立生活
  • 减数分裂发生在孢子形成时(孢子减数分裂/sporic meiosis)
  • 有世代交替(两种植物体交替),也有核相交替
  • 同形世代交替:孢子体与配子体形态大小相似 → 代表:石莼(绿藻)、水云(褐藻)
  • 异形世代交替:孢子体与配子体形态大小不同 → 代表:海带(褐藻,孢子体占优)、紫菜(红藻)
💡 生活史三型是必考核心!关键区分:①合子减数分裂=只有n植物(衣藻/水绵/轮藻) ②配子减数分裂=只有2n植物(硅藻/松藻/鹿角菜) ③孢子减数分裂=世代交替(石莼同形/海带异形)。世代交替一定有两种植物体!
类型植物体减数分裂位置世代交替代表
合子减数分裂仅n合子萌发时无衣藻、水绵、轮藻
配子减数分裂仅2n配子形成时无松藻、硅藻、鹿角菜
同形世代交替n + 2n(形态相同)孢子形成时有(同形)石莼、水云
异形世代交替n + 2n(形态不同)孢子形成时有(异形)海带(孢子体占优)、紫菜

6.4 核相交替 vs 世代交替

这是两个经常混淆的概念,必须严格区分:

  • 核相交替:生活史中单倍体(n)与二倍体(2n)核相的交替。只要有性生殖就必然有核相交替(合子2n→减数分裂→n→配子→合子2n)。三种生活史类型均有核相交替
  • 世代交替:生活史中有两种(或三种)能独立生活的植物体(孢子体2n和配子体n)的交替。只有第三种类型(孢子减数分裂)才有世代交替

关键结论:有世代交替 → 一定有核相交替;但有核相交替 → 不一定有世代交替(如衣藻只有核相交替,无世代交替)。

💡 核相交替 vs 世代交替是高频易错!核相交替=有性生殖就有(减数分裂+受精);世代交替=必须有两种植物体。衣藻有核相交替但无世代交替!石莼/海带既有核相交替又有世代交替。

6.5 初级内共生 vs 次级内共生

藻类叶绿体的起源是现代生物学的重要理论,也是竞赛拓展考点:

初级内共生(Primary endosymbiosis):

  • 一个蓝细菌(原核光合生物)被原始真核生物吞噬后,未消化,演化为叶绿体
  • 叶绿体有双层膜(来自蓝细菌的内外膜)
  • 产物:绿藻、红藻、灰藻——它们的叶绿体都是初级内共生起源
  • 高等植物的叶绿体来自绿藻祖先(故色素、贮藏物与绿藻相同)

次级内共生(Secondary endosymbiosis):

  • 一个真核藻类(已有叶绿体)被另一个真核生物吞噬 → 藻类演变为叶绿体
  • 叶绿体有三层或四层膜(额外膜来自吞噬者的膜)
  • 产物:硅藻、褐藻、甲藻、隐藻、眼虫藻等
  • 部分次级内共生藻类保留了被吞噬藻类的核→核形核(nucleomorph)(如隐藻)
💡 内共生理论是联赛拓展考点!核心:绿藻/红藻=初级内共生(2层膜);硅藻/褐藻=次级内共生(3-4层膜,吞噬了红藻)。这解释了为何褐藻和硅藻含叶绿素c和墨角藻黄素——它们吞噬的可能是红藻后代。
绿藻门→陆生植物(叶绿素a+b,淀粉) • 红藻门(藻胆素,红藻淀粉,无鞭毛) • 灰胞藻门(蓝藻与红藻过渡) 特点:2层膜 ｜ 核基因组小 ｜ nucCyt基因转移 次级内共生（Secondary Endosymbiosis）——真核藻类被吞噬 第二宿主 真核细胞 异养真核生物 初级藻类 (绿藻/红藻) 已有叶绿体 吞噬 次级叶绿体 残留 ★3-4层被膜 内共生 次级谱系（多源） 绿藻来源： 眼虫藻(3膜)、绿胞藻 红藻来源： 硅藻/褐藻(4膜)、甲藻(3膜) 隐藻、定鞭藻 证据:核膜样结构(残留核)、3-4膜

6.6 真题链接与高频考点

📌 高频考点一:原核 vs 真核

  • 蓝藻是原核(无核膜、无叶绿体、无线粒体),其余藻类为真核
  • 蓝藻光合作用场所 = 光合片层(类囊体),非叶绿体
  • 蓝藻仅有叶绿素a(无叶绿素b),与绿藻区分

📌 高频考点二:固氮

  • 异形胞含固氮酶,营造厌氧环境(壁加厚+无PSⅡ)
  • 满江红(蕨类)+ 项圈藻(蓝藻)= 共生固氮
  • 水华 = 微囊藻大量繁殖

📌 高频考点三:色素与贮藏物

  • 绿藻:叶绿素a+b,淀粉(=高等植物)→ 绿藻是高等植物祖先
  • 硅藻/褐藻:叶绿素a+c+墨角藻黄素;昆布糖/金藻昆布糖
  • 红藻:叶绿素a+d+藻胆素;红藻淀粉(碘反应特殊)

📌 高频考点四:鞭毛特征

  • 绿藻:2条等长顶生鞭毛
  • 褐藻:侧生不等双鞭毛(一长一短)
  • 红藻:全生活史无鞭毛
  • 硅藻:仅精子有鞭毛

📌 高频考点五:生活史

  • 合子减数分裂(仅n):衣藻、水绵、轮藻
  • 配子减数分裂(仅2n):硅藻、松藻、鹿角菜
  • 世代交替:同形(石莼、水云)/ 异形(海带、紫菜)
  • 复大孢子 = 硅藻有性生殖的合子

📌 高频考点六:代表植物识别

  • 水绵 = 螺旋形带状载色体 + 接合生殖
  • 衣藻 = 杯状色素体 + 2鞭毛 + 眼点 + 同配
  • 轮藻 = 有节/节间 + 卵囊精子囊 + 卵式
  • 海带 = 带片+带柄+固着器 + 异形世代交替
  • 紫菜 = 红藻 + 红藻淀粉 + 无鞭毛
💡 这些是联赛/省赛反复出现的考点!特别提醒:①满江红是蕨类不是蓝藻;②复大孢子是合子不是孢子;③红藻全生活史无鞭毛;④褐藻孢子体占优(异形);⑤绿藻=高等植物祖先(色素+淀粉)。

📊 藻类植物全章总结:五大门类核心特征与演化主线

演化核心线索:从原核到真核(蓝藻→其他),从单细胞到多细胞(衣藻→水绵→轮藻→海带),从同配到卵式(衣藻→轮藻),从无世代交替到世代交替(衣藻→石莼→海带)。

门类细胞核色素(关键)贮藏物鞭毛生活史代表
蓝藻原核叶绿素a+藻蓝素蓝藻颗粒体无仅n(无有性)念珠藻/微囊藻
绿藻真核叶绿素a+b淀粉2等长顶生仅n(合子减数)衣藻/水绵/轮藻
硅藻真核叶绿素a+c+墨角藻黄素金藻昆布糖+油仅精子有仅2n(配子减数)舟形藻/圆筛藻
红藻真核叶绿素a+d+藻胆素红藻淀粉全无世代交替紫菜/石花菜
褐藻真核叶绿素a+c+墨角藻黄素昆布糖+甘露醇侧生不等双鞭毛异形世代交替海带/鹿角菜

奥赛记忆要点(6 条主线):

  1. 原核 vs 真核:蓝藻原核(无核膜叶绿体),其余真核。蓝藻仅叶绿素a,无叶绿素b
  2. 色素与贮藏物:绿藻=叶绿素a+b+淀粉(=高等植物,故为祖先);红藻=藻胆素+红藻淀粉;褐藻/硅藻=墨角藻黄素+昆布糖
  3. 鞭毛:绿藻2等长顶生;褐藻侧生不等双鞭毛;红藻全无;硅藻仅精子有
  4. 有性生殖演化:同配(衣藻)→ 异配 → 卵式(轮藻、海带、高等植物)
  5. 生活史三型:仅n合子减数(衣藻/水绵/轮藻)、仅2n配子减数(硅藻/松藻/鹿角菜)、世代交替(同形石莼/异形海带)
  6. 固氮:蓝藻异形胞(固氮酶+厌氧环境);满江红+项圈藻共生固氮

易错辨析 TOP 6:

  1. 满江红是蕨类,项圈藻才是蓝藻(共生固氮)
  2. 复大孢子是合子(有性生殖产物),不是孢子
  3. 红藻淀粉碘反应:黄褐→葡萄红→紫(非蓝紫)
  4. 红藻全生活史无鞭毛(精子也不游动)
  5. 核相交替≠世代交替:有性生殖就有核相交替,但世代交替需两种植物体
  6. 绿藻是高等植物祖先(色素+贮藏物相同),不是褐藻或红藻
内共生拓展:初级内共生(蓝细菌→叶绿体,双层膜)产生绿藻、红藻;次级内共生(吞噬真核藻类,3-4层膜)产生硅藻、褐藻等。高等植物叶绿体源自绿藻祖先,故色素(叶绿素a+b)和贮藏物(淀粉)与绿藻完全一致——这是"绿藻是高等植物祖先"的分子证据。

📌 藻类识别速记口诀:

  • 蓝藻:原核蓝绿,异形胞固氮,念珠发菜微囊藻
  • 绿藻:叶绿ab淀粉同,高等祖先记心中;衣藻杯状同配生,水绵螺旋接合宗,轮藻节间卵式精
  • 硅藻:硅质双壳花纹美,金褐墨角昆布糖;分裂渐小复大孢,有性合子恢复长
  • 红藻:藻胆素红无鞭毛,红藻淀粉碘色奇;紫菜叶状壳斑藻,世代交替两体移
  • 褐藻:墨角黄褐侧生鞭,昆布甘露海带鲜;异形世代孢占优,带片带柄固着连
