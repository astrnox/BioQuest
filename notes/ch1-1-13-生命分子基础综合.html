一、水与无机盐（讲义第一二节补充）

（一）生命物质基础

人体 25 种元素含量排序（表 1-1，讲义 P1）：

  • O 65%（最多）→ C 18.5% → H 9.5% → N 3.3% → Ca 1.5% → P 1.0%
  • 组成四大基本元素：C、H、O、N（占 96.3%）

碳原子的核心地位：碳有 4 个共价键，能形成长链、分支、环，是生物大分子的骨架。

（二）水的关键理化性质

  • 比热容 4.2 J/(g·℃)（很大）→ 调节体温
  • 蒸发热 2400 J/g（很大）→ 出汗散热
  • 水分子间形成3-4 个氢键（每个水分子 4 个 H 键，氧 2 孤对、氢 2 极性）
  • 极性分子 → 良好溶剂（"水是生命溶剂"）

（三）自由水 vs 结合水

  • 自由水（约 95%）：以游离形式存在，参与代谢
  • 结合水（约 4.5%）：与蛋白质、多糖等亲水基团结合，不流动、不参与代谢（作为结构水）

比例与代谢/抗逆性关系：

  • 自由水 / 结合水比值 ↑ → 代谢旺盛、生长快、抗逆性弱（如幼芽）
  • 自由水 / 结合水比值 ↓ → 代谢缓慢、生长慢、抗逆性强（休眠种子、越冬植物）
测定含水量方法：烘干法（直接测失水）+ 蔗糖渗透法（间接）。结合水不蒸发、不结冰、不解离、不流动，是细胞结构的组成部分（如水母含水量 95%，仍能维持形态）。

（四）无机盐的 4 大功能（讲义 P4）

  1. 合成原料：PO₄³⁻ 合成磷脂、核酸、ATP
  2. 酶/蛋白活化因子：K⁺、Ca²⁺、Mg²⁺ 等金属离子是多种酶的辅因子
  3. 维持渗透压：Na⁺、Cl⁻、K⁺ 维持体液渗透压平衡
  4. 缓冲对：
    ① 血浆：H₂CO₃ / HCO₃⁻（pH 7.35-7.45，碳酸氢盐缓冲系）
    ② 红细胞内：H₂PO₄⁻ / HPO₄²⁻（磷酸盐缓冲系）
    ③ 蛋白质 / 血红蛋白（两性）

缓冲对的作用机制：酸来 HCO₃⁻ + H⁺ → H₂CO₃ → H₂O + CO₂（呼出）；碱来 H₂CO₃ + OH⁻ → HCO₃⁻ + H₂O。

"微量元素"是奥赛常考概念，指含量 < 体重 0.01% 的元素（如 Fe、I、Cu、Mn、Zn、Co、Mo、Se、V、Ni、Cr、Sn、F、Si、As 等 15 种）。Fe 是血红素辅基中心；I 是甲状腺激素的关键元素；Se 是谷胱甘肽过氧化物酶辅因子；F 是骨/牙的成分（CaF₂）；Zn 是胰岛素结晶和 DNA 聚合酶辅因子。

二、糖类——Fischer 投影与构型

（一）单糖的 Fischer 投影（讲义 P5）

Fischer 投影是手性中心（手性碳）的二维表示法：水平键伸向纸面前方，垂直键伸向纸面后方。醛糖的最长链竖直放置，醛基（—CHO）置顶，编号从上到下。

D-甘油醛（最简单醛糖）：CHO 在顶，C2 上 OH 在右（2R 构型）。D/L 构型：最下方手性碳（编号最高的手性碳）的 OH 在右为 D 型，在左为 L 型。

碳数与糖：

  • 丙糖（3C）：D-甘油醛、二羟丙酮（DHAP）
  • 戊糖（5C）：D-核糖（RNA）、D-2-脱氧核糖（DNA）、核酮糖（光合）、木糖、L-阿拉伯糖
  • 己糖（6C）：D-葡萄糖、D-果糖、D-半乳糖、D-甘露糖
Fischer 投影 vs Haworth 透视式：Fischer 是开链的 2D 投影，Haworth 是环状的立体投影（Pyranose 6 圆环 / Furanose 5 圆环）。Haworth 中 C1 异头碳的 —OH 与 C6 的 —CH₂OH 同侧为 α 型，异侧为 β 型。变旋现象：α 和 β 在水溶液中可互变（开链过渡态）→ 平衡时比旋光度稳定。

（二）旋光性与比旋光度（讲义 P6）

平面偏振光通过含手性分子的溶液时，偏振面会旋转，旋转的角度 α 称为旋光角。

比旋光度公式：

[α]Dt = α / (c · L)
α：实测旋光角（度）；c：浓度（g/mL）；L：管长（dm）；D：钠光 D 线（589.3 nm）；t：温度

右旋（dextrorotatory, +）与左旋（levorotatory, −）：

  • D-葡萄糖：[α] = +52.7°（右旋）
  • D-果糖：[α] = −92.0°（左旋，更强）
  • D-半乳糖：[α] = +80.2°

（三）变旋现象（mutarotation）

α-D-葡萄糖（+112°）溶于水后，比旋光度逐渐下降至 +52.7°；β-D-葡萄糖（+18.7°）则上升至 +52.7°。原因是水溶液中 α 和 β 通过开链形式互变，最终达到平衡（α : β ≈ 36 : 64）。

旋光性是手性的直接表现。氨基酸的 D/L 构型根据 α-碳的 L-α 氨基/L-α 羧基判定（生物界几乎都是 L 型）。糖的 D/L 构型根据最远端手性碳的 —OH 位置判定。

（四）Lobry de Bruyn 转化（酮-烯醇互变）（讲义 P8）

在弱碱催化下，D-葡萄糖、D-果糖、D-甘露糖可通过共同的烯二醇中间体互变：

酮-烯醇互变（Lobry de Bruyn 转化）
D-葡萄糖 ⇌ 1,2-烯二醇 ⇌ D-果糖 ⇌ D-甘露糖

这 3 种糖在 C2 位互为差向异构体（epimer）。该反应是糖的碱性变旋基础，也是 Fehling 试剂检测还原糖的化学基础。

C2 差向异构：只差在 C2 一个手性碳的构型。类似地，C4 差向异构（如葡萄糖和半乳糖）也是常见。DNA/RNA 提取中常用的测序酶处理碱基也涉及烯醇互变。

（五）糖苷键与寡糖（讲义 P9-10）

两个单糖脱水形成糖苷键（glycosidic bond），方向为"半缩醛羟基（C1 异头碳）+ 其他糖的羟基（2/4/6 位）"。糖苷键按异头碳的 α/β 区分。

常见二糖：

"还原糖 vs 非还原糖"判断：含游离半缩醛羟基（异头碳）= 还原糖。蔗糖（葡萄糖 + 果糖，α,β-1,2）的两个异头碳都参与糖苷键 → 非还原糖；麦芽糖（α-1,4）、乳糖（β-1,4）保留一个异头碳 → 还原糖。

（六）多糖——同多糖（讲义 P10-11）

  • 直链淀粉（amylose）：α-Glc 1→4 直链，螺旋，遇 I₂ → 蓝色
  • 支链淀粉（amylopectin）：α-Glc 1→4 主链 + α-1,6 分支（约每 24-30 残基一分支），遇 I₂ → 红棕色
  • 糖原（glycogen）：类似支链淀粉但分支更密（每 8-12 残基一分支），遇 I₂ → 红棕色。存在于动物肝、肌肉
  • 纤维素（cellulose）：β-Glc 1→4 直链，人体无β-糖苷酶，不能消化，但提供膳食纤维
  • 壳多糖 / 几丁质（chitin）：N-乙酰-D-氨基葡萄糖 β-1,4 聚合物，昆虫外骨骼、甲壳类壳、真菌细胞壁
淀粉-碘反应机理：直链淀粉的螺旋内径恰好容纳 I₂/I₃⁻ 多碘离子 → 形成蓝色复合物。支链淀粉的螺旋短且分支频繁 → 红棕色。糖原分支最密 → 红棕色。变性淀粉的螺旋解开 → 不与碘显色。

（七）杂多糖（讲义 P12）

  • 果胶（pectin）：D-半乳糖醛酸通过 α-1,4 键连接。植物细胞壁成分。原果胶 → 果胶 → 果胶酸 → β-半乳糖醛酸
  • 糖胺聚糖（GAG）：重复二糖单位（氨基糖 + 糖醛酸），如透明质酸、硫酸软骨素、肝素、硫酸角质素
  • 琼脂：半乳糖和半乳糖醛酸聚合物（红藻细胞壁）
  • 半纤维素：木糖、甘露糖等多糖杂聚物（植物细胞壁）

（八）糖蛋白 vs 蛋白聚糖（讲义 P12-13）

  • 糖蛋白（glycoprotein）：蛋白为主，糖链为辅（糖 < 蛋白）。如红细胞膜糖蛋白（血型物质）
  • 蛋白聚糖（proteoglycan）：糖链为主（> 95%），蛋白为骨架。如软骨基质、细胞外基质
糖脂、脂多糖（LPS）也是糖结合物（详见脂质节）。糖类通过糖苷键与蛋白/脂质结合的功能：① 血型物质（ABO）；② 精卵识别（糖链是关键识别标记）；③ 补体溶细胞；④ 细胞粘附；⑤ 抗原性。

三、脂类——鞘脂、萜类与维生素 ADEK

（一）油脂的理化性质（讲义 P15）

  • 甘油三酯：1 甘油 + 3 脂肪酸 + 3 H₂O 脱去 3 分子水
  • 饱和脂肪酸：长直链，分子间紧密 → 熔点高，常温固态（动物脂肪：硬脂酸、软脂酸）
  • 不饱和脂肪酸：顺式双键使链弯曲，分子不能紧密排列 → 熔点低，常温液态（植物油：油酸、亚油酸）
  • 反式脂肪酸（部分氢化植物油）：熔点高、人体难代谢，是心血管疾病风险因素

（二）Fenton 反应（讲义 P15）

Fe²⁺ + H₂O₂ → Fe³⁺ + ·OH + OH⁻
Fenton 反应生成羟自由基 ·OH，是氧化应激的关键反应

脂质过氧化（lipid peroxidation）：·OH 攻击多不饱和脂肪酸 → 脂自由基 → 链式反应 → 损伤生物膜。

抗氧化剂（如维生素 E、谷胱甘肽、超氧化物歧化酶 SOD、过氧化氢酶）清除自由基。Fenton 反应是生物体内 ROS（活性氧）的主要来源之一，是衰老、动脉粥样硬化、神经退行性疾病的共同基础。

（三）磷脂的两亲性与 4 种排列（讲义 P16）

磷脂分子 = 极性头部（磷酸 + 胆碱/乙醇胺/丝氨酸）+ 2 条非极性烃链尾巴 → 两亲性分子（amphipathic / amphiphilic）。

在水中的 4 种排列（图 1-3-3）：

  1. 单分子层（monolayer）：在空气-水界面
  2. 微团（micelle）：浓度低时，疏水尾巴聚拢成球形内核，亲水头朝外
  3. 双分子层（bilayer）：浓度高时，两条分子尾对尾形成双层，是生物膜的基础
  4. 脂质体（liposome）：闭合双层（囊泡），可作药物载体

三种甘油磷脂：

  • 卵磷脂（PC，磷脂酰胆碱）：胆碱（—O—CH₂CH₂N⁺(CH₃)₃）
  • 脑磷脂（PE，磷脂酰乙醇胺）：乙醇胺（—O—CH₂CH₂NH₂）
  • 丝氨酸磷脂（PS）：丝氨酸（—O—CH₂CH(NH₂)COOH）
胆汁酸盐的"清洁剂"作用：胆汁酸盐是两亲性（亲水/疏水两端）→ 乳化脂肪 → 增大脂肪酶的接触面积 → 加速脂肪消化。

（四）鞘脂类（讲义 P17）

鞘脂以鞘氨醇（sphingosine）为骨架（不是甘油），是动物细胞膜（尤其神经髓鞘）的重要成分。

鞘脂家族：

  • 神经酰胺（ceramide）：鞘氨醇 + 脂酸（酰胺键）—— 母体
  • 鞘磷脂（sphingomyelin）：神经酰胺 + 磷酸胆碱
  • 鞘糖脂（glycosphingolipid）：神经酰胺 + 糖基（β-糖苷键）
    ① 脑苷脂：单糖
    ② 硫苷脂：糖 + 硫酸基
    ③ 神经节苷脂：含唾液酸（GM1 是霍乱毒素受体）
鞘脂代谢病：① 戈谢病（β-葡萄糖脑苷脂酶缺陷）；② 尼曼-匹克病（鞘磷脂酶缺陷）；③ Tay-Sachs 病（氨基己糖苷酶 A 缺陷，GM2 堆积）—— 均是常染色体隐性遗传溶酶体贮积病。

（五）异戊二烯系脂质（讲义 P18）

异戊二烯（isoprene, C₅H₈）是萜类和类固醇的共同结构单元，由乙酰 CoA 经甲羟戊酸途径（MVA）合成。

两种类型：

  • 类固醇（甾体）：环戊烷多氢菲母核，如胆固醇、胆汁酸、类固醇激素、维生素 D
  • 萜类（terpenes）：2-异戊二烯为基本单位（IPP/DMAPP），如维生素 A/E/K、单萜、倍半萜

（六）LPS 脂多糖（讲义 P19）

革兰氏阴性菌（G⁻）外膜的特征成分，是内毒素（endotoxin），由三部分组成：

  • 脂质 A（Lipid A）：保守的糖脂结构，毒性中心（被 TLR4 识别）
  • 核心多糖（core polysaccharide）：含 KDO（3-脱氧-D-甘露辛酮糖酸）、庚糖（Hep）
  • O-特异侧链（O-antigen）：菌体抗原决定簇（O 抗原）

生理效应（败血症休克）：LPS → TLR4/MyD88 → NF-κB → TNF-α、IL-1、IL-6 等炎症因子大量释放 → 发热、低血压、DIC（弥散性血管内凝血）→ 休克。

革兰氏阳性菌（G⁺）无 LPS，但有磷壁酸（teichoic acid）作为细胞壁特征。LPS 与磷壁酸都是"病原相关分子模式"（PAMP），被免疫系统识别后引发炎症反应。

（七）血浆脂蛋白（讲义 P19-20）

四、蛋白质——20 种氨基酸 + Sec + Pyl + 二硫键

（一）α-氨基酸通式（Fischer 投影）（讲义 P22）

α-碳连接 4 个基团：—NH₂、—COOH、—H、—R。Fischer 投影中 —COOH 在顶、—R 在下、—NH₂ 在左或右（对应 L 或 D）。

蛋白质元素组成（凯氏定氮法）：C 50-55% / H 6-8% / O 20-23% / N 15-18% / S 0-4%。平均氮含量 16%（凯氏常数）→ 蛋白质含量 ≈ 氮含量 × 6.25。

（三）含硫氨基酸（讲义 P24）

  • 半胱氨酸 Cys（C）：R 基 = —CH₂SH（巯基）
  • 甲硫氨酸 Met（M）：R 基 = —CH₂CH₂SCH₃（甲硫基/甲硫醚）

胱氨酸（cystine）：两分子半胱氨酸的巯基氧化形成二硫键（—S—S—）→ 胱氨酸。二硫键是共价键，稳定蛋白质三级结构（如胰岛素有 1 个二硫键，IgG 有多个，牛胰核糖核酸酶有 4 个）。

（四）含羟基氨基酸

  • 丝氨酸 Ser（S）：R 基 = —CH₂OH
  • 苏氨酸 Thr（T）：R 基 = —CH(OH)CH₃
  • 酪氨酸 Tyr（Y）：R 基 = 对羟基苯基 —C₆H₄—OH

（五）稀有氨基酸——第 21、22 种（讲义 P23）

近年发现的两种特殊氨基酸，由终止密码子重新编码而来：

  • 硒代半胱氨酸（Sec, U, 第 21 种）：含 Se 而非 S 的 Cys 同系物，由 UGA（通常是终止密码） 在 SECIS 元件存在下重新编码。存在于谷胱甘肽过氧化物酶（GPx）、硫氧还蛋白还原酶等
  • 吡咯赖氨酸（Pyl, O, 第 22 种）：含吡咯环的赖氨酸衍生物，由 UAG（通常是终止密码） 重新编码。仅存在于产甲烷古菌中

硒代半胱氨酸是第 21 种标准氨基酸，已被 IUPAC 正式确认。

"标准氨基酸 20 + 特殊编码 2 (Sec + Pyl)" 是 2020 年后的最新分类。在 IBO 联赛中常作为"拔高"考题（如问"组成蛋白质的标准氨基酸有几种"答案可能是 20 或 22，取决于是否含特殊编码）。

（六）pI 计算公式（讲义 P25）

等电点（pI）是氨基酸或蛋白质净电荷为 0 时的 pH。三类氨基酸 pI 计算：

"pI = (pKa₁ + pKa₂) / 2" 中 pKa₁ 是最酸基团的 pKa，pKa₂ 是次酸基团。丙氨酸的两个 pKa 是 α-COOH (2.3) 和 α-NH₃⁺ (9.7)，pI = (2.3 + 9.7) / 2 = 6.0。Asp 多了一个 R-COOH (3.9) → pI = (2.3 + 3.9) / 2 = 3.1。
类型pI 计算例子
中性氨基酸（α-COOH + α-NH₂）pI = (pKa₁ + pKa₂) / 2Ala pI = (2.3 + 9.7) / 2 = 6.0
酸性氨基酸（α-COOH + R-COOH）pI = (pKa₁ + pKR) / 2Asp pI = (2.3 + 3.9) / 2 = 3.1
碱性氨基酸（α-NH₂ + R-NH₂）pI = (pKα + pKR) / 2Lys pI = (8.9 + 10.5) / 2 = 9.7

（七）肽键形成（讲义 P26）

两分子氨基酸脱水：一个氨基酸的 —COOH 与另一个的 —NH₂ 脱水 → 肽键（—CO—NH—），形成二肽。

特点：

  • 酰胺键（peptide bond）
  • 部分双键性质（C—N 不可自由旋转），构象受限
  • 反式构型（trans）为主，稳定

10 个氨基酸以下称寡肽，10-50 称多肽，50 以上称蛋白质。生物活性肽多在 3-30 个氨基酸（如催产素 9aa、加压素 9aa、谷胱甘肽 3aa）。

多肽书写方向：N 端 → C 端（左 → 右）。谷胱甘肽（GSH）：γ-Glu-Cys-Gly，是 γ-肽键（不是 α-肽键，因为 Glu 用 γ-COOH 连接），是细胞内最重要的抗氧化剂。

（八）蛋白质的二级结构（讲义 P27, P31）

α-螺旋（α-helix）：

  • 右手螺旋（绝大多数）
  • 每螺旋 3.6 个氨基酸残基，螺距 0.54 nm，每残基沿轴上升 0.15 nm
  • 氢键：n 位 C=O 与 n+4 位 N-H 形成氢键（每个 C=O 和 N-H 都参与）
  • 侧链 R 基伸向螺旋外侧
  • 破坏剂：Pro（亚氨基酸不能形成 H 键，破坏螺旋）、Gly（柔性好，熵代价大）

β-折叠（β-sheet）：

  • 主链几乎完全伸展（锯齿形）
  • 链间氢键：相邻链的 C=O 与 N-H 相互形成
  • 平行（parallel，链 N→C 方向相同）
    反平行（antiparallel，链方向相反，更稳定）
  • 例：丝心蛋白（fibroin）是反平行 β-折叠

β-转角（β-turn）：4 个残基，180° 反转（常见于球蛋白表面）。
无规则卷曲（random coil）：无规律。

二级结构中的"螺距"和"残基/圈"是常考数据：α-螺旋 3.6 aa/圈、0.54 nm/圈、0.15 nm/aa。胶原蛋白是左手三股螺旋（特殊），富含 Gly-Pro-Hyp。α-角蛋白（毛发、指甲）是典型的 α-螺旋束，β-角蛋白（蚕丝）是反平行 β-折叠。

（九）三级结构与稳定力（讲义 P29）

三级结构 = 二级结构在三维空间中的进一步折叠。包括结构域（domain）：蛋白质中独立折叠的功能单位。

稳定三级结构的 6 种化学键（图 1-4-8）：

  1. 氢键（极性基团间，如 —OH 与 O=C、—NH 与 O=C）
  2. 离子键（盐桥）（带电基团间，如 —COO⁻ 与 —NH₃⁺）
  3. 疏水键（疏水 R 基聚拢，远离水相，是主要稳定力）
  4. 范德华力（弱，非特异）
  5. 二硫键（—S—S—）（共价键，最强，常见于分泌蛋白）
  6. 酯键（如 P 与 Ser 的磷酸酯键，少数）
二硫键的还原断裂：β-巯基乙醇（β-ME）、二硫苏糖醇（DTT）可还原二硫键（用于 SDS-PAGE 样品处理）。细胞质蛋白（高还原环境）很少有二硫键；分泌蛋白和膜外部分蛋白（氧化环境）有多个二硫键稳定结构。

（十）四级结构与代表蛋白（讲义 P30-31）

抹香鲸肌红蛋白（myoglobin）：

  • 单链（153 aa），无四级结构
  • 含 1 个血红素（heme）辅基：Fe²⁺ + 卟啉环（4 个吡咯环）
  • 8 段 α-螺旋（标号 A-H）
  • 功能：储存 O₂（肌肉）

血红蛋白（hemoglobin, Hb）：

  • 四聚体：2α + 2β 亚基（成人 HbA）；还有 HbA₂ (2α+2δ)、HbF (2α+2γ, 胎儿)
  • 每亚基含 1 个血红素（4 分子/全酶）
  • 协同效应：O₂ 与一个亚基结合 → 其他亚基对 O₂ 亲和力 ↑（正协同，S 形 O₂ 解离曲线）
  • 调节因子：2,3-BPG、CO₂、H⁺（Bohr 效应）

X 射线晶体学（X-ray crystallography）：

  • Max Perutz 用 X 射线衍射解析血红蛋白结构（1962 Nobel 化学奖）
  • PDB 数据库：蛋白质结构的标准存储库
Perutz 1959 完成 Hb 结构。AlphaFold2（DeepMind, 2020）用深度学习预测蛋白质结构，CASP14 中位数 92.4 分，达到实验级精度。AlphaFold 数据库（AFDB）已包含 2 亿+ 预测结构。

（十一）4 种颜色反应（讲义 P33）

鉴别蛋白质的 4 种经典颜色反应：

  1. 双缩脲反应（biuret test）：双缩脲 H₂N-CO-NH-CO-NH₂ + CuSO₄ 强碱 → 紫红色。≥ 2 个肽键蛋白可反应，用于蛋白质定量（0.5-10 mg/mL）
  2. 酚试剂反应（Lowry 法）：Folin-Ciocalteu 试剂 + 蛋白（酪氨酸残基还原磷钼酸/磷钨酸）→ 蓝色。灵敏度比双缩脲高 100 倍
  3. 米伦氏反应（Millon test）：Hg(NO₃)₂ + 蛋白（含 Tyr 残基）→ 红色沉淀。检测 Tyr
  4. 乙醛酸反应（Hopkins-Cole test）：乙醛酸 + 蛋白（含 Trp 残基） + 浓硫酸 → 紫色环。检测 Trp
Bradford 法（考马斯亮蓝 G-250）灵敏度更高，且不依赖 Tyr/Trp 含量；BCA 法是另一常用方法。紫外吸收法在 280 nm 测蛋白（Trp/Tyr 贡献），简单快速但特异性低。凯氏定氮是"总氮"法，反映蛋白总量（× 6.25）。

（十二）蛋白质的胶体性质与沉淀（讲义 P32）

蛋白质胶体稳定的 3 个条件：

  1. 粒径 1-100 nm（胶体范围）
  2. 水化膜（亲水 R 基与水形成氢键）
  3. 同性电荷（取决于 pH 与 pI 关系）

破坏任一条件 → 沉淀。

4 种沉淀方法：

  • 盐析：高浓度中性盐（硫酸铵、Na₂SO₄）→ 破坏水化膜。最温和，不变性
  • 有机溶剂沉淀：丙酮、乙醇等降低水的介电常数 → 蛋白失水化膜。易变性
  • 重金属盐沉淀：pH > pI 时，蛋白带负电，与 Hg²⁺、Pb²⁺、Cu²⁺ 结合沉淀（抢救重金属中毒用生鸡蛋清）
  • 生物碱试剂沉淀：pH < pI 时，蛋白带正电，与苦味酸、鞣酸、钨酸结合沉淀
"盐溶 vs 盐析"对比：低浓度盐（NaCl 0.1 M 以下）增加蛋白溶解度（盐溶，破坏蛋白间静电相互作用）；高浓度盐降低溶解度（盐析，破坏水化膜）。Hofmeister 序列：硫酸根是强盐析离子，硫氰酸根是强助溶离子。

（十三）变性 vs 变构（讲义 P32）

变性（denaturation）：蛋白质天然构象破坏，生物活性丧失。可逆/不可逆。

变性因素：

  • 物理：高温（70-100℃）、紫外线、X 射线、超声
  • 化学：强酸强碱、重金属盐、有机溶剂、尿素、β-ME（断二硫键）

复性：某些简单蛋白（如核糖核酸酶）变性后可缓慢恢复天然构象（血红蛋白复性率 50%），复杂蛋白不可逆。

变构（allosteric transition）：天然构象改变但不破坏，活性调节（与变性本质不同）。

蛋白变性的例子：① 鸡蛋煮熟（卵白蛋白变性凝固，不可逆）；② 牛奶酸奶（酪蛋白变性凝固）；③ 消毒（高温变性菌体蛋白）；④ 75% 酒精杀菌（变性菌体蛋白 + 溶解脂质）。

五、核酸——碱基、辅酶、DNA 高级结构

（一）5 种碱基的结构（讲义 P34）

碱基分嘌呤（双环）和嘧啶（单环）两类：

  • 嘌呤（purine）：双环结构（嘧啶环 + 咪唑环融合），编号 N1-N9
    ① 腺嘌呤 A（adenine）：6 位 —NH₂，N9 接糖
    ② 鸟嘌呤 G（guanine）：6 位 =O，2 位 —NH₂，N9 接糖
  • 嘧啶（pyrimidine）：单环结构
    ① 胞嘧啶 C（cytosine）：4 位 —NH₂，2 位 =O，N1 接糖
    ② 胸腺嘧啶 T（thymine）：仅 DNA，5 位 —CH₃，2,4 位 =O
    ③ 尿嘧啶 U（uracil）：仅 RNA，无 5-CH₃

互变异构：氨基 ↔ 亚氨基、酮式 ↔ 烯醇式。这是碱基突变（misincorporation）的化学基础。

"亚氨基 + 烯醇" 互变体可与不正确的碱基配对：例如 C 的亚氨基形式可与 A 配对（C·A 错配是突变的常见来源）。5-甲基胞嘧啶（5mC）是真核 DNA 甲基化标志（表观遗传学）。

碱基与戊糖通过 N-糖苷键连接：

  • 嘌呤：N9 — C1'
  • 嘧啶：N1 — C1'

核苷 = 碱基 + 戊糖；核苷酸 = 碱基 + 戊糖 + 磷酸（磷酸连在戊糖 C5'）。

（四）环化核苷酸 cAMP / cGMP（讲义 P36）

cAMP（环腺苷酸）= AMP 的 3',5'-环磷酸，是经典的"第二信使"（first messenger 是激素本身）。cAMP 由腺苷酸环化酶（AC）从 ATP 合成，被磷酸二酯酶（PDE）水解。

信号通路：激素 → 受体 → Gs → AC ↑ → cAMP ↑ → PKA 激活 → 底物磷酸化 → 生理效应

cAMP 是 Sutherland 1950 年代发现"第二信使"概念的开端（获 1971 Nobel）。cGMP 也有类似作用（一氧化氮 NO → 鸟苷酸环化酶 → cGMP → 血管舒张）。

（六）3',5'-磷酸二酯键（讲义 P37）

DNA/RNA 链由3',5'-磷酸二酯键连接：

  • 一个核苷酸的 3'-OH 与下一个核苷酸的 5'-磷酸 缩合
  • 方向性：5' → 3'（左 5'、右 3'）
  • 两条链 反向平行（antiparallel）
核酸方向性是 5'→3'（N 端 → C 端类比），所以书写 DNA 序列时左 5'、右 3'。DNA 聚合酶只能 5'→3' 合成（不能 3'→5'），这就是为什么 DNA 复制是半不连续（前导链连续、滞后链不连续）。

（七）DNA 双螺旋（讲义 P38-39）

  • 右手螺旋（B 型）
  • 每螺旋 10 bp（10.5 bp），螺距 3.4 nm，碱基间距 0.34 nm
  • 碱基对在内、糖-磷酸骨架在外
  • A = T（2 个氢键），G ≡ C（3 个氢键）
  • 两条链反向平行
  • 大沟和小沟（蛋白质结合位点）

（八）DNA 其他二级结构（讲义 P40-41）

  • 发夹结构（hairpin）：单链 DNA 自身回折，回文序列（palindrome）形成对称的双链茎（5'-GAATTC-3' 是 EcoRI 识别位点）
  • 十字架结构（cruciform）：发夹结构在双链 DNA 中出现
  • H-DNA（三股螺旋）：1963 年 Hoogsteen 发现，第三条链通过 Hoogsteen 配对（不是 Watson-Crick 配对） 插入大沟

（九）DNA 超螺旋与拓扑学（讲义 P41-43）

超螺旋（supercoiling）= DNA 双螺旋进一步盘绕。

  • 连环数 L = 扭转数 T + 缠绕数 W（Fuller 公式）
  • L 为拓扑不变量（不变），T 和 W 可互换
  • 负超螺旋：W 减小（更易解链），原核生物主要形式
  • 正超螺旋：W 增大（更紧）

拓扑异构酶：调整 L 值。

  • 拓扑异构酶 I（Topo I）：切开单链 → 旋转 → 重接，L 改变 ±1
  • 拓扑异构酶 II（Topo II / 旋转酶 gyrase）：切开双链 → 另一双链穿过 → 重接，L 改变 ±2，需要 ATP

抗肿瘤药：

  • 依托泊苷（etoposide）：抑制 Topo II → 双链断裂 → 癌细胞凋亡
  • 喜树碱（camptothecin）：抑制 Topo I
拓扑学 vs 构象学：构型异构涉及共价键变化（L 变），构象异构仅非共价变化（L 不变，T 和 W 互变）。例如 pUC19 质粒 L = 28/30/31 三种拓扑异构体。

（一）酶的命名与 EC 编号（讲义 P51）

（二）酶结构与活性中心（讲义 P54）

酶的结构层级：

  • 单体酶（monomer）：单条多肽链（如溶菌酶 129 aa）
  • 寡聚酶（oligomer）：多条亚基（如 Hb 4 亚基）
  • 多酶复合体（multienzyme complex）：多种酶紧密集合（如丙酮酸脱氢酶复合体 PDH）

活性中心（active site）：

  • 结合部位（binding site）：与底物结合（决定专一性）
  • 催化部位（catalytic site）：催化反应（决定活性）

必需基团（参与催化的化学基团）：

  • Ser —OH、Thr —OH、Tyr —OH
  • His 咪唑基（pKa ≈ 6，最适质子穿梭）
  • Cys —SH（强亲核）
  • Asp/Glu —COOH（酸碱催化）
  • Lys ε-NH₂
酶活性单位：1 IU（国际单位）= 在最适条件下、25℃、1 min 内催化 1 μmol 底物转化。比活力 = 总活力 / 总蛋白 = IU/mg，是酶纯度指标。

（三）酶-底物复合物学说（讲义 P55）

两种经典模型：

  • 钥匙-锁模型（lock-and-key, 1890, Fischer）：酶活性中心与底物结构严密匹配，像钥匙插锁
  • 诱导-契合模型（induced-fit, 1958, Koshland）：底物与酶结合时，酶构象发生改变，活性中心更好地匹配底物

诱导契合是现代主流模型，更准确地解释了酶的催化效率（同种酶对不同底物的差异）。同工酶（isozyme）是催化相同反应但氨基酸序列不同的酶（如 LDH₁-₅）。

"同工酶"是奥赛常考概念。乳酸脱氢酶（LDH）有 5 种同工酶（由 M、H 亚基组合），不同组织分布不同：心肌 LDH₁ (H₄)、肝 LDH₅ (M₄)、骨骼肌 LDH₅。临床用 LDH 同工酶谱判断组织损伤。

（四）酶高效催化的 4 种机制（讲义 P56）

  1. 邻近与定向效应（proximity & orientation）：底物与酶结合后，反应基团空间上接近，反应熵减少
  2. 张力与形变（strain / distortion）：底物被酶"挤压"成过渡态构象，活化能降低
  3. 酸碱催化（acid-base catalysis）：His、Asp/Glu 充当质子供体/受体（"质子穿梭"）
  4. 共价催化（covalent catalysis）：酶的亲核基团（Ser —OH、Cys —SH、His 咪唑）与底物形成短暂共价键（酰基-酶中间体）

辅因子（金属离子）的 5 种催化作用：

  • 作为 Lewis 酸（接受电子对）
  • 通过电荷屏蔽促进反应
  • 参与氧化还原（Fe, Cu, Mn）
  • 稳定过渡态
  • 促进底物定向
酶的催化效率：10⁶-10¹² 倍加速。例如：碳酸酐酶 10⁶/s 分子，β-内酰胺酶 10³/s，催化抗体（abzyme）也可达 10⁶-10⁷。溶菌酶是经典的"诱导契合 + 酸碱催化"模型。

（五）米氏方程（Michaelis-Menten 方程）（讲义 P58）

由 Michaelis & Menten 1913 年提出，基于稳态假设：

E + S ⇌ ES → E + P
v = Vmax·[S] / (Km + [S])
v：反应速率；Vmax：最大速率；[S]：底物浓度；Km：米氏常数

Km 的意义：

  • 当 v = Vmax/2 时，[S] = Km
  • Km = 酶-底物解离常数（Kd）的近似值，Km 越小，亲和力越大
  • 不同底物对应不同 Km 值（酶对最适底物 Km 最小）
  • 同一酶在不同条件下 Km 可能变化（受 pH、温度、离子影响）

两种极端情况：

  • [S] << Km 时，v ≈ (Vmax/Km)·[S]，一级反应（[E] 远低于 [S]）
  • [S] >> Km 时，v ≈ Vmax，零级反应（酶被底物饱和）
Briggs-Haldane 1942 改良米氏方程：使用稳态假设（[ES] 不变），不要求快速平衡假设。Lineweaver-Burk 双倒数作图 1/v = (Km/Vmax)·1/[S] + 1/Vmax 可同时求 Km 和 Vmax，并区分抑制剂类型。

（六）温度、pH 对酶活性的影响（讲义 P59）

  • 最适温度：35-40℃（哺乳动物酶）；嗜热菌 Taq 酶最适 70-75℃
  • 最适 pH：6-8（多数酶）；胃蛋白酶 pH 1.5-2；碱性磷酸酶 pH 9-10

DNA 熔解温度 Tm 公式：

Tm = 69.3 + 0.41 · (%G + %C)
（适用于 0.15 M NaCl 缓冲液中的长链 DNA）
Tm 是 DNA 双链 50% 解链时的温度，受 GC 含量、离子强度、序列均一性影响。PCR 引物设计常用更精确公式：Tm = 64.9 + 41·(G+C-16.4/N)，N 为引物长度。嗜热菌 Taq 酶 70-75℃ 最适，让 PCR 扩增可使用 95℃ 变性而不损失酶活性。

（七）酶活性的调控（讲义 P60-65）

  1. 激活剂（activator）：金属离子 K⁺、Na⁺、Mg²⁺、Mn²⁺、Zn²⁺、Fe²⁺、Ca²⁺；阴离子 Cl⁻ 等
  2. 酶原激活：合成时无活性，需经切割激活（胰蛋白酶原 → 胰蛋白酶，肠激酶切）
  3. 别构调节：调节物（别构剂）结合调节部位（非活性中心）→ 改变酶构象 → 改变活性。S 形曲线（非米氏曲线）
    同促效应：底物本身调节；异促效应：其他分子调节
  4. 共价修饰：磷酸化/去磷酸化是最常见的可逆共价调节。"高高低低"原则：糖原磷酸化酶（被磷酸化激活 → 糖原分解↑），糖原合酶（被磷酸化失活 → 糖原合成↓）

  1. VC（抗坏血酸）：L-抗坏血酸（γ-内酯），强还原性
  2. 叶酸：蝶啶 + 对氨基苯甲酸 + 谷氨酸
  3. 烟酸 / 烟酰胺：吡啶环（3 位 —COOH / —CONH₂）
  4. 泛酸：β-丙氨酸 + 二羟基二甲基丁酸
  5. VB₁（硫胺素）：嘧啶 + 噻唑（+ 焦磷酸 = TPP）
  6. VB₂（核黄素）：异咯嗪环 + 核糖醇（+ AMP = FMN；+ ADP-AMP = FAD）
  7. VB₆（吡哆醇/醛/胺）：吡啶环（+ 5'-磷酸 = PLP）
维生素缺乏症的典型例子：① 长期吃精米 → 缺乏 VB₁ → 脚气病（湿性：心衰；干性：神经炎；Wernicke 脑病）；② 玉米为主食 → 缺乏烟酸 → 癞皮病（3D 病）；③ 北方冬季儿童 → 缺乏 VD → 佝偻病；④ 抗生素滥用 → 杀肠道菌 → 缺乏 VK → 出血倾向。

（三）脂溶性维生素详解（讲义 P69）

  • VA（视黄醇）：来自 β-胡萝卜素（双分子视黄醇）；3 形式：视黄醇、视黄醛、视黄酸；含 β-紫罗酮环 + 异戊二烯侧链
  • VD（钙化醇）：
    ① 皮肤中：7-脱氢胆固醇 + UV → 维生素 D₃（cholecalciferol）
    ② 肝：25-羟化酶 → 25-(OH)-D₃
    ③ 肾：1α-羟化酶 → 1,25-(OH)₂-D₃（活性形式，钙三醇）
  • VE（生育酚）：苯骈二氢吡喃环 + 异戊二烯侧链；强抗氧化剂，保护细胞膜不饱和脂质
  • VK（凝血维生素）：VK₁（叶绿醌，植物）+ VK₂（甲萘醌，肠道菌合成）；γ-谷氨酰羧化酶辅因子，使凝血因子 II、VII、IX、X 谷氨酸残基 γ-羧化（结合 Ca²⁺）

（四）钴胺素（VB₁₂）

VB₁₂ 是唯一含金属（钴）的维生素，含咕啉环（类似血红素，但 Co 替代 Fe，环更大）。

两种辅酶形式：

  • 甲钴胺素：与甲基四氢叶酸合作，参与甲硫氨酸合成（同型半胱氨酸 → Met）
  • 腺苷钴胺素：参与甲基丙二酸单酰 CoA 变位酶（丙酰 CoA → 琥珀酰 CoA）

吸收：胃壁细胞分泌内因子（Castle intrinsic factor） → VB₁₂-内因子复合物在回肠被吸收。

VB₁₂ 缺乏导致恶性贫血：① 胃壁细胞萎缩 → 内因子分泌不足 → VB₁₂ 吸收不良 → 巨幼红细胞性贫血（红细胞不能成熟）；② 神经脱髓鞘（手麻、共济失调）。Schilling 试验检测 VB₁₂ 吸收。叶酸只能治贫血不能治神经症状。

（五）CoA（辅酶 A）

CoA-SH 是泛酸（VB₅） + 3'-磷酸-ADP + 巯基乙胺组成。结构特点：

  • 末端 —SH（巯基）是活性基团
  • CoA-S—CO—R（硫酯键，能量高）

参与：乙酰 CoA（糖、脂、氨基酸代谢共同产物）、脂酰 CoA（β-氧化）、琥珀酰 CoA（TCA）等。

CoA 分子量 ~767，结构核心是 3'-磷酸 ADP。辅酶 A 的发现（1946 年 Fritz Lipmann）解决了"乙酰基如何转运"的核心问题，Lipmann 因此获 1953 Nobel 生理学或医学奖。

（六）FH₄（四氢叶酸）

叶酸（VB₉）→ 二氢叶酸（DHF）→ 四氢叶酸（FH₄, tetrahydrofolate）（活性形式）。

FH₄ 是一碳单位（1C）的载体，参与：

  • 甲基化反应：N⁵-甲基-FH₄
  • 亚甲基（—CH₂—）转移：N⁵,N¹⁰-亚甲基-FH₄（胸苷合成）
  • 亚胺甲基（—CH=NH）转移：N⁵-亚胺甲基-FH₄（组氨酸代谢）
  • 甲酰基（—CHO）转移：N¹⁰-甲酰-FH₄（嘌呤合成）
抗叶酸药物：① 甲氨蝶呤（methotrexate）抑制二氢叶酸还原酶（DHFR）→ 阻止 DHF → FH₄ → 抑制嘌呤、胸苷合成 → 抗肿瘤；② 磺胺类（如 SD, SMZ）抑制二氢叶酸合成酶 → 抑菌。孕妇补充叶酸预防胎儿神经管缺陷。
