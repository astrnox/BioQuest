一、细胞内蛋白质的降解——UPS vs 溶酶体

真核细胞内蛋白质有两个主要的降解系统,二者在选择性、调控、能量依赖性上差异巨大:

  1. 溶酶体途径(非选择性)——含约 50 种水解酶,pH ~5(酸性),含多种蛋白酶(组织蛋白酶 cathepsins),降解长寿蛋白、细胞器、胞外蛋白;通过自噬清理受损细胞器
  2. 泛素-蛋白酶体途径(UPS,ubiquitin-proteasome system)(选择性、ATP 依赖)——降解短寿蛋白、异常蛋白、调控蛋白,精确调控细胞周期、信号转导

UPS 系统的关键分子:

  • 泛素(ubiquitin):76 aa 高度保守多肽,真核生物中几乎所有蛋白都以此标记
  • E1 激活酶(ubiquitin-activating enzyme):消耗 ATP 将泛素 C 端 Gly 活化
  • E2 结合酶(ubiquitin-conjugating enzyme):接受活化的泛素
  • E3 连接酶(ubiquitin ligase):识别底物,将泛素从 E2 转移到靶蛋白 Lys 残基的 ε-NH₂ 上
  • 26S 蛋白酶体:由 20S 核心(蛋白水解活性,桶状结构)+ 两个 19S 调节帽(识别泛素化底物、去泛素化、展开底物)组成

UPS 降解流程:E1 活化泛素(ATP 依赖)→ E2 接受泛素 → E3 识别底物并催化泛素 C 端 Gly 与底物 Lys 形成异肽键 → 形成 K48 连接的泛素链(≥4 个泛素)→ 被 26S 蛋白酶体识别 → 底物被水解为短肽(7-9 aa)+ 泛素回收

高中衔接:2004 年诺贝尔化学奖授予 Ciechanover、Hershko、Rose 表彰他们发现"泛素介导的蛋白质降解机制"——这是细胞质量控制的核心机制。高中课本没讲,竞赛生必须掌握。临床应用:万艾可(伟哥)治疗勃起障碍、bortezomib(硼替佐米)治疗多发性骨髓瘤,都作用于 UPS 系统。

1.1 蛋白质半衰期的决定因素

不同蛋白质在细胞内的寿命差异巨大(从数分钟到数天),主要决定因素:

  • N-末端规则(N-end rule):N 端氨基酸决定半衰期
    • 不稳定(半衰期 2-3 分钟):Asp、Arg、Leu、Lys、Phe
    • 稳定(原核 >10 小时,真核 >20 小时):Ala、Gly、Met、Ser、Val
  • PEST 序列(富含 Pro-Glu-Ser-Thr 的区域):促进降解
  • 异常/损伤蛋白(氧化、变性):暴露出疏水残基或 PEST 序列,被快速识别降解
  • 特定信号(磷酸化、糖基化、破坏框)调控识别

📌 关键概念:UPS 是真核细胞"精确调控蛋白浓度"的核心机制——通过可控降解短寿调控蛋白(如细胞周期蛋白 cyclin、肿瘤抑制因子 p53、转录因子 NF-κB 抑制剂 IκB),实现快速、不可逆的调控。

1.2 消化道中外源蛋白质的酶促降解

外源蛋白质的消化是一个"胃-肠-肠粘膜"三段式级联过程,各种蛋白酶的专一性互补,最终把蛋白质切成氨基酸才能被吸收:

部位酶来源最适 pH作用位点产物
胃胃蛋白酶(pepsin)胃主细胞分泌胃蛋白酶原(zymogen),HCl 激活1.5-2.5切割 Phe、Tyr、Trp 等疏水氨基酸的氨基端肽键(偏好芳香族)多肽
小肠胰蛋白酶(trypsin)胰腺分泌胰蛋白酶原;被肠激酶(enterokinase)激活7-9切割 Lys、Arg 羧基端肽键(碱性氨基酸)多肽
小肠胰凝乳蛋白酶(chymotrypsin)胰腺分泌胰凝乳蛋白酶原;被胰蛋白酶激活7-9切割 Phe、Trp、Tyr 等芳香族氨基酸羧基端多肽
小肠弹性蛋白酶(elastase)胰腺分泌酶原;被胰蛋白酶激活7-9切割 Ala、Gly、Ser 等小侧链氨基酸多肽
小肠羧肽酶 A胰腺分泌酶原7-9从 C 端依次切下芳香族/支链脂肪族氨基酸氨基酸+肽
小肠羧肽酶 B胰腺分泌酶原7-9从 C 端切下碱性氨基酸(Arg、Lys)氨基酸+肽
小肠氨肽酶(aminopeptidase)小肠粘膜7-9从 N 端依次切下氨基酸二肽+氨基酸
小肠二肽酶(dipeptidase)小肠粘膜7-9水解二肽2 个氨基酸

激活级联(避免胰腺自身消化):

胰腺蛋白酶的级联激活
肠激酶(肠粘膜) → 激活胰蛋白酶原 → 胰蛋白酶 → 激活胰凝乳蛋白酶原
激活弹性蛋白酶原 + 激活羧肽酶原 + 激活更多胰蛋白酶原(正反馈)

⚠️ 临床关联:

  • 急性胰腺炎:胰蛋白酶原在胰腺内被异常激活,自我消化胰腺组织
  • 囊性纤维化:CFTR 基因突变导致胰液粘稠,消化酶不能进入肠道
高中延伸:高中提到"酶的专一性",这里给出了专一性的具体表现:胰蛋白酶只切碱性氨基酸后面,胰凝乳蛋白酶只切芳香族氨基酸后面,羧肽酶从 C 端切,氨肽酶从 N 端切——协同把蛋白质切成氨基酸。酶原激活机制(避免自我消化)是 ch1-1-7 提到的级联激活的典型例子。

二、氨基酸分解代谢总览

氨基酸分解的两大反应:

  1. 脱氨基作用(主要):产生 α-酮酸 + 氨(NH₃)
  2. 脱羧基作用(次要,但产物有重要生理活性):产生胺 + CO₂

两种反应的辅酶都是磷酸吡哆醛(PLP,维生素 B6 的活化形式)——这是为什么"几乎所有 B 族维生素都参与氨基酸代谢"的根源。PLP 与氨基酸形成希夫碱(Schiff base)中间体,把氨基酸的氨基"接管"过来。

2.1 氨基酸的脱氨基方式

方式反应酶/辅因子评价
氧化脱氨基氨基酸 → α-亚氨基酸 → α-酮酸 + NH₄⁺L-氨基酸氧化酶(FMN/FAD)、L-谷氨酸脱氢酶(NAD⁺/NADP⁺)L-谷氨酸脱氢酶最重要(肝、肾、脑;催化可逆反应)
转氨基(主要方式)氨基酸1 + α-酮酸2 → α-酮酸1 + 氨基酸2转氨酶(aminotransferase),辅酶为 PLP不产生游离氨;氨基从一种氨基酸转到另一种酮酸上
联合脱氨基(动物主要途径)转氨基(把氨基集中到 α-酮戊二酸上→谷氨酸)+ L-谷氨酸脱氢酶氧化脱氨两种酶协同真实细胞内氨基酸脱氨的主要方式
嘌呤核苷酸循环(肌肉/脑主要)谷氨酸与草酰乙酸转氨 → 天冬氨酸 + α-酮戊二酸 → 天冬氨酸进入嘌呤核苷酸循环放氨7 步循环酶肌肉、脑等组织不能用 L-谷氨酸脱氢酶,改用此途径

🧬 联合脱氨基作用的真实反应链:

氨基酸 + α-酮戊二酸 ⇌ 谷氨酸 + α-酮酸   (转氨酶,PLP)
谷氨酸 + NAD(P)⁺ + H₂O ⇌ α-酮戊二酸 + NH₄⁺ + NAD(P)H   (L-谷氨酸脱氢酶)
────────────────────────────────────────
净反应:氨基酸 + NAD(P)⁺ + H₂O → α-酮酸 + NH₄⁺ + NAD(P)H

绝大多数氨基酸的氨基都通过"先转氨给 α-酮戊二酸变成谷氨酸,再由 L-谷氨酸脱氢酶集中脱氨"的方式被清除——α-酮戊二酸是"氨基的集散中心"。

L-谷氨酸脱氢酶的关键特征:

  • 辅酶:NAD⁺ 或 NADP⁺(双辅酶)
  • 变构调节:GTP、ATP、NADH 抑制;ADP、GDP 激活
  • 可逆反应:既能脱氨(分解),又能加氨(合成)
  • 部位:肝、肾、脑线粒体基质

📌 脱氨基方式小结与竞赛要点(凌云计划):

  • 氧化脱氨基:L-谷氨酸脱氢酶是体内唯一活跃的氧化脱氨酶,需 NAD⁺/NADP⁺ 作辅酶(双辅酶)。
  • 转氨基:由转氨酶(ALT/AST)催化,辅酶为磷酸吡哆醛(PLP,维生素 B6 辅酶);反应可逆,不产生游离氨。
  • 联合脱氨基:转氨基 + L-谷氨酸脱氢酶氧化脱氨,是动物细胞内氨基酸脱氨的主要方式。
  • 嘌呤核苷酸循环:IMP→AMP→IMP+NH₃,是肌肉组织中主要的脱氨方式。

🧠 组织特异性(高频考点):肝脏以联合脱氨基为主(L-谷氨酸脱氢酶活性高);骨骼肌以嘌呤核苷酸循环为主(L-谷氨酸脱氢酶活性低,需借助嘌呤核苷酸循环间接脱氨)。这一"肝脏 vs 骨骼肌"的组织差异是竞赛常考点。

凌云计划要点:脱氨方式的组织分工——肝脏=联合脱氨基(主),骨骼肌=嘌呤核苷酸循环(主)。原因:骨骼肌中 L-谷氨酸脱氢酶活性低,无法直接氧化脱氨,故改用嘌呤核苷酸循环把氨基"伪装"成天冬氨酸经 AMP 脱氨酶释放。PLP(VitB6)是转氨酶辅酶,L-谷氨酸脱氢酶是唯一活跃的氧化脱氨酶——这两个细节常考。

2.2 重要的转氨酶(临床标志物)

转氨酶反应临床意义
谷丙转氨酶(ALT/GPT)丙氨酸 + α-酮戊二酸 ⇌ 丙酮酸 + 谷氨酸肝中活性最高;肝损伤时血中 ALT 升高
谷草转氨酶(AST/GOT)天冬氨酸 + α-酮戊二酸 ⇌ 草酰乙酸 + 谷氨酸心肌中活性最高,其次是肝;心肌梗死/肝病时血中 AST 升高

2.3 嘌呤核苷酸循环(肌肉/脑组织)

肌肉和脑组织中 L-谷氨酸脱氢酶活性低,改用嘌呤核苷酸循环脱氨。流程:

① 氨基酸 + α-酮戊二酸 → 谷氨酸 + α-酮酸   (转氨酶)
② 谷氨酸 + 草酰乙酸 → α-酮戊二酸 + 天冬氨酸   (谷草转氨酶)
③ 天冬氨酸 + IMP + GTP → 腺苷酸琥珀酸 + GDP + Pi   (腺苷酸琥珀酸合成酶)
④ 腺苷酸琥珀酸 → AMP + 延胡索酸
⑤ AMP + H₂O → IMP + NH₄⁺   (AMP 脱氨酶)
⑥ 延胡索酸 → 苹果酸 → 草酰乙酸(进入柠檬酸循环)

总效果:把氨基"伪装"成天冬氨酸进入嘌呤核苷酸循环,以延胡索酸形式回到柠檬酸循环;同时在 AMP 脱氨酶作用下释放氨。这是 ch1-1-8 中"嘌呤核苷酸循环"在氨基酸代谢中的具体应用。

2.4 氨基酸的脱羧基作用与生物胺

氨基酸脱羧 → CO₂ + 生物胺(许多生物活性物质):

R-CH(NH₃⁺)-COO⁻ → R-CH₂-NH₂ + CO₂   (氨基酸脱羧酶,辅酶 PLP)

例外:组氨酸脱羧酶不需要 PLP(使用丙酮酰基辅酶)。

氨基酸脱羧产物生理作用
谷氨酸γ-氨基丁酸(GABA)重要的抑制性神经递质
天冬氨酸β-丙氨酸辅酶 A、泛酸的成分
组氨酸组胺(histamine)血管舒张剂;胃酸分泌刺激;过敏反应介质
色氨酸5-羟色胺(5-HT,血清素)神经递质,影响情绪/睡眠/食欲
酪氨酸酪胺血管收缩;升压
半胱氨酸牛磺酸胆汁酸结合;抗氧化
鸟氨酸腐胺 → 亚精胺 → 精胺(多胺)细胞增殖调节

📌 生物胺的氧化解毒(避免积累):

R-CH₂-NH₂ + O₂ + H₂O →(胺氧化酶)→ R-CHO + H₂O₂ + NH₃
R-CHO + ½ O₂ →(醛脱氢酶)→ R-COO⁻ + H⁺

最终产物 R-COOH(脂肪酸)进入 β-氧化。单胺氧化酶(MAO)抑制剂是抗抑郁药物的作用靶点之一。

三、氨的代谢去路——重点中的重点

氨(NH₃)对中枢神经系统剧毒(尤其脑):血氨水平 5 倍以上即引起肝性脑病(肝昏迷)。因此氨必须迅速清除。

3.1 氨的运输方式

运输方式反应特点
丙氨酸-葡萄糖循环(Cahill 循环)肌肉:氨基酸把氨基转给丙酮酸 → 丙氨酸 → 血液 → 肝:丙氨酸转氨给 α-酮戊二酸 → 谷氨酸 → 释放氨;丙酮酸糖异生 → 葡萄糖 → 血液 → 肌肉把"氨基"和"丙酮酸骨架"绑在一起运输,实现肌肉产氨到肝脏解毒;饥饿时为肝提供糖异生前体
谷氨酰胺运氨谷氨酸 + NH₃ + ATP → 谷氨酰胺 + ADP + Pi(谷氨酰胺合成酶);谷氨酰胺运到肝/肾后由谷氨酰胺酶水解放氨谷氨酰胺是血液中主要的氨载体(无毒)

🧬 葡萄糖-丙氨酸循环(Cahill 循环)详解:该循环实现"氨的运输"与"糖异生前体的运输"双重功能,其完整流程如下:

葡萄糖-丙氨酸循环(Cahill 循环)
肌肉:氨基酸的氨基转给丙酮酸 → 丙氨酸(转氨基,ALT/转氨酶) → 丙氨酸经血液运输 → 肝脏
肝脏:丙氨酸 + α-酮戊二酸 → 丙酮酸 + 谷氨酸(ALT 催化) → 丙酮酸 → 糖异生 → 葡萄糖 → 血液 → 回到肌肉

📌 循环意义:

  • 氨的安全运输:将肌肉中氨基酸脱下的氨基以无毒的丙氨酸形式运到肝脏,在肝脏释放氨进行尿素合成解毒——避免肌肉局部氨积累。
  • 糖异生前体供应:丙氨酸在肝脏转氨后产生的丙酮酸,可作为糖异生前体合成葡萄糖,葡萄糖再回到肌肉供能——形成"肌肉→肝→肌肉"的碳骨架闭环。

📌 竞赛要点:葡萄糖-丙氨酸循环 = 氨的运输 + 糖异生前体的运输。关键酶为 ALT(谷丙转氨酶)——既催化肌肉中丙酮酸→丙氨酸(加氨),也催化肝脏中丙氨酸→丙酮酸(脱氨),是双向运转的核心酶。

凌云计划要点:Cahill 循环是饥饿/运动状态下的重要代谢途径。肌肉分解蛋白质产能时,氨基不能就地堆积(有毒),必须以丙氨酸形式运走;肝脏则利用运来的丙酮酸进行糖异生维持血糖。ALT 是连接两端的关键酶。注意与谷氨酰胺运氨区分:谷氨酰胺是血液中"主要氨载体"(量最大),丙氨酸循环则侧重"肌肉→肝"定向运输。

3.2 尿素循环(Ornithine Cycle)——核心

高中提到"肝脏是解毒器官"——肝脏把有毒的氨转变成无毒的尿素就是最典型的解毒过程。Krebs 一生提出两次循环(柠檬酸循环 + 尿素循环),是生物化学的奠基人之一。

总反应:

2 NH₃ + CO₂ + 3 ATP + 天冬氨酸 → 尿素 + 延胡索酸 + 2 ADP + AMP + 4 Pi
步骤反应酶部位能量/辅因子
①NH₃ + CO₂ + 2 ATP → 氨基甲酰磷酸 + 2 ADP + Pi氨基甲酰磷酸合酶 I(CPS I)线粒体基质消耗 2 ATP;N-乙酰谷氨酸(AGA)为变构激活剂
②氨基甲酰磷酸 + 鸟氨酸 → 瓜氨酸 + Pi鸟氨酸氨基甲酰转移酶(OTC)线粒体基质不可逆
③瓜氨酸 + 天冬氨酸 + ATP → 精氨酸代琥珀酸 + AMP + PPi精氨酸代琥珀酸合成酶细胞质消耗 1 ATP(等价 2 高能键);天冬氨酸提供第二个氨基
④精氨酸代琥珀酸 → 精氨酸 + 延胡索酸精氨酸代琥珀酸裂解酶细胞质延胡索酸进入柠檬酸循环
⑤精氨酸 + H₂O → 鸟氨酸 + 尿素精氨酸酶细胞质鸟氨酸回到线粒体进入下一轮循环

📌 能量总结:1 分子尿素消耗 3 ATP(等价 4 高能磷酸键)——2 ATP 用于氨基甲酰磷酸合成,1 ATP 消耗于精氨酸代琥珀酸合成(ATP → AMP + PPi)。

📌 常考点:第二个氮的来源不是第二个 NH₃,而是天冬氨酸——这是精氨酸代琥珀酸合成酶催化的反应,把"氨基"以"酰胺基"形式接入。

特征CPS ICPS II

⚠️ 临床关联:

  • 高氨血症/肝昏迷:肝功能衰竭 → 氨不能转化为尿素 → 血氨升高 → 中枢神经毒性
  • OTC 缺陷:尿素循环最常见的遗传病(X 连锁),新生儿期即出现高氨血症
  • 精氨酸是必需氨基酸(对尿素循环障碍者)——因为精氨酸降解产生的鸟氨酸/瓜氨酸可促进尿素循环残存功能
高中延伸:这一节把"蛋白质分解"和"尿素排出"两个高中没讲清楚的过程完全串起来——"吃进去的蛋白质 → 氨基酸 → 脱氨 → 氨 → 肝脏尿素循环 → 尿素 → 肾脏排出"。这是奥赛必考内容,常考"第二个 N 来自天冬氨酸"、"CPS I vs CPS II"等。

📌 竞赛要点速记(尿素循环):

  • 限速酶:CPS-I(氨甲酰磷酸合成酶 I)——尿素循环的关键调控点。
  • 正反馈调控:精氨酸可激活 N-乙酰谷氨酸合成酶(NAGS)→ 促进 N-乙酰谷氨酸(NAG) 合成 → NAG 是 CPS-I 的别构激活剂 → 加速尿素合成。即"精氨酸 → NAG → CPS-I"正反馈环路。
  • 尿素中两个 N 的来源:一个来自游离 NH₃(第①步 CPS-I 反应),另一个来自天冬氨酸(第③步精氨酸代琥珀酸合成酶反应)——这是高频考点。
  • 能量消耗:合成 1 分子尿素消耗 3 个 ATP(等价 4 个高能磷酸键)——第①步用 2 ATP,第③步 ATP→AMP+PPi(等价 2 个高能磷酸键)。
  • 精氨酸酶需 Mn²⁺:第⑤步精氨酸酶(arginase)是锰金属酶,需 Mn²⁺ 作为辅因子。

🧬 尿素循环-TCA 双循环(两循环偶联):尿素循环产生的延胡索酸并非废弃产物,而是进入柠檬酸循环:

尿素循环与 TCA 循环的偶联("双循环")
延胡索酸(尿素循环第④步) → 苹果酸 → 草酰乙酸(OAA) → 天冬氨酸(转氨)
天冬氨酸回到尿素循环第③步 ⇌ 形成"尿素循环-TCA 双循环"

这一偶联使延胡索酸→苹果酸→OAA→天冬氨酸的代谢链把两个循环连接起来——天冬氨酸既是尿素循环的第二个 N 来源,又通过 TCA 循环再生,构成代谢"桥梁"。

凌云计划要点:尿素循环的调控是竞赛高频考点。重点掌握:① CPS-I 是限速酶;② NAG 是 CPS-I 的正调节剂,精氨酸通过激活 NAGS 形成正反馈;③ 尿素两个 N 分别来自 NH₃ 和天冬氨酸;④ 消耗 3 ATP(4 高能磷酸键);⑤ 精氨酸酶需 Mn²⁺;⑥ 尿素循环-TCA 双循环通过延胡索酸-天冬氨酸偶联。

📌 生糖/生酮氨基酸完整分类(竞赛必背):

  • 纯生酮氨基酸(2 种):Leu(亮氨酸)、Lys(赖氨酸)——只能转变成乙酰 CoA/酮体,不能净生成糖。
  • 既生糖又生酮氨基酸(5 种):Ile(异亮)、Phe(苯丙)、Tyr(酪)、Trp(色)、Thr(苏)——碳骨架既能生糖又能生酮。
  • 纯生糖氨基酸(其余 13 种):Ala、Arg、Asn、Asp、Cys、Gln、Glu、Gly、His、Met、Pro、Ser、Val——碳骨架可经糖异生生糖。

🧠 竞赛口诀:"两酮亮赖,五兼异苯酪色苏"——即 2 种纯生酮(亮、赖),5 种兼性(异亮、苯丙、酪、色、苏),其余均为纯生糖。

2025 联赛真题考点:生糖生酮氨基酸的分类曾在 2025 年生物联赛中考查,要求准确判断某氨基酸属于纯生糖、纯生酮还是兼性。务必牢记"亮赖纯生酮,异苯酪色苏兼性",其余皆为纯生糖。
凌云计划要点:判断依据看碳骨架的代谢出口——若只生成乙酰 CoA(不能净生糖)则为生酮;若生成丙酮酸或 TCA 中间物(OAA、α-KG 等)则为生糖;两者皆有则兼性。亮、赖是唯二纯生酮;异亮、苯丙、酪、色、苏是 5 种兼性;其余 13 种纯生糖。

四、氨基酸的合成代谢

4.1 必需氨基酸与非必需氨基酸

高中没有"必需氨基酸"概念。本节引入:人体只能合成 12 种非必需氨基酸,另外 8 种必需氨基酸必须从食物中获取(因为人体缺乏相应合成途径/合成酶)。

8 种必需氨基酸(人体不能合成,需从食物摄取):

口诀"赖甲苏亮异色缬苯":Lys(赖氨酸)、Met(甲硫氨酸)、Thr(苏氨酸)、Leu(亮氨酸)、Ile(异亮氨酸)、Trp(色氨酸)、Val(缬氨酸)、Phe(苯丙氨酸)

🧠 替代口诀:"苯缬亮异赖蛋苏色"(Phe、Val、Leu、Ile、Lys、Met、Thr、Trp);谐音口诀"一家携两三本淡色书来"(异亮-甲硫-缬-亮-苏-苯丙-蛋-色-赖)。

特殊:His(组氨酸)婴儿必需,成人半必需;Arg(精氨酸)虽能合成但量不足,半必需——婴幼儿对 Arg、His 合成不足,需额外补充(共 9 种)。

📌 竞赛要点:必需氨基酸 = 人体不能合成的氨基酸(缺乏相应合成途径)。判断标准不是"营养必需",而是"人体是否具备从头合成该氨基酸碳骨架的酶系"。8 种必需 + His(婴儿)= 9 种。半必需氨基酸指 Arg、His(合成量不足)。

凌云计划要点:必需氨基酸的本质是"人体缺乏其合成途径",必须从食物摄取。8 种:"赖甲苏亮异色缬苯"或"苯缬亮异赖蛋苏色"。婴儿还需 His(共 9 种)。Arg、His 为半必需(婴幼儿合成不足)。注意区分"必需氨基酸"与"生糖/生酮氨基酸"——前者按"能否合成"分类,后者按"碳骨架去路"分类,是两套独立的分类体系。

4.3 一碳单位代谢

一碳单位(one-carbon unit):含有一个碳原子的基团(甲基 —CH₃、亚甲基 —CH₂—、次甲基 =CH—、甲酰基 —CHO、亚胺甲基 —CH=NH、羟甲基 —CH₂OH 等)。它们在代谢中以四氢叶酸(FH4)为载体,在维生素 B12参与下进行转移。

  • 嘌呤合成:C2、C8 来自 N10-甲酰 FH4
  • 嘧啶合成:胸腺嘧啶的甲基来自 N5,N10-亚甲基 FH4
  • 氨基酸代谢:多种相互转化
  • S-腺苷甲硫氨酸(SAM):体内最重要的甲基供体——参与肌酸、磷脂、肾上腺素等的合成

⚠️ 临床延伸:叶酸拮抗剂(如甲氨蝶呤)抑制二氢叶酸还原酶,阻断一碳单位代谢,用于癌症化疗;磺胺类药物抑制细菌叶酸合成,起抗菌作用。

翻译(translation):以 mRNA 为模板,tRNA 携带氨基酸,在核糖体上合成多肽链的过程。翻译是中心法则的最后一步,把核酸语言"翻译"成蛋白质语言。

5.2 遗传密码(genetic code)

遗传密码有 64 个密码子(4³ = 64),编码 20 种氨基酸 + 终止信号:

  • 通用性:几乎所有生物共用同一套密码子(线粒体、叶绿体有少数例外)
  • 简并性(degeneracy):多数氨基酸有多个密码子(密码子的第三位碱基专一性较低,称为"摆动(wobble)")
  • 方向性:5' → 3' 读码,翻译 N 端 → C 端
  • 起始密码子:AUG(编码 Met,真核生物中 fMet 在原核生物中起始)
  • 终止密码子:UAA、UAG、UGA(无对应的 tRNA,称为"无义密码子")

🧬 摆动配对:tRNA 反密码子第一位(5'端)与 mRNA 密码子第三位(3'端)配对时允许"非标准配对"(G-U 配对等),这解释了为什么一种 tRNA 可以识别多个密码子。

六、氨基酸代谢与其他代谢网络的整合

氨基酸代谢不是孤立的——它与糖、脂、核酸代谢通过共同中间物紧密连接:

氨基酸代谢与其他代谢的连接
糖代谢 ↔ 丙酮酸、草酰乙酸、α-酮戊二酸 ↔ 生糖氨基酸
脂代谢 ↔ 乙酰 CoA、乙酰乙酰 CoA ↔ 生酮氨基酸
核苷酸代谢 ↔ 甘氨酸、天冬氨酸、谷氨酰胺 ↔ 嘌呤/嘧啶合成
一碳单位 ↔ FH4、SAM ↔ 核酸甲基化

💡 核心概念:α-酮戊二酸是氨基代谢的中心(接受氨基变成谷氨酸);乙酰 CoA是碳骨架代谢的中心(进入 TCA 循环);SAM是甲基代谢的中心(通用甲基供体)。

📌 ch1-1-10 拓展要点 · 本节小结

  1. UPS 是真核细胞精确调控蛋白浓度的核心机制——E1/E2/E3 三酶级联 + 26S 蛋白酶体,2004 年诺贝尔化学奖;Ciechanover 等发现。
  2. 消化道蛋白酶的激活级联:肠激酶→胰蛋白酶→其他酶原激活——避免胰腺自我消化,这是酶原激活的典型例子。
  3. 联合脱氨基是动物细胞的主要脱氨方式——先转氨(把氨基集中到 α-酮戊二酸变成谷氨酸),再由 L-谷氨酸脱氢酶(唯一活跃的氧化脱氨酶)集中脱氨;α-酮戊二酸是氨基集散中心。组织特异性:肝脏以联合脱氨基为主,骨骼肌以嘌呤核苷酸循环为主。
  4. 嘌呤核苷酸循环(IMP→AMP→IMP+NH₃)是肌肉、脑等 L-谷氨酸脱氢酶活性低的组织的替代脱氨途径。转氨酶辅酶为 PLP(VitB6)。
  5. 生物胺由氨基酸脱羧产生:谷氨酸→GABA(抑制性神经递质)、组氨酸→组胺(过敏介质)、色氨酸→5-HT(血清素)等。
  6. 氨的去路:丙氨酸-葡萄糖循环(Cahill 循环,ALT 催化,= 氨运输 + 糖异生前体运输)+ 谷氨酰胺运氨(血液主要氨载体)+ 尿素循环(肝脏主要解毒)。
  7. 尿素循环 5 步——限速酶 CPS-I(线粒体,NAG 激活;精氨酸→NAGS→NAG→CPS-I 正反馈)+ OTC + 精氨酸代琥珀酸合成酶(第二个 N 来自天冬氨酸)+ 精氨酸代琥珀酸裂解酶 + 精氨酸酶(需 Mn²⁺);消耗 3 ATP(等价 4 高能键)。尿素循环-TCA 双循环:延胡索酸→苹果酸→OAA→天冬氨酸回到尿素循环。
  8. CPS I vs CPS II:CPS I 线粒体、用游离 NH₃、参与尿素循环; CPS II 细胞质、用谷氨酰胺酰胺氮、参与嘧啶合成——常考比较。
  9. 生酮氨基酸只有 Leu、Lys 两种;纯生糖 13 种(Ala、Arg、Asn、Asp、Cys、Gln、Glu、Gly、His、Met、Pro、Ser、Val);兼性 5 种(异亮、苯丙、酪、色、苏)——口诀"两酮亮赖,五兼异苯酪色苏";2025 联赛考过该分类。
  10. 8 种必需氨基酸"赖甲苏亮异色缬苯"或"苯缬亮异赖蛋苏色"(Lys、Met、Thr、Leu、Ile、Trp、Val、Phe)——人体缺乏合成途径,需从食物摄取;婴儿还需 His(共 9 种);Arg、His 为半必需。
  11. 一碳单位由 FH4 携带,丝氨酸是主要来源;SAM 是不经 FH4 的通用甲基供体(ATP 代谢、肌酸合成等)。
  12. 翻译三阶段(起始/延伸/终止):每加 1 个氨基酸消耗 2 ATP(氨酰 tRNA 合成)+ 2 GTP(进位 + 移位)= 4 高能键;23S rRNA 是核酶,催化肽键形成。
  13. 翻译后修饰对蛋白功能至关重要:磷酸化(信号)、糖基化(识别)、乙酰化(组蛋白调控)、羟基化(胶原蛋白,需 VC)、泛素化(降解)、二硫键(稳定结构)。
  14. 氨基酸代谢连接网络:α-酮戊二酸(氨基集散中心)+ 乙酰 CoA(碳骨架中心)+ SAM(甲基中心)——三大枢纽分子将氨基酸与糖、脂、核苷酸代谢连接。
