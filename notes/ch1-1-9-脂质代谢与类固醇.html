一、脂质的酶促水解

1.1 三酰甘油脂肪酶

三酰甘油脂肪酶（triacylglycerol lipase）催化三酰甘油逐步水解：

  1. 三酰甘油 → 二酰甘油 + 脂肪酸（脂肪酶）
  2. 二酰甘油 → 单酰甘油 + 脂肪酸（脂肪酶）
  3. 单酰甘油 → 甘油 + 脂肪酸（单酰甘油脂肪酶）

⚠️ 激素敏感性脂肪酶（HSL）是脂解的限速酶，受 PKA 磷酸化激活。肾上腺素/胰高血糖素 → cAMP ↑ → PKA → HSL 磷酸化激活 → 脂解加速。

1.2 磷脂酶（4 类）

磷脂在 4 个不同位置可被水解，催化酶分别为：

磷脂酶水解位置产物生理意义
磷脂酶 A1（PLA1）C1 酰基溶血磷脂 + 脂肪酸磷脂重塑
磷脂酶 A2（PLA2）C2 酰基溶血磷脂 + 花生四烯酸花生四烯酸是前列腺素/白三烯前体（炎症介质）
磷脂酶 C（PLC）磷酸酯键二酰甘油（DAG）+ 磷酸化头基PI-PLC 水解 PIP₂ → DAG + IP₃（细胞信号双信使）
磷脂酶 D（PLD）磷酸-头基键磷脂酸 + 头基（胆碱/乙醇胺）信号转导
奥赛必背：PLA2 的产物花生四烯酸（arachidonic acid）是前列腺素（PG）、白三烯（LT）、血栓素（TXA₂）的前体。阿司匹林通过乙酰化 COX-1/COX-2（环氧合酶）抑制花生四烯酸→PG/H₂，起到抗炎、抗血小板作用。

二、三酰甘油的分解代谢

2.1 甘油的氧化

甘油经 4 步反应进入糖酵解：

  1. 甘油 + ATP → 甘油-3-磷酸（甘油激酶，肝/肾）
  2. 甘油-3-磷酸 + NAD⁺ → DHAP + NADH（甘油-3-磷酸脱氢酶）
  3. DHAP → 糖酵解/糖异生

2.2 脂肪酸的 β-氧化（核心内容）

β-氧化（β-oxidation）是脂肪酸分解的核心途径，在线粒体基质中进行。每次循环从脂肪酸的 β-碳（从羧基 C1 起的第 3 个碳）开始氧化，最终产生 1 乙酰-CoA + 1 FADH₂ + 1 NADH，并使脂肪酸链缩短 2 个碳。

β-氧化前准备：脂肪酸活化 + 肉碱转运

  1. 脂肪酸活化（胞质）：脂肪酸 + CoA + ATP → 脂酰-CoA + AMP + PPi（脂酰-CoA 合成酶，消耗 2 个高能键）
  2. 肉碱转运系统（关键步骤）：
    • 脂酰-CoA + 肉碱 → 脂酰-肉碱 + CoA（肉碱脂酰转移酶 I（CPT I），位于线粒体外膜）
    • 脂酰-肉碱经肉碱-脂酰肉碱转位酶进入线粒体基质
    • 脂酰-肉碱 + CoA → 脂酰-CoA + 肉碱（肉碱脂酰转移酶 II（CPT II），位于内膜内侧）
    ⚠️ CPT I 是 β-氧化的限速酶，被丙二酰-CoA 强烈抑制（这样脂肪酸合成时不会同时被氧化）

β-氧化 4 步循环（每轮）：

步骤反应催化酶产物/能量
1 脱氢脂酰-CoA → Δ²-反烯脂酰-CoA脂酰-CoA 脱氢酶（FAD 辅基）1 FADH₂
2 水合Δ²-反烯脂酰-CoA + H₂O → L-β-羟脂酰-CoA烯脂酰-CoA 水合酶—
3 再脱氢L-β-羟脂酰-CoA → β-酮脂酰-CoAβ-羟脂酰-CoA 脱氢酶（NAD⁺ 辅酶）1 NADH
4 硫解β-酮脂酰-CoA + HSCoA → 乙酰-CoA + 缩短的脂酰-CoAβ-酮脂酰-CoA 硫解酶1 乙酰-CoA

能量计算：

  • 每轮 β-氧化产生 1 FADH₂（≈1.5 ATP）+ 1 NADH（≈2.5 ATP）= 4 ATP
  • 最终产生的乙酰-CoA 每次进入 TCA 循环产 10 ATP
  • 每轮最终净产 = 4 + 10 = 14 ATP（乙酰-CoA 计入）？不对，乙酰-CoA 是终产物（10 ATP 在下一轮才计）
  • 以软脂酸（C16:0）为例：
    • C16 → 7 轮 β-氧化（每轮缩短 2C）→ 8 乙酰-CoA
    • 活化消耗 2 ATP
    • 7 轮 × (1 FADH₂ + 1 NADH) = 7 × 4 = 28 ATP
    • 8 乙酰-CoA × 10 ATP = 80 ATP
    • 净产 28 + 80 - 2 = 106 ATP
奥赛必背：软脂酸 C16:0 完全氧化净产 106 ATP（注意 16/2 - 1 = 7 轮 β-氧化，产生 8 乙酰-CoA）。记忆："软脂酸 106 葡糖 30/32"。

2.3 特殊脂肪酸的氧化

奇数碳脂肪酸：经 β-氧化最终产生 1 分子丙酰-CoA（3 碳），再经 3 步反应转化为琥珀酰-CoA 进入 TCA：

  1. 丙酰-CoA + CO₂ → 甲基丙二酰-CoA（丙酰-CoA 羧化酶，生物素辅基）
  2. 甲基丙二酰-CoA → 琥珀酰-CoA（甲基丙二酰-CoA 变位酶，需 B₁₂ 辅酶，adoB₁₂）

⚠️ B₁₂ 缺乏时，甲基丙二酰-CoA 不能转化为琥珀酰-CoA，会引起甲基丙二酸尿症（MMA）。

不饱和脂肪酸（含双键）：需要额外的酶：

  • Δ³,⁵-Δ²,⁴-二烯脂酰-CoA 异构酶（处理顺式双键）
  • 2,4-二烯脂酰-CoA 还原酶（处理共轭双键，需 NADPH）

因此不饱和脂肪酸氧化产能较少（双键位置影响）。

支链脂肪酸：如植烷酸（含 3-甲基支链），需先经 α-氧化去掉 1 个碳，再进行 β-氧化。Refsum 病：α-氧化酶缺陷导致植烷酸堆积。

极长链脂肪酸（VLCFA，>C22）：先在过氧化物酶体中进行 β-氧化（缩短到 C8~10 后转运到线粒体继续）。Zellweger 综合征：过氧化物酶体生物合成缺陷导致 VLCFA 堆积。

2.4 酮体的生成和利用

酮体（ketone bodies）是乙酰-CoA 在肝线粒体中生成的小分子中间代谢物，包括：

  1. 乙酰乙酸（acetoacetate）：主要酮体
  2. β-羟丁酸（β-hydroxybutyrate）：乙酰乙酸还原产物（含量最多）
  3. 丙酮（acetone）：乙酰乙酸自发脱羧产物（挥发性，从呼吸道排出）

酮体生成（HMG-CoA 途径）：

  1. 2 乙酰-CoA → 乙酰乙酰-CoA（硫解酶，逆反应）
  2. 乙酰乙酰-CoA + 乙酰-CoA → HMG-CoA（3-羟基-3-甲基戊二酰-CoA）（HMG-CoA 合酶，限速酶，仅肝线粒体）
  3. HMG-CoA → 乙酰乙酸 + CoA（HMG-CoA 裂解酶）
  4. 乙酰乙酸 + NADH → β-羟丁酸（β-羟丁酸脱氢酶）
  5. 乙酰乙酸 → 丙酮 + CO₂（自发脱羧）

酮体的利用（在外周组织线粒体）：

  1. β-羟丁酸 → 乙酰乙酸（β-羟丁酸脱氢酶）
  2. 乙酰乙酸 + 琥珀酰-CoA → 乙酰乙酰-CoA + 琥珀酸（琥珀酰-CoA 转硫酶，心/脑/肾）
  3. 乙酰乙酰-CoA + CoA → 2 乙酰-CoA（硫解酶）→ 进入 TCA

⚠️ 肝生酮，肝不用酮：肝缺乏转硫酶，产生的酮体不能被自己利用；心/脑/肾/骨骼肌有转硫酶可利用酮体。

酮体生成的调控：

  • 饥饿/糖尿病/高脂低糖饮食：肝糖原耗尽 → 大量脂解 → 脂肪酸 β-氧化 ↑ → 乙酰-CoA 堆积 → 进入 TCA 受限（OAA 被消耗）→ 转向酮体生成
  • 临床意义：
    • 饥饿性酮症：长期饥饿（>3 天）→ 脑从葡萄糖供能转为酮体供能（脑每天消耗 120 g 葡萄糖 → 饥饿时节省 80 g）
    • 糖尿病酮症酸中毒：胰岛素缺乏 → 脂肪大量动员 → 酮体生成过多 → 血液 pH < 7.3 → 危及生命
奥赛必背：① 酮体 3 种：乙酰乙酸/β-羟丁酸/丙酮，含量 β-羟丁酸 > 乙酰乙酸 > 丙酮；② 饥饿时脑的主要能量来源是 β-羟丁酸（不是葡萄糖！）；③ 糖尿病酮症酸中毒：呼吸有"烂苹果味"（丙酮挥发）；④ 饥饿 3 天后脂肪成为主要能量来源（>60%）。

三、三酰甘油的合成代谢

3.1 乙酰-CoA 跨膜转运（柠檬酸穿梭）

脂肪酸合成在胞质中进行，但乙酰-CoA 在线粒体基质内产生。线粒体内膜不允许乙酰-CoA 自由通过，需经柠檬酸穿梭：

  1. 线粒体内：乙酰-CoA + OAA → 柠檬酸（柠檬酸合酶）
  2. 柠檬酸经柠檬酸载体运到胞质
  3. 胞质中：柠檬酸 + ATP → 乙酰-CoA + OAA + ADP + Pi（ATP-柠檬酸裂解酶，同时产生 NADPH）
  4. OAA → 苹果酸（胞质苹果酸脱氢酶）
  5. 苹果酸 → 丙酮酸 + CO₂ + NADPH（苹果酸酶，"苹果酸酶"途径）

总效应：1 柠檬酸 → 1 乙酰-CoA + 1 NADPH（ATP-柠檬酸裂解酶）+ 1 NADPH（苹果酸酶）= 1 乙酰-CoA + 2 NADPH（脂肪酸合成需要的"装配原料"）

3.2 脂肪酸合成（FA Synthase 系统）

软脂酸（C16:0）的合成：

第一步：乙酰-CoA → 丙二酰-CoA（限速步骤）

乙酰-CoA + CO₂ + ATP → 丙二酰-CoA + ADP + Pi
（乙酰-CoA 羧化酶（ACC），生物素辅基）

ACC 调控：

  • 变构激活：柠檬酸
  • 变构抑制：长链脂酰-CoA（终产物反馈）
  • 共价调节：磷酸化失活，去磷酸化激活（AMPK 介导）

第二步：脂肪酸合酶（FAS）复合体催化循环

真核生物 FAS 是α₂（同源二聚体）多功能大分子，含 7 种酶活性 + ACP（酰基载体蛋白）。原核生物 FAS 是 7 种独立酶 + ACP。

FAS 循环 4 步（每轮延长 2C）：

  1. 缩合：乙酰-ACP + 丙二酰-ACP → 乙酰乙酰-ACP + CO₂（β-酮脂酰-ACP 合酶（KS））
  2. 还原：乙酰乙酰-ACP → D-β-羟脂酰-ACP（β-酮脂酰-ACP 还原酶，NADPH 供氢）
  3. 脱水：D-β-羟脂酰-ACP → Δ²-反烯脂酰-ACP（脱水酶）
  4. 再还原：Δ²-反烯脂酰-ACP → 脂酰-ACP（烯脂酰-ACP 还原酶，NADPH 供氢）

循环 7 次（共 8 乙酰-CoA：1 起始 + 7 丙二酰-CoA）→ 软脂酰-ACP → 软脂酸（C16:0）

总反应（合成 1 软脂酸）：

8 乙酰-CoA + 7 ATP + 14 NADPH → 软脂酸 + 8 CoA + 7 ADP + 7 Pi + 14 NADP⁺ + 7 CO₂ + 6 H₂O

14 NADPH 来源：6 来自磷酸戊糖途径（G6PD），8 来自苹果酸酶（柠檬酸穿梭）。

奥赛必背：① ACC 是脂肪酸合成的限速酶，受柠檬酸激活、脂酰-CoA 抑制、磷酸化失活；② FAS 的 ACP 摆臂机制使底物在酶活性中心之间穿梭（类似 PDH 的硫辛酸摆臂）；③ 7 轮循环生成 C16:0；④ 软脂酸的延长（C16→C18）由内质网延长酶系统（ELOVL）催化；⑤ 软脂酸的去饱和（引入双键）由硬脂酰-CoA 去饱和酶催化（需 O₂、NADPH、细胞色素 b₅），动物不能引入 Δ9 以上的双键——这就是"必需脂肪酸"亚油酸（Δ9,12 C18:2）和亚麻酸（Δ9,12,15 C18:3）的来源。

3.3 三酰甘油合成

三酰甘油（TAG）合成步骤：

  1. 甘油-3-磷酸 + 脂酰-CoA → 溶血磷脂酸 + CoA（甘油-3-磷酸酰基转移酶，GPAT）
  2. 溶血磷脂酸 + 脂酰-CoA → 磷脂酸 + CoA（1-脂酰甘油-3-磷酸酰基转移酶，AGPAT）
  3. 磷脂酸 + H₂O → 二酰甘油 + Pi（磷脂酸磷酸酶）
  4. 二酰甘油 + 脂酰-CoA → 三酰甘油 + CoA（二酰甘油酰基转移酶（DGAT））

甘油-3-磷酸来源：① 糖酵解的 DHAP（被 G3P 脱氢酶还原）；② 甘油被甘油激酶磷酸化（仅肝/肾）。

四、磷脂代谢（Kennedy 途径）

Kennedy 途径是磷脂合成的经典途径，以 CDP-胆碱/乙醇胺为活化中间物。例：卵磷脂（磷脂酰胆碱，PC）合成：

  1. 胆碱 + ATP → 磷酸胆碱 + ADP（胆碱激酶）
  2. 磷酸胆碱 + CTP → CDP-胆碱 + PPi（CTP-磷酸胆碱胞苷酰转移酶，限速酶）
  3. CDP-胆碱 + 二酰甘油 → 卵磷脂 + CMP（胆碱磷酸转移酶，位于内质网）

脑磷脂（磷脂酰乙醇胺，PE）合成类似（用 CDP-乙醇胺）。

记忆："C→P→CDP→P"：胆碱/乙醇胺 → 磷酸胆碱/乙醇胺 → CDP-胆碱/乙醇胺 → 磷脂。

五、胆固醇代谢

5.1 胆固醇的合成（甲羟戊酸途径）

胆固醇（cholesterol）27 碳，所有动物细胞都能合成，主要在肝（合成量 50%）。从乙酰-CoA 出发，分 5 阶段：

胆固醇合成流程
乙酰-CoA → HMG-CoA → 甲羟戊酸（MVA） → 异戊烯焦磷酸（IPP） → 鲨烯 → 胆固醇
  1. 3 乙酰-CoA → HMG-CoA（与酮体生成前两步相同，但在线粒体 vs 胞质分别进行）
  2. HMG-CoA → 甲羟戊酸（MVA）（HMG-CoA 还原酶（HMGCR），限速酶，2 NADPH 供氢）
  3. MVA → IPP（异戊烯焦磷酸）（MVA 激酶 + MVA 磷酸激酶 + MVA 焦磷酸脱羧酶，消耗 3 ATP）
  4. IPP ↔ DMAPP（异构酶）→ GPP → FPP → 鲨烯（2 FPP 缩合）
  5. 鲨烯 → 羊毛甾醇 → 胆固醇（环化 + 多次氧化还原）

⚠️ HMG-CoA 还原酶（HMGCR）是限速酶，催化：

HMG-CoA + 2 NADPH + 2 H⁺ → MVA + 2 NADP⁺ + CoA

这是不可逆的还原反应，是胆固醇合成的关键调控点。

奥赛必背：HMG-CoA 还原酶是所有降胆固醇药（他汀类）的作用靶点——抑制 HMGCR → 减少胆固醇合成 → 肝 LDL 受体上调 → 血 LDL 降低。常见他汀：洛伐他汀、辛伐他汀、阿托伐他汀等。

5.2 胆固醇的代谢去路

胆固醇的去路：

  1. 胆汁酸：肝中胆固醇经 7α-羟化酶（限速酶）催化生成胆酸（cholic acid）和鹅去氧胆酸，与甘氨酸/牛磺酸结合形成胆汁酸盐，促进脂质消化吸收
  2. 类固醇激素：肾上腺皮质激素（醛固酮、皮质醇）、性激素（雌激素、雄激素、孕激素）——前体是胆固醇经孕烯醇酮 → 各种激素
  3. 维生素 D₃：胆固醇 → 7-脱氢胆固醇（7-DHC）→ 紫外线 → 维生素 D₃
  4. 胆固醇酯：ACAT（脂酰-CoA-胆固醇酰基转移酶）催化胆固醇 + 脂酰-CoA → 胆固醇酯（储存于脂滴或 HDL/LDL 内）
  5. 胆色素：血红素分解产物（间接胆红素）

5.3 胆固醇的转运：LDL/HDL

胆固醇通过脂蛋白在血液中运输。主要脂蛋白：

脂蛋白密度 (g/mL)直径 (nm)主要功能

VLDL0.95~1.00630~80从肝运甘油三酯到外周组织
IDL1.006~1.01925~35VLDL → LDL 的中间体

⚠️ LDL 受体：介导细胞摄取 LDL 颗粒（含 apoB-100）。家族性高胆固醇血症（FH）：LDL 受体基因突变导致 LDL 不能被摄取 → 血胆固醇极高 → 早发动脉粥样硬化。Brown 和 Goldstein 因发现 LDL 受体获 1985 年诺贝尔奖。

六、脂代谢与其他代谢的整合

6.1 饥饿时的代谢适应

饥饿时（>12 小时未进食）的代谢调整：

  1. 0~4 小时（吸收期）：血糖↑ → 胰岛素↑ → 糖原合成↑、脂质合成↑
  2. 4~16 小时（糖原分解期）：血糖↓ → 胰高血糖素↑ → 肝糖原分解↑
  3. 16~48 小时（糖异生期）：肝糖原耗尽 → 糖异生↑（氨基酸、甘油 → 葡萄糖）
  4. 2~3 天后（酮体期）：脂肪大量动员 → β-氧化↑ → 乙酰-CoA↑ → 酮体↑ → 脑开始利用酮体
  5. 长期饥饿（>5 天）：肾糖异生↑、蛋白分解↓（保氮）、脑主要靠酮体（节省葡萄糖）

6.2 糖尿病时的代谢异常

1 型糖尿病（胰岛素绝对缺乏）：

  • 血糖↑（不能被细胞摄取）
  • 脂肪大量动员 → 肝 β-氧化↑ → 乙酰-CoA↑ → 酮体↑ → 酮症酸中毒
  • 蛋白分解↑ → 肌肉萎缩
  • 糖异生↑ → 血糖进一步升高

2 型糖尿病（胰岛素抵抗）：常伴肥胖、高血压、高血脂（"代谢综合征"）。

📌 ch1-1-9 拓展要点 · 本节小结

  1. 4 类磷脂酶：PLA1（C1 酰基）/ PLA2（C2 酰基，释花生四烯酸）/ PLC（磷酸酯键，释 DAG + IP₃）/ PLD（磷酸-头基键）。PLA2 产物是 PG/LT/TXA 前体；阿司匹林抑制 COX。
  2. β-氧化 4 步循环：脱氢（FADH₂）+ 水合 + 再脱氢（NADH）+ 硫解（乙酰-CoA）。每轮 4 ATP（1.5 + 2.5），最终乙酰-CoA 进 TCA 产 10 ATP。软脂酸 C16:0 净产 110 ATP。
  3. CPT I 是 β-氧化限速酶（位于线粒体外膜），被丙二酰-CoA 强抑制。肉碱转运是脂酰-CoA 进入线粒体的关键步骤。
  4. 奇数碳 / 不饱和 / 支链脂肪酸：奇数碳最终产生丙酰-CoA → 甲基丙二酰-CoA → 琥珀酰-CoA（需 B₁₂ 辅酶）。不饱和脂肪酸需要额外异构酶/还原酶。植烷酸需先 α-氧化（Refsum 病）。VLCFA 先在过氧化物酶体氧化（Zellweger 综合征）。
  5. 酮体 3 种：乙酰乙酸 / β-羟丁酸 / 丙酮。HMG-CoA 合酶是肝线粒体生酮的限速酶。肝生酮、肝不用酮（缺转硫酶）。饥饿/糖尿病时酮体↑，脑从葡萄糖供能转为酮体供能。
  6. 脂肪酸合成（FA Synthase）：① 乙酰-CoA → 丙二酰-CoA（ACC 催化，限速步骤）；② FAS 循环 4 步（缩合/还原/脱水/再还原）7 轮产生 C16:0；③ ACP 摆臂机制；④ 总反应：8 乙酰-CoA + 7 ATP + 14 NADPH → 软脂酸。
  7. ACC 调控：柠檬酸激活、脂酰-CoA 抑制、磷酸化失活（AMPK 介导）。
  8. Kennedy 途径（磷脂合成）：胆碱/乙醇胺 → 磷酸胆碱/乙醇胺 → CDP-胆碱/乙醇胺 → 磷脂。CTP-磷酸胆碱胞苷酰转移酶是限速酶。
  9. 胆固醇合成（甲羟戊酸途径）：乙酰-CoA → HMG-CoA → MVA → IPP → 鲨烯 → 胆固醇。HMGCR（限速酶）是降胆固醇药（他汀类）靶点。
  10. 胆固醇代谢去路：胆汁酸（7α-羟化酶）/ 类固醇激素 / 维生素 D₃ / 胆固醇酯 / 胆色素。7-DHC 经 UV 照射 → 维生素 D₃。
  11. 脂蛋白转运：CM（肠→外周）/ VLDL（肝→外周）/ LDL（外周，apoB-100）/ HDL（外周→肝）。Brown & Goldstein 1985 诺奖（LDL 受体，FH 病）。
  12. 饥饿代谢适应：0-4h 吸收 → 4-16h 糖原分解 → 16-48h 糖异生 → 2-3 天后酮体（脑节能）→ >5 天肾糖异生↑、保氮。
  13. 乙酰-CoA 是三大物质代谢的"十字路口"：糖→乙酰-CoA（PDH）、脂→乙酰-CoA（β-氧化）、氨基酸→乙酰-CoA。乙酰-CoA 去向：TCA / 脂肪酸合成 / 胆固醇合成 / 酮体 / 乙酰胆碱 / N-乙酰化。
