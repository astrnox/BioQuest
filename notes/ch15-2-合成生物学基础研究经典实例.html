第二节

合成生物学基础研究经典实例

本节通过 4 个经典实例展示合成生物学"理性设计→建模→构建→验证"的标准流程：

  1. 双稳态开关：Gardner 2000，Nature。
  2. Repressilator 振荡器：Elowitz & Leibler 2000，Nature。
  3. 逻辑门（AND / OR）：基因线路的逻辑运算。
  4. 人工多细胞图案系统：Weiss 2005，Nature。
2000 年是合成生物学 元年：Gardner 与 Elowitz 同期在 Nature 发表开山论文。

一、在大肠杆菌中构建双稳态开关（Toggle Switch）

双稳态开关（toggle switch）由 Gardner, Cantor, Collins 2000 在 Nature 上发表（DOI: 10.1038/35002131），是大肠杆菌中第一个"工程化基因线路"。

研究意义：

  • 首次在活细胞中实现 双稳态（bistability），相当于电子工程中的"SR 锁存器"。
  • 证明基因线路可以具有 记忆 能力——细胞"记住"上一次的诱导信号。
  • 开启了合成生物学"基因线路"研究方向。
双稳态 = 两个稳定状态 + 状态间的可切换性。Gardner 2000 是基因线路的开山之作。

（一）基因线路设计

双稳态开关由 两个相互抑制的转录抑制子 组成：

  • lacI（乳糖操纵子抑制子）抑制 tetR 启动子 Ptrc-2 → 控制 tetR 表达；
  • tetR（四环素操纵子抑制子）抑制 lacI 启动子 PLlacO-1 → 控制 lacI 表达；
  • 每个抑制子也控制一个报告基因（gfp 或 lacZ）。

结果：

  • 高 lacI / 低 tetR 状态 = "绿"状态（GFP 亮）
  • 低 lacI / 高 tetR 状态 = "暗"状态（GFP 暗）
  • 两个状态都稳定，细胞群呈现"全亮"或"全暗"两种表型。
lacI ⊣ tetR，tetR ⊣ lacI：两个抑制子互相抑制，形成正反馈 + 负反馈的混合环路。
分子机理：lacI 蛋白结合 PLlacO-1 启动子阻遏 tetR 转录；tetR 蛋白结合 Ptrc-2 启动子阻遏 lacI 转录。当一个抑制子升高，会进一步抑制另一个，形成"互抑"的双稳态结构。这种互抑结构在数学上等价于"非单调动力学的双吸引子"。

（二）基因线路实现

为了实现设计的基因线路逻辑功能，必须选择恰当的基因功能模块：

  • 抑制子选择：选择 lacI 和 tetR 这两个相互正交的转录抑制子，互不干扰。
  • 启动子选择：PLlacO-1 启动子（含 lacO 操纵位点）受 lacI 抑制；Ptrc-2 启动子（含 tetO 操纵位点）受 tetR 抑制。
  • 诱导剂：用 IPTG 抑制 lacI（解阻遏 tetR）；用 aTc（无水四环素）抑制 tetR（解阻遏 lacI）。
  • 质粒系统：两个独立的相容性质粒（pIKE 质粒系统），分别表达 lacI/PLlacO 调控单元和 tetR/Ptrc 调控单元。
正交化（orthogonalization）：选择的两个抑制子互不干扰，是合成生物学 模块化 的基础。

（三）数学模型建立

用 ODE 模型 描述双稳态：

  • 设 u = lacI 浓度，v = tetR 浓度；
  • du/dt = α₁ / (1 + vⁿ) - u
  • dv/dt = α₂ / (1 + uⁿ) - v
  • 其中 α₁, α₂ 为基础转录速率，n 为 Hill 系数，· 表示归一化降解。

双稳态特性：

  • 当 α₁ = α₂ 且 n > 1 时，系统有两个稳定平衡点（对称双稳态）；
  • 在外界诱导下，可在两个稳定点之间切换；
  • 这与电子工程中的 施密特触发器（Schmitt trigger） 类似。
Hill 系数 n > 1：协同结合，是双稳态出现的关键参数。

（四）功能检测

用 流式细胞仪（flow cytometry） 检测 GFP 荧光分布，实验结果：

  • 未经诱导：细胞群呈 双峰分布，一部分亮、一部分暗（自发的双稳态）；
  • IPTG 诱导：所有细胞切换到"亮"状态（lacI 被抑制 → tetR 表达 → 抑制解除 → GFP 表达）；
  • aTc 诱导：所有细胞切换到"暗"状态；
  • 诱导去除后：细胞保持新状态数小时甚至数代——证明 遗传记忆（genetic memory）。
双稳态开关是 细胞存储器 的雏形：去诱导剂后状态可保持多代。

二、构建 Repressilator 基因振荡器

Repressilator（合成振荡器）由 Elowitz & Leibler 2000 在 Nature 上发表（DOI: 10.1038/35002125），是合成生物学的另一开山之作。

研究意义：

  • 首次在活细胞中实现 自激振荡（self-sustained oscillation）。
  • 证明 合成的转录调控网络 也能产生节律性行为。
  • 为人工合成昼夜节律（circadian rhythm）系统铺平道路。
Repressilator 名称来自 repress（抑制）+ oscillator（振荡器），后缀 -ilator 模仿 oscillator。

（一）基因线路设计

Repressilator 由 三个转录抑制子首尾相连 形成 自激振荡环（repressilator ring）：

  • tetR → 抑制 lacI 启动子；
  • lacI → 抑制 cI 启动子（λ 噬菌体抑制子）；
  • cI → 抑制 tetR 启动子。

动力学：

  • tetR 升高 → 抑制 lacI → lacI 降低 → 解阻遏 cI → cI 升高 → 抑制 tetR → tetR 降低 → 解阻遏 lacI → lacI 升高 → 抑制 cI → cI 降低 → 解阻遏 tetR → tetR 升高……循环。
  • 三个蛋白浓度随时间正弦振荡，周期约 2–3 小时（远慢于细胞分裂 30 min，因此可以观察到完整周期）。
三节点环是 最小 的转录振荡器，奇数节点才会振荡（偶数节点会稳定在某一状态）。

（二）功能检测

在三个基因下游分别加 荧光报告基因（gfp / cfp / yfp），用流式细胞仪 + 时间序列显微镜观察：

  • 荧光检测结果：在不考虑细胞分裂因素的情况下，GFP 荧光随时间呈正弦振荡，周期约 150 min。
  • 细胞间同步性：早期实验仅约 40% 细胞同步振荡，提示噪声（noise）是合成振荡器的主要挑战。
  • 后继改进：Elowitz 2002 通过引入正反馈 + 加快蛋白降解（ssrA 降解标签）提高同步性；Stricker 2008 实现周期约 13 min 的快速振荡；Danino 2010 实现群体同步的"群体振荡器"。
Repressilator 是 合成节律系统 的原型，对研究昼夜节律、细胞周期有启发意义。

三、逻辑门功能基因线路

用基因线路实现 电子工程中的逻辑运算（AND、OR、NOT、NAND 等），是合成生物学"程序化细胞"的基础。常见逻辑门：

  • 与门（AND）：两个输入信号（A AND B）同时存在时，输出激活。
  • 或门（OR）：两个输入信号（A OR B）任一存在时，输出激活。
  • 非门（NOT）：输入信号存在时，输出被抑制；输入不存在时，输出默认激活。
  • 与非门（NAND）：NOT(AND)，全宇宙通用逻辑门——任何布尔函数都可由 NAND 复合而成。
NAND 完备性：NAND 是 功能完备 的逻辑元件，理论上可组成任何数字电路。

逻辑"与"门（AND gate）

经典设计（Anderson 2007, Weiss lab）：

  • 两个启动子分别响应输入 A 和输入 B（正交的转录激活）；
  • 每个启动子下游表达一个转录激活子（act1 和 act2）；
  • 输出基因的启动子需要 act1 和 act2 共同结合才能激活（类似 真核增强子 机制）。

真值表：

  • A=0, B=0 → 输出 0
  • A=1, B=0 → 输出 0
  • A=0, B=1 → 输出 0
  • A=1, B=1 → 输出 1
AND gate：两信号 协同 才能激活输出，类似真核基因的"双重增强子"。

逻辑"或"门（OR gate）

经典设计：

  • 两个启动子分别响应输入 A 和输入 B；
  • 两个启动子分别独立驱动 同一个输出基因；
  • 任一启动子激活即可表达输出。

真值表：

  • A=0, B=0 → 输出 0
  • A=1, B=0 → 输出 1
  • A=0, B=1 → 输出 1
  • A=1, B=1 → 输出 1
OR gate：两信号 任一 即可激活输出，是最简单的合成门。
其他常见逻辑门：① NOT gate（抑制子 + 启动子）；② NAND（两个 NOT 的串联 + 整合）；③ NOR（NOT 抑制子 + 双输入启动子）；④ XOR（异或，需要更复杂线路，如可逆启动子开关）。MIT 的 Cello 软件 2016 年可自动设计 60+ 逻辑门线路。

四、人工多细胞图案系统

人工多细胞图案系统（synthetic multicellular pattern） 由 Weiss Lab 2005（Basu, Gerchman, Collins 等）在 Nature 上发表（DOI: 10.1038/nature04311）。

研究意义：

  • 首次在 大肠杆菌菌落 上实现 人工图案（synthetic pattern）——如条纹、斑马纹、棋盘格等。
  • 证明 群体感应（quorum sensing, QS） 系统可被工程化用于细胞间通讯。
  • 为 合成发育生物学、合成组织工程 铺平道路。
群体感应（QS）：细胞通过分泌/感应小分子（AHL、AI-2）实现"细胞数"感知。是 原核版的细胞通讯。

基因线路设计

两种工程化菌株 + 群体感应：

  • "发送者"菌（sender）：合成群体感应分子 AHL（乙酰高丝氨酸内酯），受阿拉伯糖启动子 PBAD 控制。
  • "接收者"菌（receiver）：在 AHL 浓度足够时激活 gfp 表达。

机理：

  • Sender 持续产生 AHL，AHL 在琼脂平板上扩散形成浓度梯度；
  • Receiver 距离 sender 越近，AHL 浓度越高，GFP 越亮；
  • 距离越远，GFP 越暗；
  • 在混合菌落（sender + receiver）上形成 空间 GFP 梯度，呈现条纹、圆环等图案。
AHL 扩散 + 阈值响应 = 经典 Turing 形态发生模式（reaction-diffusion）。

功能检测

实验结果：

  • 在混合 sender + receiver 的琼脂平板上，可见绿色荧光环，环宽约 1–2 mm；
  • 改变阿拉伯糖浓度、菌落密度、AHL 合成酶拷贝数等参数，可获得多种形状颜色区域；
  • 在双色实验中（GFP + RFP），可形成 红绿相间的棋盘格。
Turing 1952 提出"反应-扩散"形态发生模型，Basu 2005 用合成生物学验证了该模型。

本节核心要点

  • 双稳态开关（Gardner 2000）：两个互抑抑制子（lacI ⊣ tetR，tetR ⊣ lacI），具有遗传记忆，是合成生物学开山之作。
  • Repressilator（Elowitz 2000）：三节点环（tetR → lacI → cI → tetR），周期约 150 min，是合成振荡器原型。
  • 逻辑门：AND（双重激活）、OR（任一激活）、NAND（功能完备）、XOR（异或）。MIT Cello 2016 自动设计 60+ 逻辑门。
  • 多细胞图案（Basu 2005）：sender 产 AHL + receiver 感应 AHL + GFP 报告，菌落上呈现条纹、圆环、棋盘格图案，验证 Turing 反应-扩散模型。
