第四节 细胞癌变

第四节

细胞癌变

一、癌细胞的概念与基本特征

细胞癌变（cell carcinogenesis）是指正常细胞在致癌因子的作用下，转变为不受控制增殖的癌细胞的过程。

癌细胞（cancer cell）是在个体发育过程中或在某些外界因素作用下，部分细胞因基因突变而失去对正常增殖调控的反应，获得无限增殖能力并具有浸润性和转移性的恶性细胞。

癌细胞与正常细胞的差异——6 大特征：

1. 细胞永生复制和无限增殖：

  • ① 突破 Hayflick 界限：癌细胞可无限分裂（端粒酶重新激活，端粒不缩短）
  • ② 失去接触抑制：正常细胞在单层培养时形成单层后停止分裂；癌细胞可继续堆积形成多层
  • ③ 对生长因子的依赖性降低：即使没有外部生长因子也能增殖
  • ④ 在低血清/无血清条件下仍能增殖
  • ⑤ 缺乏程序性死亡（凋亡）的正常触发机制
  • ⑥ 可在悬浮条件下（软琼脂）形成集落——"锚定非依赖性生长"
  • ⑦ 端粒酶活性恢复 → 端粒不缩短 → 无限分裂

2. 易分散、易转移、能侵入：

  • 癌细胞间黏附力降低（E-钙黏蛋白减少）→ 易从原发部位脱落
  • 分泌基质金属蛋白酶（MMP）→ 降解基底膜和细胞外基质 → 浸润周围组织
  • 进入血管/淋巴管 → 随循环到达远端器官 → 转移（metastasis）
  • 新位点形成继发性肿瘤（secondary tumor）

3. 细胞形态发生显著变化：

  • 细胞大小不等、形态不规则（多形性）
  • 细胞核增大、核质比↑、核仁大且多
  • 染色质深染、染色体畸变
癌细胞的"6 大特征"中，"无限增殖 + 转移性"是其恶性本质。端粒酶重新激活是癌细胞的"分子开关"。

4. 细胞质膜产生了新的抗原：

  • 细胞膜上出现新抗原（肿瘤特异性抗原 TSA）
  • 丢失了某些正常抗原
  • 膜糖蛋白糖基化不完全（糖链缩短或分支减少）
  • MHC-抗原复合物异常
  • 免疫系统可识别这些新抗原（用于免疫治疗）

5. 基因组的不稳定性和核型的改变：

  • 染色体数目异常（非整倍体）
  • 染色体结构异常（易位、缺失、重复、倒位）
  • DNA 修复机制缺陷（错配修复基因突变）
  • 突变率高，是正常细胞的 10-100 倍

6. 细胞能量代谢异常：Warburg 效应

  • 即使在有氧条件下，癌细胞仍以糖酵解为主（有氧糖酵解），产生大量乳酸
  • 1924 年 Otto Warburg 提出：癌细胞线粒体功能损伤 → 糖酵解↑
  • 现代修正：癌细胞主动选择糖酵解（更快产生 ATP、产生生物合成前体）
  • 谷氨酰胺代谢↑：通过 ASCT2 转运体吸收 → 产生 α-酮戊二酸 → 进入三羧酸循环
  • Warburg 效应是 PET 显像的基础（¹⁸F-FDG 在肿瘤部位浓集）
Warburg 效应是癌细胞代谢重塑的核心。PET-CT 利用 ¹⁸F-FDG（葡萄糖类似物）显示高代谢肿瘤。

二、原癌基因、抑癌基因与癌基因

参与细胞生长调控的蛋白质可分为 7 大类：（详见下表）

类别功能举例
① 生长因子（growth factor）分泌型信号分子EGF、FGF、PDGF
② 生长因子受体跨膜受体（RTK）EGFR、PDGFR
③ 信号转导蛋白细胞内信号分子Ras（GTP 结合蛋白）、Src（酪氨酸激酶）
④ 转录因子/转录调节因子调控基因表达Myc、Jun、Fos
⑤ 抗凋亡蛋白抑制细胞凋亡Bcl-2
⑥ 细胞周期控制蛋白驱动细胞分裂Cyclin D、CDK4
⑦ DNA 修复蛋白维持基因组稳定性p53、BRCA1/2、ATM

这 7 类蛋白质在正常细胞中协同工作，调控增殖、凋亡和基因组稳定性。每一类蛋白的基因突变都可能导致细胞癌变。

7 类蛋白是癌症研究的"7 大靶点"。针对每类蛋白都开发了相应药物（如 EGFR 抑制剂治疗肺癌、CDK4/6 抑制剂治疗乳腺癌）。

（一）原癌基因（proto-oncogene）：

原癌基因是正常细胞中存在的、促进细胞生长增殖的基因，是正常生命活动所必需的（如调控细胞分裂、分化、凋亡）。

原癌基因突变或异常激活后变成癌基因（oncogene），导致细胞癌变。

原癌基因激活的 4 大机制：

  1. ① 点突变：单个碱基改变导致蛋白质活性异常增高。如 Ras 蛋白的点突变（12 位甘氨酸→缬氨酸）→ GTP 酶活性丧失 → 持续激活下游信号通路
  2. ② 基因扩增：基因拷贝数增加（正常 2 个变成几十到几百个）→ 蛋白表达量大幅增加。如 N-myc 在神经母细胞瘤中扩增 100-1000 倍
  3. ③ 基因重排（染色体易位）：原癌基因易位到强启动子附近 → 转录增加。如 Burkitt 淋巴瘤中 c-myc 易位到免疫球蛋白启动子下游，高表达导致 B 细胞癌变
  4. ④ 病毒强启动子插入：逆转录病毒整合到原癌基因附近，病毒强启动子驱动原癌基因高表达。如 RSV 病毒的 v-src

原癌基因产物分类：

  • 生长因子类：sis（PDGF-B 链同源）
  • 生长因子受体类：erbB（EGFR 同源）、erbB2/neu/HER2
  • 信号转导类：ras（GTP 结合蛋白）、src（酪氨酸激酶）
  • 转录因子类：myc、myb、jun、fos
  • 抗凋亡类：bcl-2
  • 细胞周期类：cyclin D、CDK4
原癌基因激活的"4 大机制"：点突变、扩增、重排、病毒启动子插入。Ras 突变在约 30% 人类肿瘤中存在。

（二）抑癌基因（tumor suppressor gene）/ 抗癌基因：

抑癌基因是正常细胞中存在的、抑制细胞过度增殖或促进细胞凋亡的基因。

抑癌基因失活（突变、缺失）会导致细胞癌变。抑癌基因的失活通常是"隐性"的——需要两个等位基因都失活（纯合失活）才致癌（"二次打击假说"，Knudson 1971）。

主要抑癌基因：

  • Rb（视网膜母细胞瘤基因）：第一个被克隆的抑癌基因（1986）。Rb 蛋白低磷酸化时与 E2F 结合，抑制细胞从 G₁→S。Rb 磷酸化后释放 E2F，启动 DNA 复制。Rb 失活 → 细胞周期失控
  • p53："基因组卫士"。在 50% 以上的人类肿瘤中突变。p53 功能：① DNA 损伤时激活 p21 → 抑制 CDK2/4 → G₁ 期阻滞；② 激活 DNA 修复基因；③ 损伤无法修复则激活凋亡（Bax、PUMA）
  • BRCA1/2：DNA 双链断裂的同源重组修复，与乳腺癌、卵巢癌相关
  • PTEN：磷酸酶，抑制 PI3K-AKT 信号通路
  • APC：结肠癌中的关键抑癌基因，调控 Wnt 信号通路
  • NF1：Ras GAP，促进 Ras-GTP 水解
  • VHL：肾癌相关，调控 HIF 降解

Rb 调控细胞周期的机制：

  • G₁ 早期：Rb 与 E2F 结合，抑制转录，细胞停滞在 G₁
  • G₁ 后期：Cyclin D-CDK4/6 磷酸化 Rb → 部分释放 E2F
  • G₁/S 转换：Cyclin E-CDK2 进一步磷酸化 Rb → 完全释放 E2F → 启动 DNA 复制基因
  • Rb 突变失活 → E2F 持续释放 → 细胞周期失控 → 癌变
原癌基因是"油门"——单突变激活（显性）；抑癌基因是"刹车"——双突变失活（隐性）。p53 是人类肿瘤中突变率最高的抑癌基因（约 50%）。

（三）原癌基因 vs 抑癌基因比较：

"油门/刹车"模型：原癌基因是油门（加法），抑癌基因是刹车（减法）。癌细胞 = 油门卡死 + 刹车失灵。

（四）病毒癌基因（v-onc）与细胞癌基因（c-onc）：

1911 年 Rous 发现鸡肉瘤病毒（Rous sarcoma virus, RSV）能致癌——这是第一个被发现的肿瘤病毒，Rous 获 1966 年诺奖。

逆转录病毒的癌基因起源于宿主细胞的原癌基因：

  • 病毒 RNA → 逆转录为病毒 DNA → 整合到宿主 DNA
  • 病毒 DNA 与宿主原癌基因重组 → 病毒癌基因（v-onc）
  • v-onc 突变成强致癌形式（缺失调控区 + 突变）
  • v-src（来自 RSV）是第一个被鉴定的病毒癌基因

病毒癌基因（v-onc）与细胞原癌基因（c-onc）的同源性证实了"病毒癌基因来自细胞原癌基因"的假说。

主要病毒癌基因：

v-onc来源/同源 c-onc病毒相关肿瘤
v-srcc-srcRSV（鸡肉瘤病毒）鸡肉瘤
v-mycc-mycMC29（鸡髓细胞瘤病毒）鸡髓细胞瘤
v-rasc-ras鼠肉瘤病毒鼠肉瘤
v-erbBc-erbB（EGFR）鸡成红细胞增多症病毒鸡红细胞增多症
v-sisc-sis（PDGF-B）猴肉瘤病毒猴肉瘤
病毒癌基因起源 = 病毒劫持了细胞的原癌基因，并在病毒复制过程中发生突变成为强致癌形式。这一发现连接了病毒学和癌症研究。

三、肿瘤的发生是基因突变逐渐积累的结果

癌症是一种多基因突变逐渐积累的体细胞遗传病。单个基因突变一般不会致癌，需要 3-7 个原癌基因/抑癌基因突变的累积。

（一）肿瘤发生的"二次打击"学说（Knudson 1971）：

  • 视网膜母细胞瘤的遗传型和散发型都符合"两次打击"模型
  • 遗传型：第一次打击来自父母（生殖细胞突变）→ 出生时一个等位基因已失活；第二次打击发生在体细胞（体细胞突变）→ 发病早（多灶性、双侧）
  • 散发型：两次打击都发生在体细胞 → 发病晚（单灶性、单侧）

（二）肿瘤发生的多阶段模型：

  • ① 启动期（initiation）：单个细胞发生不可逆的基因突变（致癌因子作用）
  • ② 促进期（promotion）：启动细胞在促癌剂作用下克隆扩增
  • ③ 进展期（progression）：进一步突变积累 → 恶性表型（侵袭、转移）

（三）家族性癌症与遗传性肿瘤综合征：

  • Li-Fraumeni 综合征：p53 胚系突变 → 多种肿瘤早发
  • 家族性乳腺癌：BRCA1/2 胚系突变
  • 家族性结肠息肉（FAP）：APC 胚系突变 → 结肠多发息肉 → 癌变
  • 遗传性视网膜母细胞瘤：Rb 胚系突变
  • 着色性干皮病（XP）：DNA 修复基因突变 → 紫外线易致皮肤癌
Knudson 二次打击学说是肿瘤遗传学的奠基理论。家族性癌症综合征是研究抑癌基因的"金矿"。

四、肿瘤干细胞（Cancer Stem Cells, CSC）

肿瘤干细胞（tumor stem cell, TSC）是肿瘤中具有自我更新能力、多向分化潜能、能够驱动肿瘤形成和维持肿瘤生长的一小群细胞。

（一）肿瘤干细胞的研究与发现：

  • 1958 年 Hamburger 和 Salmon 提出肿瘤中存在"干细胞样"细胞
  • 1994 年 John Dick 首次在急性髓性白血病（AML）中证实肿瘤干细胞的存在
  • 后陆续在多种实体瘤（脑胶质瘤、乳腺癌、结肠癌、胰腺癌等）中发现 CSCs
  • 肿瘤组织中只有约 1% 的细胞是肿瘤干细胞

（二）肿瘤干细胞的来源：

  • ① 正常干细胞积累致癌突变 → 转化形成
  • ② 已分化的祖细胞去分化 + 突变获得干细胞特性
  • ③ 体细胞融合（罕见）

（三）肿瘤干细胞的生物学特征：

  • ① 自我更新能力（不对称分裂产生 CSC + 分化细胞）
  • ② 多向分化潜能（分化为多种肿瘤细胞）
  • ③ 高致瘤性（少量细胞即可在小鼠中形成肿瘤）
  • ④ 抗凋亡（高表达 Bcl-2 等抗凋亡蛋白）
  • ⑤ 常处于 G₀ 静止期（对常规化疗不敏感）
  • ⑥ 高表达 ABC 转运蛋白（如 ABCG2），将化疗药物泵出 → 耐药
  • ⑦ 高表达端粒酶、DNA 修复能力强
  • ⑧ 特异性表面标志物（CD44、CD133、CD34 等）

（四）肿瘤干细胞是恶性肿瘤复发和转移的根本原因：

  • 常规化疗主要杀死肿瘤组织中快速增殖的细胞（"主体"细胞），而 CSC 因处于 G₀ 静止期，存活下来
  • 残留 CSC 重新增殖 → 肿瘤复发
  • CSC 进入血管/淋巴管 → 转移
  • 因此，有效治疗必须清除肿瘤干细胞
肿瘤干细胞是肿瘤的"种子细胞"，是肿瘤复发和转移的根源。常规化疗对 CSC 效果差，需要开发针对 CSC 的特异疗法（如表面标志物 CAR-T）。

五、致癌因子（Carcinogens）

致癌因子是指能引起细胞癌变的各种因素，可分为三大类：

（一）化学致癌因子：

  • ① 烷化剂：氮芥、硫芥、环磷酰胺、苯丁酸氮芥（化疗药，但本身也是致癌物）
  • ② 多环芳烃（PAH）：3,4-苯并芘、3-甲基胆蒽、煤焦油、沥青、烟草烟雾（烟碱/尼古丁）、烧烤食物
  • ③ 芳香胺类：联苯胺、β-萘胺（导致膀胱癌）
  • ④ 亚硝胺类：亚硝酸盐 + 二甲胺（腌制食物、隔夜菜）
  • ⑤ 霉菌毒素：黄曲霉素 B1（AFB1），是已知最强的化学致癌物之一，导致肝细胞癌。常污染花生、玉米
  • ⑥ 金属致癌物：砷、铬盐、镍、镉、铍
  • ⑦ 其他：苯（白血病）、四氯化碳（肝癌）、焦油（肺癌）、有机氯杀虫剂、激素类（如己烯雌酚致阴道癌）

（二）物理致癌因子：

  • ① 电离辐射：X 射线、γ 射线、α 粒子、β 粒子、中子。损伤 DNA（双链断裂、碱基脱落）。居里夫人因长期接触镭而死于白血病，是著名案例
  • ② 紫外线（UV）：UVB（280-315 nm）使相邻嘧啶形成嘧啶二聚体（TT、CC、CT），导致 DNA 损伤。着色性干皮病（XP）患者因 DNA 修复缺陷而对 UV 极度敏感 → 皮肤癌
  • ③ 其他：石棉纤维、矿物粉尘（致间皮瘤）

（三）病毒致癌因子（生物致癌因子）：

  • ① DNA 肿瘤病毒：
    • HPV（人乳头瘤病毒）16/18 → 宫颈癌（E6/E7 蛋白分别降解 p53 和 Rb）
    • EBV（EB 病毒）→ 鼻咽癌、Burkitt 淋巴瘤
    • HBV（乙肝病毒）→ 肝细胞癌（慢性炎症机制）
  • ② RNA 肿瘤病毒（逆转录病毒）：
    • HTLV-1（人 T 细胞白血病病毒）→ 成人 T 细胞白血病
    • HIV 不直接致癌，但免疫抑制增加 Kaposi 肉瘤等机会性肿瘤

约 15% 的人类癌症由肿瘤病毒引起。

致癌因子"三巨头"：化学（黄曲霉素最强）、物理（UV/电离辐射）、生物（HPV/EBV/HBV）。HPV 疫苗是预防宫颈癌的有效手段。

（四）致癌因子的共同特点：

  • ① 引起 DNA 损伤（突变、断裂、交联）
  • ② 通常需要长期、反复作用（剂量-效应、时间-效应）
  • ③ 致癌过程是多阶段、多基因参与的
  • ④ 个体对致癌因子的敏感性不同（与代谢酶活性、DNA 修复能力、免疫状态有关）
"吸烟者肺癌发病率提高 11 倍"——一个具体的致癌因子流行病学数据。戒烟是降低肺癌风险最有效的方法。

六、癌细胞代谢：Warburg 效应

Warburg 效应（Warburg effect）：1924 年 Otto Warburg 发现，癌细胞即使在有氧条件下，仍以糖酵解为主进行能量代谢，产生大量乳酸。

经典 Warburg 理论：癌细胞线粒体功能损伤 → 有氧呼吸↓ → 糖酵解↑

现代修正观点：癌细胞是主动选择糖酵解（而不是被迫）：

  • ① 糖酵解 ATP 产生速度比有氧呼吸更快（虽然产量低）
  • ② 糖酵解中间产物可作为生物合成前体（核苷酸、脂质、氨基酸）
  • ③ 乳酸产生 → 微环境酸化 → 利于肿瘤侵袭和免疫逃逸
  • ④ 避免产生过多 ROS（保护癌细胞）

谷氨酰胺代谢（glutaminolysis）：

  • 癌细胞高度依赖谷氨酰胺作为能源和氮源（"谷氨酰胺成瘾"）
  • 通过 ASCT2 转运体吸收谷氨酰胺
  • 在谷氨酰胺酶作用下脱氨生成谷氨酸
  • 谷氨酸 → α-酮戊二酸 → 进入三羧酸循环
  • 补充 TCA 循环中间产物（用于生物合成）

Warburg 效应的临床应用：

  • ① PET-CT 显像：¹⁸F-FDG（氟代脱氧葡萄糖，葡萄糖类似物）被高代谢肿瘤大量摄取 → 显像剂浓集于肿瘤部位
  • ② 抗代谢药物（如 5-氟尿嘧啶、甲氨蝶呤）靶向核苷酸合成
  • ③ 靶向糖酵解途径关键酶（如 HK2、PKM2、LDHA）的药物研发
Warburg 获 1931 年诺奖。Warburg 效应是肿瘤代谢研究的起点，2011 年 Science 期刊将"肿瘤代谢重塑"评为年度突破之一。

七、肿瘤微环境（Tumor Microenvironment, TME）

肿瘤微环境（tumor microenvironment, TME）是指肿瘤细胞周围的细胞、分子和结构组成的局部环境，包括肿瘤细胞本身、免疫细胞、基质细胞、血管、细胞外基质及各种可溶性因子。TME不仅是肿瘤生长的"土壤"，更是肿瘤进展、转移、耐药和免疫逃逸的关键调控者。肿瘤不是孤立的细胞团，而是一个复杂的"器官"——TME与肿瘤细胞相互作用、共同进化。

（一）TME的组成：

  1. 肿瘤细胞：TME的核心，通过分泌细胞因子、生长因子和代谢产物改造周围环境。
  2. 免疫细胞：
    • 肿瘤相关巨噬细胞（TAM）：多为M2型，促进肿瘤生长、侵袭、血管生成和免疫抑制。分泌IL-10、TGF-β、VEGF。
    • 调节性T细胞（Treg）：高表达Foxp3，抑制效应T细胞功能，介导免疫耐受。
    • 髓系来源抑制细胞（MDSC）：未成熟髓系细胞，抑制T细胞和NK细胞功能。
    • CD8⁺细胞毒性T细胞：肿瘤浸润淋巴细胞（TIL），抗肿瘤主力军，但在TME中常处于"耗竭"状态（高表达PD-1/TIM-3/LAG-3）。
    • NK细胞：功能受抑（MHC I下调但抑制信号增强）。
    • 树突状细胞（DC）：抗原呈递功能受损（"耐受型"DC），不能有效激活T细胞。
  3. 基质细胞：
    • 癌相关成纤维细胞（CAF）：活化的成纤维细胞，分泌细胞外基质（胶原、纤连蛋白）、生长因子（FGF、TGF-β）、细胞因子，促进肿瘤增殖、侵袭和耐药。
    • 周细胞（pericyte）：覆盖血管内皮，血管稳定性调控。
  4. 细胞外基质（ECM）：胶原、纤连蛋白、层黏连蛋白、透明质酸等。ECM过度沉积→组织硬度增加→促进侵袭和耐药。
  5. 血管与淋巴管：肿瘤血管（结构紊乱、渗漏、缺氧）；淋巴管（肿瘤转移通道）。VEGF是关键促血管生成因子。
  6. 可溶性因子：细胞因子（IL-6、IL-10、TGF-β）、趋化因子、生长因子（VEGF、FGF、PDGF）、代谢产物（乳酸、腺苷）。

（二）免疫抑制性TME的形成机制：

  • ① 免疫抑制细胞聚集：Treg、TAM(M2)、MDSC大量浸润 → 抑制效应T细胞
  • ② 免疫检查点分子高表达：肿瘤细胞/免疫细胞高表达PD-L1、CTLA-4等 → T细胞耗竭
  • ③ 抑制性细胞因子：TGF-β、IL-10、IL-35 → 抑制T细胞活化和增殖
  • ④ 代谢竞争：肿瘤细胞高消耗葡萄糖、谷氨酰胺 → T细胞营养不足；高乳酸 → 抑制T细胞功能
  • ⑤ 缺氧（hypoxia）：快速增殖+血管紊乱 → 缺氧 → HIF-1α激活 → 促进血管生成、EMT、免疫抑制
  • ⑥ 抗原呈递缺陷：肿瘤细胞MHC I下调 → CD8⁺T细胞无法识别；DC功能受损 → 无法有效激活T细胞
  • ⑦ 物理屏障：致密ECM和高间质压 → T细胞难以浸润肿瘤实质（"免疫排斥型"肿瘤）

（三）Warburg效应与TME酸化：

  • 肿瘤细胞有氧糖酵解（Warburg效应）→ 大量乳酸产生 → TME pH值降低（酸化，pH 6.5左右）
  • 酸化的后果：
    1. 抑制T细胞和NK细胞的增殖和细胞因子分泌（效应T细胞适宜pH 7.0-7.4）
    2. 促进M2型巨噬细胞极化（免疫抑制表型）
    3. 促进Treg分化和功能
    4. 增强肿瘤细胞侵袭能力（激活MMPs）
    5. 促进血管生成
  • 腺苷累积：缺氧/炎症→ATP大量释放→胞外CD39/CD73将ATP降解为腺苷→腺苷结合A2A受体→抑制T细胞和NK细胞功能
肿瘤免疫编辑（cancer immunoediting）学说：机体免疫系统与肿瘤相互作用经历三个阶段——①清除期（elimination）：免疫系统识别并清除大多数肿瘤细胞；②平衡期（equilibrium）：少数肿瘤细胞与免疫系统处于动态平衡，肿瘤潜伏；③逃逸期（escape）：肿瘤细胞通过各种机制（如下调MHC、表达PD-L1、招募Treg等）逃避免疫监视，形成临床可见的肿瘤。TME是逃逸期的核心场景。
TME=肿瘤的"土壤与堡垒"。六大组成：肿瘤细胞+免疫细胞(TAM/Treg/MDSC/CD8+T)+基质细胞(CAF)+ECM+血管+可溶性因子。免疫抑制TME七大机制：抑制细胞聚集+检查点高表达+抑制因子+代谢竞争+缺氧+抗原呈递缺陷+物理屏障。Warburg效应→乳酸→TME酸化→免疫抑制+促侵袭。肿瘤免疫编辑三阶段：清除→平衡→逃逸。

八、肿瘤的诊断与治疗

（一）诊断方法：

  • ① 影像学：X 光、CT、MRI、超声、PET-CT
  • ② 病理学：活检 + 免疫组化、分子病理
  • ③ 肿瘤标志物：甲胎蛋白（AFP，肝癌）、癌胚抗原（CEA，结肠癌）、CA125（卵巢癌）、PSA（前列腺癌）
  • ④ 液体活检：循环肿瘤 DNA（ctDNA）、外泌体

（二）治疗策略：

  • ① 手术切除：早期实体瘤的首选
  • ② 化疗：化学药物（如顺铂、紫杉醇、5-FU）杀死快速分裂的细胞
  • ③ 放疗：电离辐射损伤肿瘤细胞 DNA
  • ④ 靶向治疗：针对特定分子靶点（如 EGFR 抑制剂、BCR-ABL 抑制剂伊马替尼、HER2 抗体曲妥珠单抗）
  • ⑤ 免疫治疗：PD-1/PD-L1 抑制剂、CAR-T 细胞治疗、肿瘤疫苗
  • ⑥ 激素治疗：乳腺癌（他莫昔芬）、前列腺癌
  • ⑦ 抗血管生成：贝伐珠单抗（抗 VEGF）
现代肿瘤治疗已从"化疗 + 放疗"走向"靶向 + 免疫"的精准医学时代。免疫检查点抑制剂（PD-1/PD-L1）获 2018 年诺奖。

第四节核心要点回顾：

  • 癌细胞 6 大特征：永生增殖、易转移、形态异常、新抗原、基因组不稳定、Warburg 代谢
  • 原癌基因：正常功能促进增殖，激活变癌基因（显性、单突变）。激活机制：点突变、扩增、重排、病毒启动子
  • 抑癌基因：正常功能抑制增殖，失活后致癌（隐性、双突变）。代表：Rb、p53、BRCA1/2、PTEN、APC
  • 病毒癌基因起源：v-onc 来自 c-onc（病毒劫持）。v-src（RSV）、v-myc（MC29）
  • 肿瘤发生：Knudson 二次打击学说；多阶段（启动-促进-进展）
  • 肿瘤干细胞：肿瘤的"种子细胞"，1% 群体；自我更新 + 抗凋亡 + 静止 + 耐药；导致复发和转移
  • 致癌因子 3 类：化学（黄曲霉素 B1 最强）、物理（UV、电离辐射）、生物（HPV、EBV、HBV，约 15%）
  • Warburg 效应：有氧糖酵解；谷氨酰胺成瘾；PET-CT 应用
