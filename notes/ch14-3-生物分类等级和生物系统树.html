第三节

生物分类等级和生物系统树

一、分类等级（taxonomic ranks）

林奈的分类系统最初只包括 纲（classis）、目（ordo）、属（genus）、种（species） 4 个等级。

现代分类学已扩展为 7 个基本等级（由高到低）：

  • 界（Regnum / Kingdom）
  • 门（Phylum / Divisio）（植物用 Divisio）
  • 纲（Classis / Class）
  • 目（Ordo / Order）
  • 科（Familia / Family）
  • 属（Genus）
  • 种（Species）

每一级之下都可插入 亚级（sub-），如亚界、亚门、亚纲、亚目、亚科、亚属、亚种。有时在特别庞大的阶元前还可加 超级（super-），如超目、超科；或加 下级（infra-），如下纲、下目。

奥赛必记 七级分类：界门纲目科属种。口诀："界门纲目科属种"，由高到低。

附加单元：

  • 亚种（subspecies）：种下的分类阶元，是种内因地理隔离分化形成的个体群。
  • 变种（variety, varietas）：种内的种型或个体变异，不是法定的分类阶元。
  • 品种（cultivar / breed）：人为通过培育形成的种群，非分类阶元，仅用于农业畜牧。
亚种、变种、品种三者易混。亚种 是分类阶元；变种 是种内变异；品种 是人工培育的产物。

二、种（species）的概念

不同专业的生物学家对"种"的概念有不同的理解，争论焦点主要有二：

  1. 形态学种（morphological species）/ 分类学种（taxonomic species）：把物种定义为形态结构相似的个体群。
  2. 生物学种（biological species）：强调种间 生殖隔离（reproductive isolation） 的机制。

随着科学发展，提出了 多维性种（multidimensional species） 的概念："种是形态、生理、行为和生殖的动态群"。

陈世骧（1905–1988） 我国著名昆虫学家、分类学家，对物种的定义：

"种是由种群所组成的生殖单元，在自然界占有一定的生境，在系谱上代表一定的分支。"

该定义包括 种的四个标准：

  • ① 种群组成：由若干种群组成。
  • ② 生殖隔离：与其他种不能交配或交配后不能产生可育后代。
  • ③ 生境地位：在自然界占有一定生态位。
  • ④ 系谱分支：在进化树上代表一条独立分支。
陈世骧（中国科学院院士）的种定义在国际分类学界被广泛接受，是奥赛常考的人名概念。

种是客观存在的，又是进化发展的。一个种通过遗传、变异和自然选择，可能会发展成另一个新种；现在地球上的众多物种，就是由共同祖先逐渐演化而来的。

其他物种概念（奥赛拓展）：

  • 进化种（evolutionary species）：Simpson 1951 提出，一个种是一条独立进化的世系，具有自己独特的进化历史和趋势。
  • 系统发育种（phylogenetic species）：Cracraft 1983 提出，一个最小可诊断的单系群（monophyletic group）。
  • 生态种（ecological species）：Van Valen 1976 提出，占据独特生态适应区的生物类群。
  • 无融合种（agamospecies）：对无性繁殖生物使用，与形态学种类似。
4 大物种概念（奥赛重难点）：生物学种 / 进化种 / 系统发育种 / 生态种，各有所长也各有所短。

三、亚种、变种、品种的区别

种下还有 亚种、变种、品种 三个易混概念，区别如下：

三者关系：种 = 亚种 × n；变种 是种内变异；品种 是人工培育的。
项目亚种（subspecies）变种（variety, var.）品种（cultivar, cv.）
性质分类阶元（法定的）非分类阶元（种内变异）非分类阶元（人工产物）
形成原因地理隔离 + 长期分化基因突变 + 自然选择人工选择 + 培育
分布不同的地理区域同一区域内可并存由人类决定
遗传差异较大，已达亚种级较小，基因频率差异人为定向选育
举例东北虎 / 华南虎高豌豆 / 矮豌豆（种内）金鱼犬、富士苹果
学名Canis lupus familiarisPisum sativum var. pumilioMalus pumila 'Fuji'

举例说明：

  • 东北虎 vs 华南虎：是虎（Panthera tigris）的两个亚种，长期地理隔离有可能会进化成两个不同的种。
  • 北京人 vs 现代人：周口店"北京人"是直立人（Homo erectus）的一个亚种，学名 Homo erectus pekinensis（北京直立人）。他和现代人同属（Homo），但不同种（erectus vs sapiens）。
  • 高茎豌豆 vs 矮茎豌豆：高茎豌豆种群中出现了矮茎豌豆植株，这些矮茎豌豆植株就是 变种。若把矮茎豌豆人工培育成大种群，则和原始种各成一个 品种。
变种 × 培育 → 品种。变种是天然的，品种是人工的，这是判断的关键。

四、生物系统树（phylogenetic tree）

图 6-3-1 生物系统树 是以古生物学、比较形态学等方面资料为基础，同时吸收了分子生物学的一些研究结果而建成的 以门类为单位的系统树。这个系统树反映生命进化先后经历三个阶段：

  1. 原核生物阶段：细菌、蓝藻等原核生物。
  2. 真核单细胞阶段：原生生物（草履虫、变形虫、眼虫等）。
  3. 真核多细胞阶段：植物界、真菌界、动物界。
三阶段：原核 → 真核单细胞 → 真核多细胞。这是 Whittaker 五界系统（1969）的纵向演化轴。
图 14-3-2　生物系统树（以门类为单位；仿"图 6-3-1"） ┌── 被子植物 ├── 裸子植物 ┌─ 植物界┤├── 苔藓 │ ├── 蕨 │ ├── 红藻 / 绿藻 / 团藻 / 硅藻 / 衣藻 / 金藻 / 褐藻 ┌─ 真核生物 ────┤ │ (Eukaryota) │ ┌── 脊索动物 │ ├─ 动物界┤├── 节肢动物 │ │ ├── 软体动物 / 棘皮动物 / 扁形动物 / 腔肠动物 / 海绵 │ │ └── 原生动物 │ │ │ ├─ 真菌界 ── 真菌 / 黏菌 / 酵母菌 │ │ │ └─ 原生生物（单核真核） │ 古原核生物（共同祖先） │ └─ 原核生物 ─┬── 细菌 ── 蓝藻 / 原绿藻 └── 古细菌

系统树是生物界的 "家谱"，是生物的种类繁多、历史久远、彼此之间关系十分复杂的视觉化体现。

系统树反映的内容：

  • 分支关系：亲缘关系越近，分类位置越近。
  • 时间方向：根在左（旧），叶在右（新）。
  • 进化程度：越靠近末端的类群通常越高等。

比较生物化学、免疫学等多学科的研究不断为探寻生物亲缘关系提供新资料，生物系统树也从而不断地得到补充和修正。

系统树是 假说性 的：随着新证据（特别是分子证据）的出现，系统树会不断调整。

系统树构建的常用方法：

  • 距离法（distance-based）：邻接法（Neighbor-Joining, NJ, Saitou & Nei 1987）、最小进化法（ME）、UPGMA（最早，但常给出错误的有根树）。
  • 最大简约法（Maximum Parsimony, MP）：寻找所需进化改变最少的树。
  • 最大似然法（Maximum Likelihood, ML）：Felsenstein 1981 提出，依据特定进化模型计算似然值。
  • 贝叶斯法（Bayesian Inference, BI）：用马尔可夫链蒙特卡罗（MCMC）采样后验分布。
4 大建树方法：距离（NJ/UPGMA）/ 简约（MP）/ 似然（ML）/ 贝叶斯（BI）。奥赛重在 NJ 和 MP。
根（root） 的确定：① 外群法（outgroup）：选择一个明显外群的物种作为外群，确定树根位置；② 中点法（midpoint rooting）：将根定在最长分支的中点；③ 分子钟定根：用已知分歧时间的化石标定点来定根。

本节核心要点

  • 七级分类：界门纲目科属种。亚级前缀"亚"或"下"；超级前缀"超"。
  • 种的概念（陈世骧定义）：由种群组成的生殖单元，占据一定生境，代表系谱分支。包括四个标准：种群组成、生殖隔离、生境地位、系谱分支。
  • 种下阶元：亚种（分类阶元，地理隔离） / 变种（非阶元，种内变异） / 品种（非阶元，人工培育）。
  • 生物系统树：以门类为单位，反映三阶段进化（原核 → 真核单细胞 → 真核多细胞）。
  • 建树方法：距离法（NJ/UPGMA）、最大简约法（MP）、最大似然法（ML）、贝叶斯法（BI）。
