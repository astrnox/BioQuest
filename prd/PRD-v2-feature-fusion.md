## 二、核心功能设计

### 2.1 生物方向测评（融合「升学小测」）

**灵感来源**：https://forum.trae.cn/t/topic/42449  
**融入位置**：学习管理中心 → 新增「🎯 生物方向测评」Tab

**功能设计**：
- **多维度测评问卷**（5-8 题）：兴趣倾向（分子生物/生态/遗传/医学/神经等）、能力特长（记忆型/推理型/实验型）、学习风格、职业意向
- **AI 匹配算法**：根据测评结果推荐 3-5 个生物学细分方向，每个方向附带推荐理由、适合特质、推荐学习路径
- **趣味分享标签**：生成「🧬 分子侦探」「🌿 生态观察家」等可传播标签
- **学习路径规划**：为每个方向生成从当前到高考/竞赛的阶段性学习建议

**技术要点**：
- 前端纯 HTML/CSS/JS 问卷组件
- 调用 `AIClient.chat` 生成个性化测评结果
- JSON 结构化输出 {directions, labels, roadmap}
- 可生成分享卡片（Canvas 截图或纯 CSS 卡片）

### 2.2 每日探索（融合「Disrec 反推荐」）

**灵感来源**：https://forum.trae.cn/t/topic/47646  
**融入位置**：社区模块 → 新增「每日探索」区域；练习模块 → 智能推荐多样化

**功能设计**：
- **每日 3 篇精选**：推送学生平时不常接触的生物分支内容（如常做遗传题的学生，推送生态学/神经生物学文章）
- **三轴标签**：每篇文章标注「知识域」（分子/细胞/生态/演化等）、「难度」（竞赛/高考/科普）、「呈现形式」（文字/图解/视频/交互）
- **知识多元度雷达**：六维雷达图展示学生当前知识覆盖广度（细胞生物学、遗传学、生态学、生理学、分子生物学、演化生物学）
- **推荐去重**：历史感知，避免重复推送同类内容

**技术要点**：
- 基于学生错题本/练习记录的标签分布，计算盲区维度
- 每日 0:00 刷新，跨 session 持久化
- 雷达图用纯 Canvas 或 SVG 实现（无需 ECharts 依赖）

### 2.3 「学练思行」闭环重组（融合「Ogden 850」）

**灵感来源**：https://forum.trae.cn/t/topic/29627  
**融入位置**：学习管理中心 → 重组现有任务/进度/抢救/日志

**功能设计**（将现有功能重组为四阶闭环）：

| 阶段 | 现有功能 | 增强 |
|------|----------|------|
| **学**（知识输入） | 今日任务 | 自动关联对应知识卡片/课件 |
| **练**（即时巩固） | 练习模块 | 学完即练，I+1 自适应难度 |
| **思**（反思归纳） | 任务日志 | 结构化反思模板（"我学到了什么/哪里没懂/下一步"） |
| **行**（迁移应用） | AI 抢救 | 从"错题重做"升级为"真实情境应用题" |

**技术要点**：
- 工作量低，主要是 UI 重组 + 反思模板
- 每个阶段标记完成状态，四阶全绿 = 当日学习闭环完成

### 2.4 AI 角色卡系统（融合「DianaAgent」）

**灵感来源**：https://forum.trae.cn/t/topic/36626  
**融入位置**：AI 课堂 → 多代理讨论的角色管理

**功能设计**：
- **角色卡定义**：为每个 AI 代理（教师/助教/学霸/困惑学生/应用学生）创建角色卡，定义人设、知识域、对话风格
- **双层记忆**：
  - 短期记忆：当前课堂对话上下文
  - 长期记忆：学生历史提问偏好、认知水平、常见错误类型
- **对话风格预设**：教师可切换教学模式（"苏格拉底式提问"/"直讲式"/"探究式"）

**技术要点**：
- 复用现有 MultiAgent 架构，为每个 agent 添加 roleCard 配置
- 长期记忆存储在 Supabase 的 user_profile 中
- 对话风格切换无需重新生成，直接修改 system prompt

### 2.5 自适应难度练习（融合「I+1 Quest」）

**灵感来源**：https://forum.trae.cn/t/topic/40927  
**融入位置**：练习模块 → 智能出题策略

**功能设计**：
- **I+1 难度算法**：基于 IRT 3PL 模型（已有），在用户当前能力 θ 之上 +1 难度出题
- **故事化闯关**：将生物主题映射为冒险关卡（"穿越细胞膜""基因密码破译""生态金字塔攀登"）
- **关卡解锁**：当前关卡正确率 ≥ 70% 解锁下一关

**技术要点**：
- 工作量高，需重新设计练习 UI 为冒险地图
- 与现有 IRT 模型兼容，仅调整选题策略
- 建议作为可选皮肤，保留原列表模式

---

### 2.6 可视化学习路径（融合「LinkWeave」）

**灵感来源**：https://forum.trae.cn/t/topic/40960  
**融入位置**：学习管理中心 → 学习路径编排

**功能设计**：
- **学习路径白板**：节点拖拽创建学习计划（"细胞结构 → 光合作用 → 综合练习"），节点间连线表示前置依赖
- **任务看板**：三列（待开始/进行中/已完成），拖拽卡片更新状态
- **自动生成**：AI 根据目标（"3 周掌握遗传学基础"）自动生成学习路径节点

**技术要点**：
- 工作量高，需纯 Canvas/SVG 实现拖拽白板
- 可降级为纯列表形式，保留 AI 自动生成路径功能
