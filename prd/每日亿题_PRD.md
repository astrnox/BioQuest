# 每日亿题 — 产品需求文档（PRD）

> **版本**：v1.0  
> **定位**：从「每日一题」的克制，走向「每日亿题」的放纵——一个让你刷题上瘾的无限题海宇宙。  
> **核心一句话**：**把刷题变成刷短视频一样上瘾，把题海变成你可以纵身一跃的游乐场。**

---

## 一、产品愿景

> *"一题太少，亿题刚好。"*

「每日一题」教会了用户**坚持**；「每日亿题」要教会用户**沉浸**。

我们不再给用户每天一道题的门票，而是给他们一整片海洋的钥匙——你可以在海边踩水，也可以一口气潜到深海。题目不再是"任务"，而是"探索"；刷题不再是"苦修"，而是"冲浪"。

**核心隐喻：「题海」**

整个产品视觉围绕"海洋"展开。题目是水滴，题库是海洋，用户是潜水者。  
- 浅水区（入门）→ 珊瑚礁区（进阶）→ 深海区（精通）→ 深渊区（大师）→ 海底火山（限时挑战）

## 二、目标用户画像

| 角色 | 特征 | 核心诉求 |
|------|------|----------|
| **碎片刷题人** | 通勤/排队/摸鱼时刷几题 | 快速、爽感、即时反馈 |
| **考公/考研战士** | 需要大量刷题提分 | 题量、正确率统计、错题回顾 |
| **知识上瘾者** | 纯粹喜欢学新知识 | 趣味性、多样性、冷知识 |
| **社交卷王** | 喜欢和朋友比拼 | 排行榜、对战、炫耀 |
| **焦虑型学习者** | 总觉得学不够 | 量化成长、可视化进度 |

## 三、核心体验设计（UX 金三角）

### 3.1 第一触感：进入即"刷"

> 打开 App 的第一秒，不是欢迎页，不是课程表，而是**直接开始刷题**。

像 TikTok 一样：**零摩擦启动**。首页 = 题目流。下滑 = 下一题。上滑 = 上一题。左滑 = 跳过。右滑 = 收藏。

**交互模型：卡片式题目流（Question Feed）**

```
┌──────────────────────────────┐
│  ← 上一题    [题目卡片]    → 下一题  │
│                              │
│   题目内容区域                │
│   （支持文字/图片/代码/音频）   │
│                              │
│   选项 / 填空 / 拖拽区域      │
│                              │
│   作答后：                    │
│   ✅ 正确 → 绿色涟漪 + 连击数  │
│   ❌ 错误 → 红色微震 + 解析展开 │
│                              │
│   [收藏] [分享] [报告] [跳过]  │
└──────────────────────────────┘
```

### 3.2 核心循环：刷题上瘾飞轮

```
          ┌──────────────────┐
          │   看到一道题       │
          └───────┬──────────┘
                  │
       ┌──────────▼──────────┐
       │  作答（< 3秒决策）    │
       └───────┬──────────┘
               │
    ┌──────────┴──────────┐
    │                     │
    ▼                     ▼
  正确                   错误
    │                     │
    ▼                     ▼
 连击+1              连击断裂
 得分×连击           解析自动展开
 升级进度+           错题自动入库
 特效增强            鼓励"再来一题"
    │                     │
    └──────────┬──────────┘
               │
               ▼
       "再来亿题？"
       （自动加载下一题，无缝衔接）
```

### 3.3 题海可视化：你的潜水地图

用户不是在看一个"已完成 328/5000"的进度条，而是在看一张**深海地图**：

```
        🌊 海平面
    ┌───────────────────────
    │  🐠 浅水区 (0-100m)    已探索 ████████░░  80%
    │  🐙 珊瑚礁区 (100-300m) 已探索 ████░░░░░░  40%
    │  🦑 深海区 (300-1000m)  已探索 ██░░░░░░░░  15%
    │  🐋 深渊区 (1000m+)    未解锁 🔒
    │  🌋 海底火山            限时活动 ⏰
    └───────────────────────
```

每答对一题，潜水深度 +1 米。每解锁一个新区域，获得专属海洋生物徽章。

## 四、功能模块详解

### 4.1 无限题流（Infinite Question Feed）

| 特性 | 说明 |
|------|------|
| **题目来源** | AI 实时生成 + 题库 + 用户共创 + 错题变形 |
| **推荐算法** | 基于你的知识图谱，难度在"心流区间"（85% 正确率）波动 |
| **题目类型** | 单选 / 多选 / 填空 / 判断 / 拖拽排序 / 代码补全 / 语音作答 |
| **题目形态** | 文字题 / 图片题 / 音频题 / 视频题 / 交互式代码题 |
| **刷题模式** | 自由刷（随机）、专项刷（按知识点）、挑战刷（限时）、对战刷（PK） |

### 4.2 连击系统（Combo System）

> 灵感来自音游和格斗游戏。连击是让刷题"上瘾"的核心机制。

- **连续答对**：连击数 +1，题目特效随连击升级（火花 → 闪电 → 彩虹 → 全屏特效）
- **连击倍数**：分数 = 基础分 × 连击倍数（10连击×1.5, 50连击×2, 100连击×3）
- **连击断裂**：答错或超时则连击归零，但保留"最高连击记录"
- **连击保护**：每日有 3 次"连击护盾"，答错不打断连击
- **连击排行榜**：好友间比拼最高连击数

### 4.3 知识图谱 & 自适应难度

```
用户知识图谱动态更新：

  数学
  ├── 代数    ████████░░  82% (强)
  ├── 几何    ██████░░░░  58% (中)
  ├── 概率    ███░░░░░░░  30% (弱) ← 优先出题
  └── 微积分  ░░░░░░░░░░   0% (未探索)

  算法会自动：
  1. 在弱项知识域多出题
  2. 在强项域偶尔出题维持记忆
  3. 难度始终在"85% 正确率"的心流区间
```

### 4.4 对战模式（Battle Mode）

| 模式 | 规则 | 乐趣点 |
|------|------|--------|
| **1v1 实时对战** | 同题竞速，先答对得分 | 心跳加速，肾上腺素 |
| **多人乱斗** | 10 人同时答题，淘汰制 | 大逃杀式紧张感 |
| **好友挑战** | 发起挑战，24h 内比拼总分 | 社交传播 |
| **房间模式** | 创建主题房间，邀请入局 | 社群/班级场景 |
| **异步对战** | 像 Chess.com 一样，不要求同时在线 | 低门槛社交 |

### 4.5 每日挑战 & 限时活动

- **每日亿题挑战**：每天随机 100 题包，完成后获得"亿题达人"徽章
- **海底火山爆发**：不定时出现限时高难度题，全服协作解答，答对者获得稀有奖励
- **周末题海马拉松**：周六日不限量刷题，双倍积分
- **主题周**：每周一个主题（如"三国周"、"宇宙周"、"算法周"），所有题目围绕主题

### 4.6 错题本 & 智能复习

- 错题自动归档，按知识点分类
- AI 将错题变形（换数字、换表述、换场景）生成"影子题"反复练习
- 艾宾浩斯遗忘曲线自动安排复习节奏
- 错题攻克后自动从错题本"毕业"，获得成就

### 4.7 社交 & 社区

- **题友圈**：分享战绩、连击截图、有趣题目
- **题目共创**：用户可以投稿题目，审核通过后加入题库，出题人署名
- **题海热榜**：本周最热题目、最难题型、最有趣冷知识题
- **组队刷题**：创建或加入"刷题小队"，团队总分排名

### 4.8 成就 & 收集系统

| 成就类型 | 示例 |
|----------|------|
| **深度成就** | 潜入 100m / 500m / 1000m / 5000m |
| **连击成就** | 10连击 / 50连击 / 100连击 / 500连击 |
| **数量成就** | 累计 100 题 / 1000 题 / 10000 题 / 100000 题 |
| **速度成就** | 1秒秒答 / 连续 10 题 3 秒内 |
| **收集成就** | 集齐浅水区所有生物 / 解锁全部海洋区域 |
| **隐藏成就** | 凌晨 3 点刷题 / 连续 7 天 100 连击 / 答对全部火山题 |

## 五、视觉 & 动效设计方向

### 整体风格
- **主题**：深蓝海洋 + 霓虹光效（赛博海洋风）
- **暗色模式优先**：深蓝底色，题目卡片为半透明磨砂玻璃质感
- **生物伙伴**：用户选择一只海洋生物作为"刷题伙伴"（小丑鱼、海龟、章鱼、鲸鱼），它会随着你的进度成长

### 关键动效
- **答对**：从卡片中心扩散绿色涟漪，伴随清脆的"叮"声，连击数字弹出
- **答错**：卡片微震（haptic），红色脉冲，正确答案自动高亮展开
- **连击升级**：连击达 10/50/100 时，全屏特效 + 震动反馈
- **区域解锁**：深海地图展开动画，新生物游入画面
- **切换题目**：卡片翻转或水流过渡

## 七、技术实现要点

| 模块 | 技术方案 |
|------|----------|
| AI 题目生成 | LLM + 知识图谱约束，确保题目准确性和多样性 |
| 题目推荐 | 协同过滤 + 知识追踪模型（如 DKT/BKT） |
| 实时对战 | WebSocket + 消息队列，低延迟匹配 |
| 题目流 | 预加载 + 滑动窗口缓存，保证滑动流畅 |
| 错题变形 | 基于模板的题目变换 + LLM 语义改写 |
| 离线刷题 | 本地缓存 50-100 题，无网络也能刷 |

## 九、从「每日一题」到「每日亿题」的迁移策略

| 阶段 | 动作 | 风险控制 |
|------|------|----------|
| **Phase 1：共存** | 保留「每日一题」入口，新增「题海冲浪」模式 | 老用户不流失 |
| **Phase 2：引导** | 「每日一题」完成后自动推荐「再来亿题？」 | 自然过渡 |
| **Phase 3：融合** | 「每日一题」成为「每日亿题」的子功能（每日挑战） | 品牌统一 |
| **Phase 4：进化** | 正式更名为「每日亿题」，旧入口下线 | 完成迁移 |

## 十、风险 & 边界

| 风险 | 应对 |
|------|------|
| **刷题疲劳** | 心流算法确保难度适中；每 30 分钟推送"浮出水面休息"提醒 |
| **题目质量下降** | AI 生成题目需人工抽检 + 用户举报机制 + 社区投票 |
| **沉迷问题** | 每日刷题上限（可自定义）+ 健康提醒 + 家长模式 |
| **作弊** | 对战模式反作弊检测（答题速度异常、切屏检测） |
| **内容安全** | 题目内容审核 pipeline，敏感词过滤 |

## 十一、总结

> **每日一题教会你自律，每日亿题让你享受自由。**

「每日亿题」不是对「每日一题」的否定，而是它的进化。从"每天完成一道题的任务感"进化到"随时跳进题海畅游的沉浸感"。它把学习从一件需要意志力的事情，变成一件你忍不住想再做的事情。

核心就三个字：**多、快、爽**。

- **多**：AI 驱动的无限题库，永远有下一题
- **快**：零摩擦启动，秒级反馈，连击飞轮
- **爽**：视觉、听觉、触觉三通道正反馈，刷题如游戏
